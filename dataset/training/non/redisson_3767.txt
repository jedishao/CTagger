RedissonReactiveClient limitations
**Is your feature request related to a problem? Please describe.**
`RedissonReactiveClient` is missing many of the features compared to  `RedissonClient`.
1. Returned `RMapReactive` has no methods to set max size or eviction algorithm.
2. No method to create a `LocalCachedMap` (or perhaps) `LocalCachedMapReactive`. There's an open issue https://github.com/redisson/redisson/issues/3671 for this point only.

**Describe the solution you'd like**
Bring feature parity between blocking and reactive API.

**Describe alternatives you've considered**
Using blocking API.
