Kafka Plugin `kafka.table-names` configuration
In Kafka plugin there's an option 
* specify a schema for topics and in separate schema definition file
* use default schema with message as json and internal metdata fields. 

If you opt to specify a schema for the topic you need additionally add table name to `kafka.table-names` variable in a catalog, even though table name exists in schema definition file. This creates additional operation burden configuring the topics as you need simultenisly modify two files with the same information.

*Proposal*
If the topic has corresponding schema definition file do NOT require to add table name to `kafka.table-names` property and use table name from the schema file.
