ApproximateHistogram: Better quantile estimation for first bin
The approximate histogram based quantile estimator works by building up a set of bins `(value, count)` and attempting to capture a decent amount of the distribution.

Currently, due to the following code, if the requested quantile falls in the first bin, then the minimum value is returned. This can mean that if your resolution is set too low, even if you ask for a high quantile (like 98%), you'll get the min back rather than something potentially more reasonable (like, something that takes into account the first bin value).

```java
if (i == 0) {
        // At the first bin, there are no points to the left of p (min)
        quantiles[j] = this.min();
      }
```

I haven't checked the last bin, but it may have a similar issue.
