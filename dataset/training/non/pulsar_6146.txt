Pulsar SQL Cluster Fails Out of the Box with Default Deployment v2.5.0
With a default deployment of 3 Zookeeper nodes, 3 Broker/BookKeeper nodes, and 3 Pulsar SQL nodes, SQL query "select * from pulsar."public/default".generator_test;" fails.

"select * from system.runtime.nodes;" works correctly and 
"show tables in pulsar."public/default";" works correctly.

There are two ways in which it fails: 

1. For a cluster with multiple hosts, where conf/presto/catalog/pulsar.properties "pulsar.broker-service-url=http://10.0.0.7:8080,10.0.0.8:8080,10.0.0.9:8080", the following error message is shown at the Presto CLI with --debug:
