**Expected behavior**
No exception happened

**Actual behavior**
Exception happened

**Redis version**
6.2.6

**Redisson version**
org.redisson:redisson:3.13.1

**Redisson configuration**
```
Config config = new Config();
config.useSingleServer().setAddress("redis://127.0.0.1:6379");
config.setLockWatchdogTimeout(15 * 1000);
RedissonClient client = Redisson.create(config);
```

**Steps to reproduce or test case**
Let me simplify the reproduce process:

1. Thread x get Lock "A" and hold the Lock
2. Thread y get ReadLock "A" and also hold the ReadLock
3. Thread x and thread y all acquired lock
4. Thread y call method `unlock` to release ReadLock y
5. After a few seconds, thread x also call method `unlock` to release Lock x，and then it causes an exception
