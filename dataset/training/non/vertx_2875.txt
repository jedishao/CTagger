web socket responses are not being sent on eventBus.Message
I would like to use a single socket connection, to send multiple messages to Socket server and receive the response from the socket server and reply via **eventBus.Message.** 


```public class SocketClient extends AbstractVerticle {

    @Override
    public void start(Future<Void> startFuture) {

        HttpClient client = vertx.createHttpClient();
        client.websocket(9090, "localhost", "/socketDuplicate", webSocket -> {
            this.vertx.eventBus().<String>consumer("/socketClient")
                    .toFlowable()
                    .subscribe(message ->
                            webSocket.writeBinaryMessage(Buffer.buffer(message.body())).handler(buffer -> {
                                System.out.println("Buffer is " + buffer.toString() + " for request " + message.body());
                                message.reply(buffer.toString());
                            }));
            startFuture.complete();
        });
    }
}
```

but the response from the socket server is not being sent via message.reply.
I tried with HTTP client, that seems to be working fine. 
To replicate: https://github.com/pavanGorti/vertx_socket_issue_replicate (expected & actual output are in README.md)

Please point out where am I going wrong.
