RedissonPromise泄露
`RBlockingQueue`的`take`方法导致内存泄露

```java
public void run(String... args) throws Exception {
        RBlockingQueue<String> queue = client.getBlockingQueue("demo");

        Runnable producer = () -> {
            for (int i = 0; i < 1000000; i++) {
                queue.offer(i + "");
            }
        };

        Runnable consumer = () -> {
            while (true) {
                try {
                    String msg = queue.take();
                    System.out.println("receive: " + msg);
                } catch (Exception e) {
                    e.printStackTrace();
                }
            }
        };

        new Thread(producer).start();
        new Thread(consumer).start();
    }
```
