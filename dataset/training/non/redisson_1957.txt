redis-4.0 Tencent Cloud Cluster (腾讯云集群版)

### Redisson version
3.10.0-3.10.3

### Redisson configuration
        Config config = new Config();
        config.useSingleServer()
                .setAddress("redis://10.1.1.16:6379")
                .setTimeout(3000)
                .setPassword(password);
