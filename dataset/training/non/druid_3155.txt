version field of HadoopTuningConfig is always set to default value
http://druid.io/docs/latest/ingestion/batch-ingestion.html says that user can specify `version` of segments.
But, `HadoopIndexTask` always replaces `version` with DateTime of indexing start time (which is default when no version is given).

I'm not sure the behavior of `HadoopIndexTask` is intended or not 
but I think it needs consistency between docs and implementation.
