Improve externalAuthentication with CLI
As requested and discussed in https://github.com/trinodb/trino/pull/7335

Seems like SSO is configured on the server and managed via the server. As such it makes no sense to require a CLI (or JDBC driver). Instead either of these tools should just react appropriate if told by the server to display a SSO URL or redirect to it or whatever.

In the current setup is is also unclear what happens if the server is SSO configured but the user does not use the externalAuthentication option.

This is can be used to clarify this for the documentation and potentially also update the code and how it works.
