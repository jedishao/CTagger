[Proposal] maxQueryTimeout property in runtime properties.
`druid.server.http.defaultQueryTimeout` property can be overridden by clients via query context. It would be nice to have `druid.server.http.maxQueryTimeout` setting  similar to `druid.server.http.maxScatterGatherBytes` where actual value used should be default or math.min(context.timeout, maxQueryTimeout).
