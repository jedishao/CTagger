I can solve this error by adjusting the `-XX:MaxDirectMemorySize` size to be larger than the `memoryNeeded` size specified in the error.  However, when I try to reduce or even change the `druid.processing.buffer.sizeBytes` configuration value to fix the problem, this has no effect.  Regardless of what I set this value to in my properties file, the error message will report the value to be `1,073,741,824`.

In digging through the source it looks like this come from the `intermediateComputeSizeBytes` method of the [`DruidProcessingConfig`](https://github.com/druid-io/druid/blob/0.8.0/processing/src/main/java/io/druid/query/DruidProcessingConfig.java) class, which by default returns a static value (`1024 * 1024 * 1024`).  I'm likely missing some implementation  details of this class and method, so I can't say for certain why this is happening, but as it is the value set in the properties file has no effect on the reported buffer size for the storage of intermediate results.
