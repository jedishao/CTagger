Improve rewrite of EXISTS subquery with single equality conjunct
Currently queries with `EXISTS` with single equality conjunct like:
``` 
SELECT o_orderkey FROM orders WHERE EXISTS (SELECT 1 FROM nation WHERE o_orderkey = n_nationkey);
```
are rewritten to plan containing `count()` aggregation and `LEFT JOIN`.

Simpler (and probably more performant) rewrite would facilitate `SEMI JOIN`. So rewritten plan is equivalent to plan for query

```
SELECT o_orderkey FROM orders WHERE o_orderkey IN (SELECT n_nationkey FROM nation);
```
