Bad error message when function cannot be resolved
```sql
SELECT reduce_agg(value, 0, (a, b) -> a + b, (a, b) -> cast(a + b as varchar))
FROM (VALUES 1) t(value);
```

Produces:

```
line 1:8: Unexpected parameters (integer, integer, io.prestosql.sql.analyzer.TypeSignatureProvider@26a54cef, io.prestosql.sql.analyzer.TypeSignatureProvider@15956b6e) for function reduce_agg. 
Expected: reduce_agg(T, S, function(S,T,S), function(S,S,S)) T, S
```

Note the references to ` io.prestosql.sql.analyzer.TypeSignatureProvider@...`
