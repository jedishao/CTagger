[Feature Request]Tiered storage like Pravega
Both Pulsar and [Pravega](https://github.com/pravega/pravega) are streaming storage solution based on BookKeeper. However, Pravega has an extra feature of automatic segment migration for tiered storage(auto tiering)---BookKeeper for streaming and distributed filesystem(HDFS,S3,..,etc) for long term storage.  Given this feature available, Pravega could be a unified storage solution for both streaming and batch processing. On the other hand, Flink would be a unified computation solution for both streaming and batch processing, as a result, Pravega+Flink might be candidates for next generation big data platform which could be defined as Stream Native. The segment store design of Pravega is not complicated, if this feature could be provided by Pulsar, perhaps Pulsar+Flink could be a better choice for NG big data platform.
