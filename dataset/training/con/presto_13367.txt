Presto queries start to hang only for a particular user
I have a Presto 0.220 cluster in EMR connected to a custom Hive Metastore backed by AWS RDS instance. Along with Presto, there is Alluxio (https://www.alluxio.io/) deployed on all of the machines of the same EMR cluster. The data for querying is on S3 but all IO goes through Alluxio (since Alluxio is basically a distributed read/write through cache between S3 and Presto in this case). The cluster is configured with `query.max-execution-time=2m` since it expects to have only short-running queries.

This setup runs fine in production for several hours but after that queries just start to time out. It looks like for some reason some of the TableScan tasks just run indefinitely.

For example, a query `select count(*) from ecs_db.prod_db_funnel where uid in ('3210be7ad82f403298f7c4da065ec657') AND ( year='2019' and ( (month='06') ) )` times out, though usually it should finish in several seconds.
