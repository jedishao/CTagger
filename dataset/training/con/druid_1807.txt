query hangs on broker with Jetty 9.2.13 version
- Attached query when sent to the router hangs on bard 
  [groupBy_large.txt](https://github.com/druid-io/druid/files/9452/groupBy_large.
-  removing the filter from the query i.e reduce the size of serialized query makes it working. 
- from initial exploration it seems router AsyncProxy is being wierd with the latest jetty version when forwarding the query request to the broker and the broker keeps waiting for more content from the router. 
- reverting the Jetty version to 9.2.5 seems to fix it.
