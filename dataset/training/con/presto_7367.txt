Query stuck in join filter function
We saw a worker not making progress on queries today. And noticed that the 59 of the worker's 64 threads are stuck in doing work for a query that had been abadoned.

Query is a very expensive cross join:
```
SELECT COUNT (*)
FROM (
  select id
  from dim_all
  where ...) a
INNER JOIN (
  SELECT LEAST(user1, user2) AS id1, greatest(user1, user2) AS id2
  FROM dim_r
  WHERE ...
  GROUP BY 1,2) b
ON (
  a.id=b.id1 
  OR a.id=b.id2)
LIMIT 10000
``` 

Two issue we need to fix here:
* remove getBlocks call from StandardJoinFilterFunction.filter
* make sure the driver gives up its thread after processing for a while. It was stuck in our cluster for 15 hours.
