Possible cause:

The Yielder generated by the ClientQuerySegmentWalker expects to be called only from a single thread ever (by way of the assumption in QueryMetrics), but it's called by multiple threads in the context of the JDBC server. This is because one logical query might be split into multiple frames and each frame could be got by a different http request.
