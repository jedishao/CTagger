Hang in AWS SDK with parallel uploads under load
As [PrestoS3FileSystem.uploadObject](https://github.com/prestodb/presto/blob/f9f3542efa413e21a896909476890c2416846a4e/presto-hive/src/main/java/com/facebook/presto/hive/PrestoS3FileSystem.java#L1032) is using aws s3 sdk 1.10.30, a race condition in aws sdk waitForCompletion method affects it. A proposal to update AWS SDK to a newer stable version.


> A race condition that can occur with multiple calls to CopyMonitor#setFuture and UploadMonitor#setFuture that can cause an infinite loop in AbstractTransfer#waitForCompletion.
> https://github.com/aws/aws-sdk-java/blob/1.11.119/CHANGELOG.md#bugfixes
> https://github.com/aws/aws-sdk-java/issues/1102
