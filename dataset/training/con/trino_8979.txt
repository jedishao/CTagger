Exception caused by cancellation in JDBC driver not informative enough
In the Trino JDBC driver, when a thread T is waiting for the execution of a statement to complete, another thread can invoke Statement.cancel to cancel the execution of the statement and unblock T. T will then get an SQLException. However, the SQLException provides no indication that the failure of the execution is due to cancellation. In particular, neither the error code nor the SQL state is set, and the exception message just says something along the lines of "Error fetching results" or "Error executing query". It would be nice if the error code or the SQL state is set to indicate that the reason is cancellation so that an exception handler can handle the exception accordingly.
