RLockReactive fail to unlock when subscribe to tryLock(Thread ID)
RLockReactive fail to unlock with RedissonShutdownException when un lock it at the end of the reactive sequence with doFinally() or with then() operators. When testing it with StepVerifier the unlock is complete sucessfully but fail with subscribe().
Example:
RLockReactive lock = reactiveClient.getLock("lock");
lock.tryLock(Thread.currentThread().getId())
				.flatMap(locked -> {
					if(locked)
						return Some Mono;
					else
						return Mono.error(new RuntimeException(""));
				})
				.flatMap(value -> {
					if(value != null && !value.isEmpty()){
						return Mono.just(do some json parsing);
					}

					else
						return Mono.error(new RuntimeException("!"));
				}).
				.flatMap(newValue -> {
					if(newValue!=null){
						//some processing to newValue
						return Mono.just(true);
					}
					return Mono.error(new RuntimeException(""));
				})
				.doFinally(s-> lock.unlock(Thread.currentThread().getId()).subscribe());
                               or .then(lock.unlock(Thread.currentThread().getId())
