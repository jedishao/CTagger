Use SNAPSHOT ISOLATION in SQL Server connector
This helps avoid read locks on the tabels being read. SQL Server's READ COMMITTED + SNAPSHOT ISOLATION is equivalent to ordinary READ COMMITTED in Oracle, PostgreSQL.

Also, since Presto doesn't read "transactionally", there is no advantage of increased isolation beyond single query consistency.
