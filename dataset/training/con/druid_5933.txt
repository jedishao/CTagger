Kafka indexing task gets stuck indefinitely on supervisor shutdown and when no data to ingest
When the supervisor is shut down, running index tasks sometimes complete and sometimes don't depending on whether any data was ingested or not.
Here are the steps to reproduce: _Task doesn't complete_

1. Start Kafka server
```
bin/kafka-server-start.sh config/server.properties
```
2. Turn on supervisor
```
curl -X POST -H 'Content-Type: application/json' -d @supervisor.json http://localhost:8090/druid/indexer/v1/supervisor
```
3. Add/check if the topic exists
```
bin/kafka-topics.sh --list --zookeeper localhost:2181
```
4. Check if indexing task is in "Running Tasks"
5. Shutdown supervisor using supervisor API

Observation:
- Supervisor shuts down and disappears, but the index task is still in "Running Tasks." 
- After waiting for hours (I waited for 6 hours), the task is still present
