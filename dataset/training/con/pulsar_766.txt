[Test-output](https://gist.github.com/rdhabalia/d65cb3765fcc214c729b09b25120fe77): shows that [IOUtilsTest.test5()](https://github.com/apache/incubator-pulsar/blob/master/pulsar-client-tools/src/test/java/org/apache/pulsar/admin/cli/utils/IOUtilsTest.java#L101) doesn't run as we don't see that test's output in the log.

So, we can see below behavior : 
1. Test case with I/O operation if it takes some more time then maven process thinks that forked thread is dead and doesn't fork the new thread and it marks build failed after all test-cases ran in that module.
2. After disabling this test-case, build has been passed.

This issue exist in maven-surfire pluging: 2.20
1. Issue1: https://issues.apache.org/jira/browse/SUREFIRE-1374
2. Issue2: https://issues.apache.org/jira/browse/SUREFIRE-1386

Therefore, we should upgrade [maven-surfire plugin](https://github.com/apache/incubator-pulsar/blob/master/pom.xml#L751) once, fix is available.
