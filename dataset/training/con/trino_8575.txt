Add a test analyzer to ensure single-threaded base test classes are extended correctly
Until we upgrade to TestNG 7.4 we should add a test analyzer to catch cases where a test class extends a base class with `singleThreaded = true`.

TestNG has a bug where the tests don't run single threaded unless the extending class has at-least 1 `@Test` method.
See https://github.com/trinodb/trino/pull/8568 for context.

Rel https://github.com/trinodb/trino/issues/8571
