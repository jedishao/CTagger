HttpClientResponse#end may throws an IllegalStateException when the response contains trailers
### Version

5.0.0

### Context

While testing HTTP Trailer's related work with a Vert.x HttpClient. In this test I need to check for the presence of trailers which come after the body is fully received. So I tried to wait for `response.end.await()` then to check the trailers.
But I found out my test was unstable: sometime calling `response.end()` threw an IllegalStateException because of [this piece of code](https://github.com/eclipse-vertx/vert.x/blame/e91dc2c77b0f811ace299f8848219f67aed741c5/vertx-core/src/main/java/io/vertx/core/http/impl/HttpClientResponseImpl.java#L144): 
```java
  @Override
  public synchronized Future<Void> end() {
    checkEnded();
    return eventHandler(true).end();
  }
// ...
  private void checkEnded() {
    if (trailers != null) {
      throw new IllegalStateException();
    }
  }
```

I don't really know why checkEnded checks for trailers neither why `end()` calls `checkEnded()` in the first place, but this causes issues when I call `response.end()`, if, for some reasons the response has already been 100% received.

My workaround is to set a `endHandler` early to be notified of the ending.

### Steps to reproduce

Here is a test that reproduces the error: 
```java
@Test
public void responseEndFailsWithIllegalStateException() throws InterruptedException {
    Vertx vertx = Vertx.vertx();
    vertx.createHttpServer()
         .requestHandler(req -> req.response()
                                   .setStatusCode(200)
                                   .putTrailer("myTrailer", "myValue")
                                   .end())
            .listen(8080)
            .await();
    HttpClientResponse receivedResponse = vertx.createHttpClient().request(GET, 8080, "localhost", "/")
                                                                  .compose(io.vertx.core.http.HttpClientRequest::send)
                                                                  .await();
    Thread.sleep(1000);
    receivedResponse.end(); // throws IllegalStateException.
}
```
