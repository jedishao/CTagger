[BUG] Openlineage plugin dataset naming does not follow standard naming - scheme missing
OpenLineage integration produces OpenLineage events with datasets' namespaces not following naming standards. OpenLineage [naming convention](https://openlineage.io/docs/spec/naming/) suggests trino datasets' namespace to follow: `trino://{host}:{port}`.

However, given a trino docker instance running under `trino://trino:8080/`, the integration creates namespace `trino:8080`, which is missing the scheme. Following the standard is crucial to have cross-platform consistent lineage dependency graph.
