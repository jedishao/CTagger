[docs] Create session properties page as counterpart for (Configuration) Properties reference
The existing doc pages [Properties Reference](https://prestodb.io/docs/current/admin/properties.html) and [Presto C++ Properties Reference](https://prestodb.io/docs/current/presto_cpp/properties.html) describe configuration (also referred to as system) properties, and then for some include a mention of the associated session property. 

For one example, the doc for [join-distribution-type](https://prestodb.io/docs/current/admin/properties.html#join-distribution-type) includes the statement "This can also be specified on a per-query basis using the join_distribution_type session property."

As part of the discussion in #23527 and #23541, I now believe the Presto doc would benefit from the creation of two new pages describing session properties for Presto and Presto C++.

## Expected Behavior or Use Case
New pages in the Presto documentation describing session properties for Presto and Presto C++. Use the existing topics and organization for each page. 

Note: The existing two pages are incomplete - not all configuration properties and not all session properties are documented. This issue is not intended to solve that problem. Let's improve the doc structure and then worry about filling the gaps in the doc. 

My thoughts on the new session property pages, and their relationship to the existing configuration property pages: 

* I think the existing configuration property pages should stay as they are. Specifically, the existing mention of a session property should not be deleted from the existing configuration property description. 
* Add a link from the existing mention of the session property to the new session property doc. 
* On the new page, create a heading for the session property. The description should link to the configuration property entry, but does not have to be more than that. The description could include a single line code block of an example that the reader could copy-paste, with an introduction sentence.
For example, the entry on the new page for the session property `join_distribution_type` doesn't have to be more than this : 

`join_distribution_type` 

  See [join-distribution-type](https://prestodb.io/docs/current/admin/properties.html#join-distribution-type).

  To set the value to `PARTITIONED`, use the following example:

  ``join_distribution_type = PARTITIONED``


 
* For the very rare edge case of a session property that does not have a corresponding configuration property, write the description in the new page. 


## Presto Component, Service, or Connector
Documentation.

## Possible Implementation
Copy the existing session property entries from [Properties Reference](https://prestodb.io/docs/current/admin/properties.html) and [Presto C++ Properties Reference](https://prestodb.io/docs/current/presto_cpp/properties.html) to create new pages, perhaps named Session Properties Reference and Presto C++ Session Properties Reference.
