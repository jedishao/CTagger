Support for new JDBC connector Teradata
<!--- Provide a general summary of the feature request or improvement in the Title above -->
<!--- Look through existing open and closed feature proposals to see if someone has asked for the feature before -->
Teradata Database is a relational database management system used to support large data warehousing operations. Implement support for the JDBC based Teradata connector in Presto by introducing a new module presto-teradata.

## Expected Behavior or Use Case
<!--- Tell us how it should work -->
Adding support to the Teradata connector allows querying and creating tables in an external Teradata database through Presto.

## Presto Component, Service, or Connector
<!--- Tell us to which service or component this request is related to -->
New connector
