[Iceberg] Add S3 Tables catalog support
[Amazon recently announced the S3 Tables feature](https://aws.amazon.com/blogs/aws/new-amazon-s3-tables-storage-optimized-for-analytics-workloads/), which is a type of S3 bucket which provides Iceberg table management features.  [S3 Tables has its own special catalog](https://github.com/awslabs/s3-tables-catalog), which means that in order for Presto to read and write to S3 tables, it must add support for the S3 Tables catalog.

## Expected Behavior or Use Case
There should be an S3 Tables catalog available to the Presto Iceberg connector.

## Presto Component, Service, or Connector
Iceberg connector

## Possible Implementation
[Import this library](https://github.com/awslabs/s3-tables-catalog), and add it as a catalog type in Presto.

## Context
S3 Tables provide a convenient managed table service.  It would be nice for Presto to connect to it so it is an option for those who want to try out this service.
