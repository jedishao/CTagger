Empty Host Header still not supported
### Version

4.4.6

### Context

Empty host header not supported still in 4.4.6, but should be already fixed.
see https://github.com/eclipse-vertx/vert.x/issues/4879

### Reproducer

curl -iv -H "User-Agent:" -H "Accept:" -H "Host:" http://localhost:8080
Fails with 500 and an NullPointerException in log.
