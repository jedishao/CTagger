LLAP: cleanup local folders on startup and periodically
When LLAP daemon crashes, there might be leftovers in the hive llap local dirs, which are good candidates to be cleaned up on startup/regularly. Under normal circumstances, these are cleaned up, however, as the LLAP damons is responsible for that, it cannot help in the event of a crash, so it would make sense to make it able to clean up old files.
