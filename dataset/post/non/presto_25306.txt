Issue while accessing Symlink Tables on S3
<!--- Provide a general summary of the issue in the Title above -->
<!--- Look through existing open and closed issues to see if someone has reported the issue before -->
Introduction of WrapperJobConf and CopyOnFirstWriteConfiguration lead to issues while accessing Symlink tables since the actual configuration object is wrapped inside a configuration object

https://github.com/prestodb/presto/blob/786324b5aa8a4dfcd7165034ba8a2ea342d1afb0/presto-hive/src/main/java/com/facebook/presto/hive/StoragePartitionLoader.java#L186-L187

`targetFilesystem.getConf()` is of type `WrapperJobConf`/`CopyOnFirstWriteConfiguration` due to which Hadoop Library is not able to copy the actual Configuration Object.

## Your Environment
<!--- Include as many relevant details about the environment you experienced the bug in -->
* Presto version used: 0.294-SNAPSHOT
* Storage (HDFS/S3/GCS..): S3
* Data source and connector used: Hive
* Deployment (Cloud or On-prem): Cloud

## Expected Behavior
<!--- Tell us what should happen -->
S3 should be accessible work out of the box
