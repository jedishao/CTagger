camel-sql - Make it easier to use Map values for non-named SQL statements
When you have a Map then you usually want to use named SQL statements to lookup the value via the parameter name as a key. But sometimes you have a LinkedHashMap and then the order of the values are as added to the map, and then you can use the values without key lookup in SQL statements.
