Output the database name for SHOW EXTENDED TABLES statement
HIVE-21301 introduced {{SHOW EXTENDED TABLES}} statement which output table name and table type while listing tables in a database.

In this patch, we aim to add a new output filed for database name with following reasons:
1. database name in {{SHOW EXTENDED TABLES}} statement is optional, output the database is informal in this case.
2. when statistic table names and database names by this statement for list of databases, the output result including database name is much more helpful.
