## Steps to Reproduce

<!--- reproduce this bug. Include code to reproduce, if relevant -->
1. Create a table with a varchar column with non-ASCII characters in the rows, such as Cyrillic characters. 
2. Use Presto CLI to select one of these records containing these characters in the terminal.
3. To view the intended result, use something like ./presto-cli <args> --output-format <JSON|CSV|TSV> --execute <SQL> > output.<json|csv|tsv>
