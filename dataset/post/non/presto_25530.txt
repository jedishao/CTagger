Check column data type during construct Iceberg IDENTITY column transform object
<!--- Provide a general summary of the issue in the Title above -->
<!--- Look through existing open and closed issues to see if someone has reported the issue before -->

Currently in Presto Java Iceberg connector, when define a identity transform on a column, the column type is not checked, and the actual check is after the transform been applied.
The check is inside function 
`getIcebergValue`

It would be better to move the check into this function

`PartitionTransforms::getColumnTransform`

This can also align with other transform types.
