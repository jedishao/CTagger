S3Location should remove double slashes from `path`
`S3Location` doesn't remove double slashes from paths while HDFS `Path` and NIO `Path` do. This causes issues when Iceberg metastore returns path to table location with double-slashes. In native FS metadata file will be stored on S3 with double slashes (which is valid location), but it won't be possible to read it via legacy FS. For compatibility purposes `S3Location` should remove double slashes.
