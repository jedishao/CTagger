Can't use language as parameter in a Kamelet
When I use setBody in a Kamelet like this:


{code:java}
- setBody:
              language:
                language: "groovy" # Hardcoded language
                expression: "{{content}}"{code}

I get a proper response. However, because the language is user-defined I tried to set a parameter dynamically:


{code:java}
          - setBody:
              language:
                language: "{{language}}" # Attempting to use a dynamic parameter
                expression: "{{content}}" {code}
Though language is a String, it seems not allowed, because the parameter isn't interpolated like for example expression, so I get:


{code:java}
"Failed to create route setbody-test at: >>> SetBody[{{language}}{{{content}}}] <<< in route: Route(bodytest3-2)[From[{{in}}] -> [SetBody[{{language}}{{{c... because of No language could be found for: {{language}}"  {code}
I try to avoid workarounds like multiple Kamelets for each language, or have a choice with multiple languages in it.

Note that this issue occurs in other EIP's like split, filter, setHeaders as well. I just took setBody as example.
