camel-jbang - Add command to easily upgrade or downgrade the CLI version
Installing camel jbang CLI is done the standard jbang way, but then you get the lastest release, and jbang has this auto-update checker that calls the internet which you may not want. We should have some camel command that can upgrade or dowgrade the CLI. Then users can be in more control and only use one CLI tool (not need to learn jbang first).
