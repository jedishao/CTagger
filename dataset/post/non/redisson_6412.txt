Redis RemoteExecutorService "expiration" sorted set growing undefinitely
### Redis version

7.9.225

### Redisson version

3.43.0

### Redisson configuration

Single server

### What is the Expected behavior?

Redis RemoteExecutorService "expiration" sorted set task entries get removed as soon as task terminates 

### What is the Actual behavior?

Looking at Redis RemoteExecutorService keys, "expiration" sorted set is growing undefinitely with entries from correctly executed and terminated tasks. 

### Additional information

The key is accessible on Redis at "executor service name:org.redisson.executor.RemoteExecutorService:expiration"
This issue is turning in ever growing memory consumption on Redis, maybe also deteriorating performances when accessing the key?
