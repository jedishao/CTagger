[SUPPORT] Support setting the maximum number of partitions for a table
Many companies have Hive tables with tens or even hundreds of thousands of partitions. This is because data warehouse developers do not understand the use of partitions. If the number of partitions can be limited, irregular use can be better restricted.

Similar to hive, Alibaba Cloud odps supports some constraints to better ensure cluster stability:
[https://www.alibabacloud.com/help/en/maxcompute/product-overview/limits-4#section-7mi-eex-be0]
