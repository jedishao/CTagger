camel-http - Also set HTTP_RESPONSE_CODE and HTTP_RESPONSE_TEXT when throw exception on failure
[https://camel.zulipchat.com/#narrow/channel/257298-camel/topic/camel-http.3A.20okStatusCodeRange]

When we have a response in the http producer then we should set the response code and reason phrase if possible as camel headers so they are always there, even if we have throw exception on failure.

Those would be set anyway if the response is success
