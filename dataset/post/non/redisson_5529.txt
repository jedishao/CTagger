**Expected behavior**
The `RETURN` clause in RedissonSearch should correctly handle the specified number of tokens and return the attributes as expected.

**Actual behavior**
When using the `RETURN` clause with a specified number of tokens, the behavior is inconsistent. It seems that the number of tokens is not being interpreted correctly, leading to unexpected results.

**Steps to reproduce or test case**
1. Use the following `RedissonSearch` code snippet:
```
   if (!options.getReturnAttributes().isEmpty()) {
       args.add("RETURN");
       args.add(options.getReturnAttributes().size());
       for (ReturnAttribute attr : options.getReturnAttributes()) {
           args.add(attr.getIdentifier());
           if (attr.getProperty() != null) {
               args.add("AS");
               args.add(attr.getProperty());
           }
       }
   }
```

**Redis version**
7.2.3

**RediSearch version**
3.8.9

**Redisson version**
4.25.2
