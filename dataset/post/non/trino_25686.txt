Trino Ranger plugin does not support basic authenticated Solr

We use Trino Ranger plugin to control access to Trino and collect access audit logs which is then stored by a Solr service.  The Solr service is setup with [basic authentication](https://solr.apache.org/guide/solr/latest/deployment-guide/basic-authentication-plugin.html#enable-basic-authentication). 

To allow Trino Ranger plugin to send authenticated requests to Solr, we have setup preemptive authentication to Solr by setting a global JVM param following this [guide](https://solr.apache.org/guide/solr/latest/deployment-guide/basic-authentication-plugin.html#global-jvm-basic-auth-credentials). This fails with the following stack trace

After some investigation, we found out the issue was due to conflicting jetty dependencies version between Ranger and Trino. Latest version of Ranger requires v9 of jetty client and Trino is using v12, and there are some breaking changes between the 2.  

- Plugin version: 471
- Ranger version: 2.5.0
- Solr version: 8.11.3
