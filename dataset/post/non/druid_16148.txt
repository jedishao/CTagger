Druid prometheus-emitter does not emit all the metrics
Druid [prometheus-emitter](https://druid.apache.org/docs/latest/development/extensions-contrib/prometheus/) does not emit all the metrics.

### Affected Version
`28.0.1`

### Description
I was trying to emit metrics from druid cluster deployed in k8s using druid `prometheus-emitter` extension. But there are many metrics provided here ([druid-metrics](https://druid.apache.org/docs/latest/operations/metrics/)) which are not available in the metrics emitted by the extension. I am providing two basic metrics, but there are many which I was not able to find:
- [Service Health](https://druid.apache.org/docs/latest/operations/metrics/#service-health)
- [zk-connected](https://druid.apache.org/docs/latest/operations/metrics/#zookeeper)

- FYI, I added the necessary [monitors](https://druid.apache.org/docs/latest/configuration/#metrics-monitors) for the metrics, I was trying to get.
