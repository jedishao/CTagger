Maven build failure for Camel JBang exported Quarkus app
When Camel JBang exports code to a Quarkus Maven application the resulting build fails with: 
{noformat}
SRCFG00014: The config property quarkus.camel.openapi.codegen.model-package is required but it could not be found in any config source{noformat}
The code exported is Sample.java:
{noformat}
import org.apache.camel.builder.RouteBuilder;


public class Sample extends RouteBuilder {
  @Override
  public void configure() throws Exception {
          from("timer:tick")
        .log("Hello Camel!");
  }
}{noformat}
The Camel JBang command used to export:
{noformat}
camel export Sample.java --runtime=quarkus --gav=org.apache.camel:sample:1.0-SNAPSHOT --dir sample{noformat}
Camel version: 4.7.0-SNAPSHOT
