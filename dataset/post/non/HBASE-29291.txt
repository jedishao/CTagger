Add a command to refresh/sync hbase:meta table
The objective of this *refresh_meta* command is to synchronize the *_hbase:meta_* table with the actual state of regions in the backing storage. 
More details about this command can be found in the [design doc. |https://docs.google.com/document/d/1EI0lsURX1BZhv3DYgMvZCl4EUy-ADJRkHUc1PjzZtj0/edit?tab=t.0#heading=h.kfyf5z4njcjr]
