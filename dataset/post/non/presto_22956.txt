Project all fields from the probe side (for inner joins) when possible
I see queries copying (one of the) join keys from the build side like:

select T2.x from T1 JOIN T2 on T1.x = T2.x

And we faithfully copy it - note that this will need probably adding a column to the page (from the probe side). So not very good. we should replace T2.x with T1.x in the optimizer.
