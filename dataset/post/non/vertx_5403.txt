Vert.x event bus - Unix Domain Socket Event Bridge Support Option - Which helps processes communicate within the same K8s container using event bus
The event bus in vert.x is extensible within the same unix k8s container using TCP.
The issue with TCP is that it has to go through an entire stack and when two processes are communicating within the same container that are polyglot like Python and Vertx itself over the event bus, tcp becomes a performance bottleneck.

Hence request that a Unix domain socket option be given for the event bus of vertx so that the performance between processes using the event bus within the same container is maximized trememdously.

This will make it more cloud friendly, the trend today
