## Context

presto code is not directly dependent on "/tmp" directory , but the JVM is dependent on "/tmp" directory , and JVM is creating 

"ELF 64-bit LSB shared object, x86-64, version 1 (SYSV), dynamically linked, with debug_info, not stripped"  files.
In order to mitigate this problem , one solution is to use "-Djava.io.tmpdir" config in jvm.config , which helps us in configuring custom tmp directory.
