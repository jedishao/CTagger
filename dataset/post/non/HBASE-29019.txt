Provide HBase Docker Image for Integration Testing on Docker Hub or Github Packages
* I noticed that documents like [https://hbase.apache.org/book.html#_get_started_with_hbase] require batch shell commands to initialize the HBase environment.
 *  It would be nice if HBase could provide a runtime Docker image on Docker Hub or Github Packages. This would help writing unit tests for third-party libraries like *testcontainers-java* .

 - Some early investigation came from https://issues.apache.org/jira/browse/PHOENIX-6912 and https://issues.apache.org/jira/browse/PHOENIX-6919 .
