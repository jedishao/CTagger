Iceberg Glue using maintenance mode AWS SDK for Java 1.x
When enabling iceberg connector with glue catalog there is an AWS SDK for Java 1.x end of support message printed in the coordinator log. Are there any plans for lifting the iceberg glue catalog to the latest glue API?

We are also having problems with using web identity token credentials in EKS due to this. Hence this other reported issue may be prematurely closed:
https://github.com/trinodb/trino/issues/25135

Config:
```
  iceberg: |
    connector.name=iceberg
    iceberg.catalog.type=glue
```
