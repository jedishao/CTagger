Issue with Injected Projection Type on Trino Table Based on Hive Connector
## Issue with Injected Projection Type on Trino Table Based on Hive Connector

### Table Creation

I've created a Trino table with injected projection type based on the Hive connector using the following DDL:

```sql
CREATE TABLE hive.default.injected_table_issue (
    id varchar,
    department varchar WITH (partition_projection_type = 'INJECTED')
)
WITH (
    external_location = 's3://bucket/v1/injected_table_issue',
    format = 'PARQUET',
    partition_projection_enabled = true,
    partition_projection_location_template = 's3a://bucket/v1/injected_table_issue/${department}',
    partitioned_by = ARRAY['department']
);
```

### Issue

When attempting to run any query, it fails with the following error message:

```sql
select * from hive.default.injected_table_issue where department = 'any_dept';
```

```
Query 20240806_112351_00004_zpw6c failed: Column projection for column 'department' failed. Injected projection requires single predicate for its column in where clause.
```

However, using `DevelopmentServer` allows me to query without any exceptions.
