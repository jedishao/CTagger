grpc-java is not compatible with the latest Netty version 4.1.101.Final
<!-- Please answer these questions before submitting a bug report. -->

### What version of gRPC-Java are you using?

v1.59.0, all previous versions have the same issue.

### What is your environment?
macOS, but doesn't matter for this issue

### Steps to reproduce the bug

1. Bump Netty version to 4.1.101.Final.
2. Execute any test that sends a request and receives a response with trailers.

### Additional details

The changeset [#13603](https://github.com/netty/netty/pull/13603) uses [headers.isEmpty()](https://github.com/netty/netty/blob/285ba74f899866ddf3e23a6770c954e350245bd7/codec-http2/src/main/java/io/netty/handler/codec/http2/DefaultHttp2ConnectionDecoder.java#L419) method. gprc-java has its custom implementation of Netty's Http2Headers interface, where they implement only [size()](https://github.com/grpc/grpc-java/blob/0346b40e4e19e081e082288fc8af49169dd848ad/netty/src/main/java/io/grpc/netty/GrpcHttp2HeadersUtils.java#L289-L292) but not isEmpty() method. Its parent `AbstractHttp2Headers` implements this method as throwing `UnsupportedOperationException`.
