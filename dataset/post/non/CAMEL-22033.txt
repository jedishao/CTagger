camel-salesforce - For the Pub/Sub API, add the original ConsumerEvent as an exchange property
Each salesforce event is shipped with a unique identifier in the id field. Unfortunately, this id is not accessible within the camel API.

Pub Sub API gets replay id, but not other identifying fields: [https://github.com/apache/camel/blob/camel-4.4.1/components/camel-salesforce/camel-salesforce-component/src/main/java/org/apache/camel/component/salesforce/internal/client/PubSubApiClient.java]

Ideally, either the message id, or the entire consumer event could be placed into an exchange property for use by consuming camel routes.
