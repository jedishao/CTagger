Not able to set literal arguments for sketch functions processing subquery results
Sketch aggregator creation fails; because the argument doesn't [look like a literal](https://github.com/apache/druid/blob/895e53555cf69cce992ee54d8523624fe1150214/extensions-core/datasketches/src/main/java/org/apache/druid/query/aggregation/datasketches/hll/sql/HllSketchBaseSqlAggregator.java#L90)

queries like `DS_HLL(dim2, 18)` may fail; however `DS_HLL(dim2)` could still be used (but it will use defaults)

### Affected Version

current master for sure...possibly introduced earlier; will update the ticket
