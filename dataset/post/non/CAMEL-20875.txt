Trigger component-test automatically on PR jobs
Currently there is the possibility to trigger component test by providing a comment on a PR with /component-test.
it would be convenient to start the test automatically.
Maybe easier starting with Dependabot as there is the name of the updated dependency in the message.
Not necessarily easy to kno all of the component directly impacted. Currently what I'm doing manually is:
- pick the artifact id of modified dependency
- do a search on language Maven pom, for instance https://github.com/search?q=repo%3Aapache%2Fcamel+huaweicloud-sdk-core+language%3A%22Maven+POM%22&type=code
- look for components affected
- provide the comment

Maybe as a first iteration, providing a link in the generated comment message to the search URL can help to save few clicks
