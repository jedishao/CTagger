Create a jenkins job for Camel JBang IT test suite
The [Camel JBang IT|https://github.com/apache/camel/tree/main/dsl/camel-jbang/camel-jbang-it] test suite is slow to execute, therefore, by default the test execution is disabled. Having a daily Jenkins job for the supported branches that execute only this test suite would be nice.

The idea is the following:
* main - tests the latest SNAPSHOT
* 4.x branches, test the latest released 4.x camel jbang version (not the SNAPSHOT), ex. camel-4.8.x will be tested via camel jbang 4.8.3 (latest 4.8.x camel jbang release at this time)
