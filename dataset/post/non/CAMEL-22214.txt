camel-groovy - Allow to pre-load groovy source files for shared functions and DTOs
We can call groovy from the DSL as an expression language.

But you may want to have small functions and DTO classes and whatnot as part of reusable in the classpath. 

So we should look at have some kind of camel.language.groovy.preload=foo.groovy,shared/*.groovy

where you can use file globs to refer which files should be loaded and compiled on startup and added to the classpath.

This is valuable for low-code and camel-jbang style of work.
