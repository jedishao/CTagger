BigQuery Connector - tables with upperCase letter are not listed in information_schema.columns
Hi people, 

We have this query:

```
"SELECT table_schema, table_name, column_name, ordinal_position, is_nullable, data_type
FROM \"catalog_name\".information_schema.columns
WHERE table_catalog='catalog_name'
AND table_schema <> 'information_schema'
ORDER BY table_schema, table_name, ordinal_position, column_name"
```

It returns only tables with a table name which only has lowercase letters. A table with an uppercase letter is not returned.

Steps to reproduce

1. Create bigquery instance in gcp
2. Create table with an uppercase letter
3. Optional: Create a column and add an entry

Anyone else had this issue?
