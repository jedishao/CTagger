Oracle not using BaseJdbcConfigs for user and password
<!--- Provide a general summary of the issue in the Title above -->

Oracle is not using user and password configs from BaseJdbcConfigs. Currently, we are connecting to Oracle by appending the username and password in the connection URL. 



## Expected Behavior

User and password config from the BaseJdbc config can be used like below. But it is not working now.

```
connector.name=oracle
connection-url=jdbc:oracle:thin:@(DESCRIPTION=(ADDRESS=(PROTOCOL=<tcp>)(HOST=<host>)(PORT=<port>))(CONNECT_DATA=(SID=<sid>)))
connection-user=<user>
connection-password=<password>
```


## Current Behavior

We need to add the user and password in the connection URL even though we have the configs in the BaseJdbc.

`jdbc:oracle:thin:<username>/<password>@//<host>:<port>/<SID/SERVICE_NAME>`

## Possible Solution

It is possible to do a minimal code change to use these configs.
