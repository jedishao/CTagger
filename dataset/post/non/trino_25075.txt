Trino Trying to Enable Spooling Protocol
Trino version: 467
emr version 7.7.0

Hello,

I am trying to set up the spooling protocol on my EMR cluster with Trino. My intention is to attempt to write out the results or a query from worker nodes directly into an S3 bucket. I have added the following 2 lines to my config.properties file
```
protocol.spooling.enabled=true
protocol.spooling.shared-secret-key=_key_
```
And I have created a spooling-manager.properties file in /etc/spooling-manager.properties, as mentioned in the [docs](https://trino.io/docs/current/client/client-protocol.html#protocol-spooling). However, when I run 
```
sudo tail -f /var/log/trino/server.log
```
I see the error
```
Spooling protocol is enabled, but manager configuration file does not exist: etc/spooling-manager.properties. 
```

I also tried moving the spooling-manager.properties file to /etc/trino/conf/ since this is where all the catalog properties and node properties are, but I get the same error doing that.

Any advice on how to get around this issue?
