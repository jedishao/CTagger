JSF ViewState problem with Redisson Tomcat Session Manager
### Redis version

5.0.3 Standalone

### Redisson version

3.30.0

### Redisson configuration

[redisson.yaml.txt](https://github.com/redisson/redisson/files/15470262/redisson.yaml.txt)
[context.xml.txt](https://github.com/redisson/redisson/files/15470270/context.xml.txt)

### What is the Expected behavior?

**Environment**
- TomEE Plume 9.1.3 (https://tomee.apache.org/comparison.html)
- Redisson 3.30 (redisson-tomcat-10-3.30.0.jar, redisson-all-3.30.0.jar)
- Redis Standalone 5.0.3
- Session Manager configured in conf/context.xml (see attached)
- Jakarta Faces (JSF) Application

**Description**
I have a running JSF application on a TomEE 9.1.3. When I replace the TomEE Session Manager with the Redisson Session Manager with ‘readMode=’REDIS‘’, the application stops working. I was able to narrow down the problem to the JSF ViewState. I always get a ‘jakarta.faces.application.ViewExpiredException’. Apparently the saving of the ViewState does not work with the Redisson Session Manager. By changing the ‘jakarta.faces.STATE_SAVING_METHOD’ to ‘client’ I can work around the problem, this is not a solution for security reasons among others.

### What is the Actual behavior?

jakarta.faces.application.ViewExpiredException (see description)
