Insert clause allows invalid arithmetic expressions between values
## Description
Multiple + and - operands are allowed in the insert clause statement.

## To Reproduce


1. Create a test table
```
CREATE TABLE trino_test.trino_insert_test (
    id INTEGER,
    name VARCHAR,
    value DOUBLE
);

```
2. Insert data into it but add multiple - and + in it. 

```
INSERT INTO trino_test.trino_insert_test (id, name, value) VALUES (1, 'Five Number', - + - + - + - - - - - 5);

INSERT INTO trino_test.trino_insert_test (id, name, value) VALUES (2, 'Six Number', - + + + + - + - - 6 / + + 6 + + - 6 * + + 6);

INSERT INTO trino_test.trino_insert_test (id, name, value) VALUES (3, 'Seven Number', 7 - + - + - + - - - - - 7);
```
