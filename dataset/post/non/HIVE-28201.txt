LLAP perf counter: all nodes, used nodes
The proposal is to introduce counters as below:
LLAP_NODES_COUNT_ALL: number of LLAP nodes visible for the task communicator
LLAP_NODES_COUNT_TASK_ASSIGNED: number of LLAP nodes where a task attempt was assigned to

I'm assuming here that 1 node == 1 daemon, so the counter can be referred to as number of daemons
