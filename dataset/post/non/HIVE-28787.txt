Improve/optimize Delete failed txns Sql 
The current cleanEmptyAbortedTxn() query
{code:java}
DELETE FROM "TXNS" WHERE "TXN_ID" NOT IN (SELECT "TC_TXNID" FROM "TXN_COMPONENTS") AND "TXN_STATE" = 'a';{code}
is inefficient especially in PostgreSQL, leading to very high execution times when entries get piled up.

Can we re-write this query using LEFT JOIN or WHERE EXISTS for better performance?
{code:java}
DELETE FROM "TXNS"
WHERE NOT EXISTS (
    SELECT 1 FROM "TXN_COMPONENTS" 
    WHERE "TXN_COMPONENTS"."TC_TXNID" = "TXNS"."TXN_ID"
)
AND "TXN_STATE" = 'a'; {code}
