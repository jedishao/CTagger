Redisson selects wrong codec for a batch command result?
### Redis version

valkey 7.3

### Redisson version

3.45.1

### Redisson configuration

Redisson client configuration:
```java
 new Config().useClusterServers().setReadMode(ReadMode.MASTER)
                    .addNodeAddress(redisAddress)
                    .setMasterConnectionPoolSize(1)
                    .setMasterConnectionMinimumIdleSize(1)
                    .setSlaveConnectionPoolSize(1)
                    .setSlaveConnectionMinimumIdleSize(1);
```

We're submitting batches to Redis (size=512) along with some long value updates and this is part of the batch:
```java
RBatch batch = redisClient.createBatch(BatchOptions.defaults()
            .executionMode(BatchOptions.ExecutionMode.REDIS_WRITE_ATOMIC)
            .retryAttempts(100)
            .responseTimeout(5, TimeUnit.SECONDS)
            .retryInterval(1, TimeUnit.SECONDS));
...
RMapAsync<String, String> map = batch.getMap("someKey", StringCodec.INSTANCE);
map.replaceAsync(objectUpdate.getKey, objectUpdate.getJson());
```
This is the json we're trying to replace:
```java
"{"id":4,"name":"USDT",...}"
```

Successful execution
