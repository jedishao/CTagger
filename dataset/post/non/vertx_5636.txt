Vert.x Config and Vertx OpenTelemetry
Currently there is no way to use Vert.x Config to integrate Vertx OpenTelemetry into an application. 
To integrate Vertx OpenTelemetry you need to provide OpenTelemetryOptions in VertxOptions

`        Vertx vertx = Vertx.vertx(new VertxOptions()
                .setTracingOptions(new OpenTelemetryOptions(otel)));
`

and to create OpenTelemetryOptions you need to provide an endpoint 

`
    OtlpGrpcSpanExporter exporter = OtlpGrpcSpanExporter.builder()
      .setEndpoint("http://localhost:4317")
      .build();
`

this end point can't be retrieved from  Vert.x Config.

To create ConfigRetriever you need an existing vertx object

`
ConfigRetriever retriever = ConfigRetriever.create(vertx, options);
`

To create a config retriever you need a vertx object, and to create a vertx object you need opentelementry options, so there is no way to use Vert.x Config for Vertx OpenTelemetry.
