[Native] - Range window frame query (for double range with int order column) fails on native but passes on Java 
<!--- Provide a general summary of the issue in the Title above -->
<!--- Look through existing open and closed issues to see if someone has reported the issue before -->

Query comprising of sliding window frame with range (with decimal values as offset) fails against native worker when an integer type column was used in the over clause. This query passes on the Java worker.

## Expected Behavior
<!--- Tell us what should happen -->
```
Following is the query and its expected output against the native worker:
        assertQuery("SELECT array_agg(a) OVER(ORDER BY a RANGE BETWEEN 0.5 FOLLOWING AND 1.5 FOLLOWING) " +
                        "FROM (VALUES 1, 2, 4) T(a)",
                "VALUES " +
                        "ARRAY[2], " +
                        "null, " +
                        "null");

```

## Current Behavior
<!--- Tell us what happens instead of the expected behavior -->
```
But the query fails with the following error against the native worker:
```
