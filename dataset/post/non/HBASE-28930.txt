Clean up explicit depency versions in poms
Unless there is some specific reason, all dependency versions should be set in DependencyManage sections.

Right now we at least some Hadoop dependencies where the versions are redundantly set directly in the Dependency entries.

We should also consistently set hadoop.version from the hadoop3 profiles in the modules that have them. (I think that those aren't relevant in branch-3+, but we should either set them consistently, or just remove them outside branch-2.x)
