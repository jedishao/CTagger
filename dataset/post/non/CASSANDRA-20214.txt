The short -p option for the copyData arg in the Import node tool command conflicts with the --port option
In the Import nodetool command:
{code}
    @Option(title = "copy_data",
            name = {"-p", "--copy-data"},
            description = "Copy data from source directories instead of moving them")
    private boolean copyData = false;
{code}

on the other hand, the command has another option:
{code}
        @Option(type = OptionType.GLOBAL, name = {"-p", "--port"}, description = "Remote jmx agent port number")
        private String port = "7199";
{code}

If the -p option is set from the command line for the nodetool, it fails at the CLI parsing stage because it can't tell which option to use. Suggestion: rename the short name for the option copyData since it's not used by users and fails.
