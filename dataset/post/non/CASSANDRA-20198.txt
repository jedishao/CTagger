AST library for CQL-based fuzz tests
An AST library has already been introduced in the {{cep-15-accord}} branch to help with fuzzing Accord. However, it has begun to show its usefulness in tracking down non-Accord issues, and we need to port it back to trunk. It has also become a dependency for the the newer generation of Harry tests in the Accord branch, which also need to be ported to trunk to fully test issues like CASSANDRA-20189.
