Expand specification and contract test coverage for InputStream reads.
This issue is a spin-off from HADOOP-19389, specifically [this code review discussion|https://github.com/apache/hadoop/pull/7291#discussion_r1920495312]. We can enhance the FS specification and contract tests to cover expected semantics of the {{InputStream}} single-byte and multi-byte read methods:

* Multi-byte read should validate the arguments passed to it, according to the pattern established in the JDK base {{InputStream}} class.
* You should get the same bytes whether going through single-byte or multi-byte read.
* It is legal to mix calls to single-byte and multi-byte read, and this should also yield the same bytes.
