Aged cel-spec dependency blocks googleapis upgrade
`googleapis` in bazel-central-registry fails hard when we try to use the `switched_rules` extension: https://github.com/bazelbuild/bazel-central-registry/blob/main/modules/googleapis/0.0.0-20241220-5e258e33/overlay/extensions.bzl#L19

`cel-spec` at HEAD still uses `switched_rules`: https://github.com/google/cel-spec/blob/master/MODULE.bazel#L53

`grpc-java` uses an older version of `cel-spec` but states that it may be removed in future: https://github.com/grpc/grpc-java/blob/master/MODULE.bazel#L54

If we attempt to upgrade `googleapis` then we hit this hard fail. Is there a way to remove this dependency so we don't have to pin back `googleapis`?

Perhaps the ask should be with `cel-spec` but there would still need to be a `grpc-java` upgrade to incorporate any changes.
