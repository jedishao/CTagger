Refactor chaos monkey related code to a new module hbase-chaos
As part of this Jira we will create a new module named {{hbase-chaos}} and optionally include it in the assembly. This change is necessary because we will be removing all test jars from our assembly (with HBASE-28433), resulting in the removal of chaos monkey and all its code, which may need to be manually copied by operators. Currently, all the code resides in {{{}hbase-it{}}}.

This fix will provide an option to build hbase such that we can bundle hbase-chaos in assembly, albeit we wont do this by default.
