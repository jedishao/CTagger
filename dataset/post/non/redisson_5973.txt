Connection RST causes "Command execution timeout for command: (CLUSTER NODES)"
### Redis version

7.1

### Redisson version

3.29.0

### Redisson configuration

```
Config config = new Config();
        config.useClusterServers()
                .addNodeAddress(
                        "rediss://MY-REDIS:6379")
                .setConnectTimeout(500)
                .setTimeout(5000)
                .setRetryAttempts(3)
                .setRetryInterval(200);
```

### What is the Expected behavior?

If a connection is terminated and the client is able to immediately reconnect, its expected that the `cluster nodes` command would not timeout but be retried instead. 

### What is the Actual behavior?

A timeout exception is thrown. This seems to depend on timing leading to the assumption that this might be related to dropping the connection with an in-flight request.
