Add support for correlated scalar subqueries in lambda expressions
There is a common pattern in data loading for AI training. There are 2 tables: base and lookup. Values in base table refer to rows in lookup table using foreign key or a prefix of a foreign key. Typically, a row in a base table contains an array of keys. For each row in a base table, for each value in array of keys, the query needs to lookup rows in "lookup" table, aggregate these into a single value (using something like array_agg) and replace the key with the aggregated data (effectively hydrating or fattening the base row).

For example, the base table:

```
presto:di> with t as (select * from unnest(array[array[1, 3, 5], array[2, 4]]) as t(keys))
        -> select * from t;
   keys
-----------
 [1, 3, 5]
 [2, 4]
(2 rows)
```

Lookup table:

```
presto:di> with u as (select * from unnest(array[1, 2, 2, 3, 4, 5, 5], array[11, 22, 23, 33, 44, 55, 56]) as t(key, data))
        -> select * from u;
 key | data
-----+------
   1 |   11
   2 |   22
   2 |   23
   3 |   33
   4 |   44
   5 |   55
   5 |   56
(7 rows)
```

The query: 

```
presto:di> with t as (select * from unnest(array[array[1, 3, 5], array[2, 4]]) as t(keys)),
        -> u as (select * from unnest(array[1, 2, 2, 3, 4, 5, 5], array[11, 22, 23, 33, 44, 55, 56]) as t(key, data))
        -> select *, transform(keys, k -> (select array_agg(u.data) from u where u.key = k)) from t
        -> ;
Query 20250624_074445_31840_gd2hf failed: line 3:32: Lambda expression cannot contain subqueries
```

This query naturally combines transform lambda function with a subquery. While Presto supports lambda functions and subqueries separately, it doesn't support these used together.

The above query can be supported if the optimizer is enhanced to flatten it using AssignUniqueId, Unnest, Join and Streaming Aggregation. The plan would look something like this:

```
- StreamingAgg(row_id): array_agg(a)
  - StreamingAgg(unnested_row_id): a := array_agg(u.data)
    - LeftJoin(t.key = u.key)
      - AssignUniqueId(unnested_row_id)
        - Unnest(keys) -> key
          - AssignUniqueId(row_id)
            - Scan(t)
      - Scan(u) 
```
