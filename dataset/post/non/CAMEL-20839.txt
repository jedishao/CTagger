camel-jbang - Run with openapi in sub folder does not work
To reproduce the issue use this example: [https://github.com/apache/camel-kamelets-examples/tree/main/jbang/open-api] and move greetings-api.json to a subfolder 'apis'. Then run 'camel run --open-api apis/greetings-api.json Greetings.java' and it throws: "The given OpenApi specification cannot be loaded from: greetings-api.json ... Cannot invoke "[java.net|http://java.net/].URI.toString()" because the return value of "org.apache.camel.spi.Resource.getURI()" is null" . It doesn't work even if I use quotes "apis/greetings-api.json"
