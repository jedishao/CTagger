Include arbitrary metadata to the camel-catalog
It would be nice to include some additional and arbitrary metadata in the camel-catalog, as example, for components:

{code:json}
{ 
    "component": { 
        "metadata": {
            "camel.apache.org/capabilities": "tracing,metrics"
        } 
}
{code}

This would helps tools to gather some additional information about the various element of the catalog as well as generating custom catalog with additional information needed by 3rd party tools.
