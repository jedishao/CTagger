Add support for multi region splits in Catalog Janitor
This is to add the API to support multi region splitting - HBASE-28438

Catalog janitor checks ongoing region splits  and compactions on the daughter regions completed or not by looking at the reference files present in the daughter region directories to delete the parent region from meta.


All the APIs used by catalog janitor check only two daughter regions and reference files of those two daughter regions which need to be changed to support multi region split feature - HBASE-28438.
