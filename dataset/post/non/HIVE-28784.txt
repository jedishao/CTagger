Ensure Hive constructs URI's with IPv6 literals safely. 
There are a lot of code locations where hive constructs URLs by concatenating host + port in a way that is not safe with IPv6 stack.

Examples:
{code:java}
url = "jdbc:hive2://" + host + ":" + port + "/default;principal=" + serverPrincipal;{code}
{code:java}
conf.set(HiveConf.ConfVars.METASTORE_URIS.varname, "thrift://localhost:" + port);{code}
