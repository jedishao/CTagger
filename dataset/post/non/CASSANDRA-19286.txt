Accord: Safe guards against erroneously marking replicas stale
Replicas are marked stale using inferences made when data cannot be obtained from peers. However, if a replica is marked stale erroneously it could cause an outage; any systemic issue in this system could be severe. We should harden this system against potential errors, and offer the option of only marking replicas stale that have been marked as stale by an operator (and otherwise reporting an error to the user).
