CopyTable to accept custom cf/qualifier for timestamp range filtering
Currently CopyTable starttime/endtime param filters on HBase's built-in timestamp.

Add the following options to support filtering based on the value of custom timestamp column.
{noformat}
 ts.cf        column family for time range checking (use HBase built-in timestamp if not specified)
 ts.qualifier qualifier for time range checking (use HBase built-in timestamp if not specified)
{noformat}
