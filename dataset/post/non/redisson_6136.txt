Add method computeIfAbsent with TTL for RMapCache
RMapCache

https://www.javadoc.io/doc/org.redisson/redisson/3.3.2/org/redisson/api/RMapCache.html

Currently there is a computeIfAbsent method from ConcurrentMap. There are specific methods with TTL putIfAbsent and put. It would be great to have a computeIfAbsent method with the ability to set TTL.

Currently you have to call computeIfAbsent and then expireEntryIfNotSet, but if the application crashes after computeIfAbsent, the key will not have a TTL set
