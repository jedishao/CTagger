DOC - Link tickets, pages in FAQ page
The [FAQ|https://cassandra.apache.org/doc/latest/cassandra/overview/faq/index.html] page references tickets and pages which are not hyperlinked. For example:

{quote} See {{256}} and {{43}} for more gory details.{quote}

should instead be:

{quote} See [CASSANDRA-256|https://issues.apache.org/jira/browse/CASSANDRA-256] and [CASSANDRA-43|https://issues.apache.org/jira/browse/CASSANDRA-43] for more gory details.{quote}

A second example is:

{quote}When a new nodes joins a cluster, it will automatically contact the other nodes in the cluster and copy the right data to itself. See {{topology-changes}}.{quote}

should instead be:

{quote}When a new nodes joins a cluster, it will automatically contact the other nodes in the cluster and copy the right data to itself. See [topology changes|https://cassandra.apache.org/doc/latest/cassandra/managing/operating/topo_changes.html].{quote}
