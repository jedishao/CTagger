TIMESTAMP (value), MILLIS_TO_TIMESTAMP()/TIMESTAMP_TO_MILLIS() not honoring sqlTimeZone
### Affected Version

25.0.0

### Description

I have a date/time value converted via TIMESTAMP_TO_MILLIS() on ingestion.  When I use MILLIS_TO_TIMESTAMP() at query time with the sqlTimeZone query context parameter set, the TIMESTAMP returned is still in UTC time.

_I believe_ that a timestamp comparison using BETWEEN is also failing because it is comparing timestamps of two different time zones incorrectly.

The documentation reads:
```Sets the time zone for this connection, which will affect how time functions and timestamp literals behave.```
