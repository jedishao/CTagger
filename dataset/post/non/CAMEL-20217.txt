Provide option to create a Pipe file through Camel Jbang init
it would be convenient to provide an option of Camel Jbang init to create a Pipe file.

There is currently an option --integration to create a Camel K integration, maybe we can add an exclusive option --pipe

What would be the content of the file?

proposal:
{noformat}
  apiVersion: camel.apache.org/v1
  kind: Pipe
  metadata:
    name: my-pipe // maybe use the name of the file here?
  spec:
    source:
      ref:
        kind: Kamelet
        apiVersion: camel.apache.org/v1
        name: timer-source
        properties:
          message: hello
    sink:
      ref:
        kind: Kamelet
        apiVersion: camel.apache.org/v1
        name: log-sink
{noformat}
