camel-core - Beans with inlined script (such as groovy) add support for {{ }} property placeholders
We can add an option to 
BeanFactoryDefinition to make it possible to use \{{ }} inside the script source to make Camel property placeholders directly supported. Otherwise you need to use context.resolvePropertyPlaceholders("xxx") api calls.
 
We should add a boolean flag to turn this on|off, as you may want to let the script be as-if, in case you need for some odd reason to work with string values \{{ }}. For example some json, but you could then use { { (space between) then they dont clash with camel property placeholders.
