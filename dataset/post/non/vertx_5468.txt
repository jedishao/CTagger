WebSocketClient does not work with io_uring

### Version

4.5.12

### Context

I have refactored from the older `vertx.createHttpClient(...)..webSocketAbs(...)`  to the newer `vertx.createWebSocketClient(..).wsClient.connect(...)` style API. The project is using `io.netty.incubator:netty-incubator-transport-native-io_uring:0.0.26.Final` on Linux to utilize io_uring. This works fine with the previous API, but with the new API fails with the following exception:
