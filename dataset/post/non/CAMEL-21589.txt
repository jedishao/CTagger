Make manual acknowledgements configurable in Paho-Mqtt5
When using the Camel MQTT5 Source Kafka Connector, messages are automatically acknowledged, which doesn't ensure they reach their final destination at least once. Enabling manual acknowledgements ensures the connector is able to provide at least once delivery to topics. 

This new parameter would make it possible for the user to enable manual acknowledgements in the client. By default, the parameter is set to false and messages will be automatically acknowledged. If set to true, the acknowledgement is added in the exchange's completion callback.
