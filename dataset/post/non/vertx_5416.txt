Vertx 5 migration documentation
#### Describe the feature

I am trying to migrate an application from vert.x 4 to 5.
The current documentation on:
https://github.com/vert-x3/wiki/wiki/5.0.0-Deprecations-and-breaking-changes
does not include many deprecated methods and classes.

Please provide a migration documentation. This will help many users save time searching for solutions.

#### Use cases

examples: 

- RoutingContext.user() now returns ContextUser instead of User.
- RoutingContext.clearUser() has been removed. 
- io.vertx.ext.auth.AuthProvider has been removed.
- io.vertx.core.logging.Logger has been removed.
- StaticHandler.setWebRoot has been renamed.
- etc.
