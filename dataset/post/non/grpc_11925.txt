### What did you expect to see?
I can not compile any proto3 message containing a field of type `repeated EnumType`.  Here is an example of a proto file having this issue
```
syntax = "proto3";

package messages.device.shared;

message FanSpeed {
  enum Type {
    UNSPECIFIED = 0;
    AUTO = 1;
    MIN = 2;
    MID = 3;
    MAX = 4;
    BOOST = 5;
  }

  Type value = 1;
  repeated Type capabilities = 2;
}
```
It only works replacing the field type `Type` with `int32`.

### What did you see instead?
I get this compilation error:
```
error: cannot find symbol
    private static final com.google.protobuf.Internal.IntListAdapter.IntConverter<
                                                     ^
  symbol:   class IntListAdapter
  location: class Internal
```
