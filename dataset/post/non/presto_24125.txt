Size related memory configurations use GiB instead of GB
The documentation for Prestissimo and the config names, e.e. system-memory-gb use the GB unit to define the value.

However, the Prestissimo code converts the value from GiB into bytes (for use in Velox) by doing a left shift on the provided config value.

This leads to confusion about the correct settings for memory related resources.

Example for `system-memory-gb`:

doc: https://prestodb.io/docs/current/presto_cpp/properties.html#query-memory-gb
code: https://github.com/prestodb/presto/blob/300ca07cd149bd88fbf5e7f7b9473d763af52aee/presto-native-execution/presto_cpp/main/PrestoServer.cpp#L811

This affects many settings that end with `-gb`. (complete list to follow).
