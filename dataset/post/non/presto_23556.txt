SSL Support for Oracle Connector
Oracle is not using ssl connection.Currently presto is supporting only non ssl connection.

## Expected Behavior or Use Case
Oracle to support the ssl connection

## Presto Component, Service, or Connector
presto-oracle

## Possible Implementation
we can add truststore path and password 

```
oracle.tls.truststore-path=/path/to/truststore
oracle.tls.truststore-password=<truststore-password>
```
