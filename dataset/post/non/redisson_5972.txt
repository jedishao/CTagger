The redis three-master and three-slave clusters often perform active/standby switchover. As a result, the redisson client may report an error (MOVED), which affects services
redis version：6.0.11
redisson version：3.30.0
Due to the poor performance of network or cluster node machines, our redis cluster is often in an unstable state and will have multiple master/standby switches. In this case, there is a certain probability that redisson's cluster topology information will fail to refresh, which is inconsistent with the actual cluster node information, resulting in its request being sent to the standby redis node. redis returns a moved error, but the redisson client still does not refresh its cluster topology. The error cannot be recovered by itself, and the service needs to be restarted to resolve it. The specific error information is as follows:
