Native CTE with materialized shuffle.
https://github.com/prestodb/presto/issues/22630 added support for CTE materialization using Velox writer/reader. This approach, while simple has some drawbacks as the CTE writing needs to be completed before the reads. If a very big CTE gets chosen, then this could be prohibitive.

A more reliable approach is to use a materialized shuffle for CTE as that can schedule reads of the materialized tables as soon as any data is available for the reader.

Velox has now added materialization support for the shuffle. Investigate using that for CTE.
