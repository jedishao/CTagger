[native] Memory configuration default must be automatically inferred based on the available memory
Memory configs `system-memory-gb`, `system-mem-limit-gb` defaults must be automatically inferred.


## Expected Behavior or Use Case
A user should not have to set these configs.

## Presto Component, Service, or Connector
Prestissimo

## Possible Implementation
Query the system to find the memory available.


## Context
This simplies deployment and user adoption.
