CLI with --external-authentication doesn't work on headless systems without -Djava.awt.headless=true
Running the following fails with the error in annex:

```
java -jar trino-cli-452-executable.jar --user <user> --external-authentication --server <server>
```

Adding `-Djava.awt.headless=true` works:

```
java -Djava.awt.headless=true -jar trino-cli-452-executable.jar --user <user> --external-authentication --server <server>
```

The `-Djava.awt.headless=true` requirement is undocumented and probably unexpected?
