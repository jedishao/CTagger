camel-catalog - XPath language doesn't seem to validate
When I validate an expression, for example this invalid jsonpath:


{code:java}
String expression = "$store.book[*].title"
DefaultCamelCatalog catalog = new DefaultCamelCatalog();
catalog.validateLanguageExpression(ClassLoader.getSystemClassLoader(), "jsonpath", expression);
{code}
 

I get a validation error as expected: 
{code:java}
"Illegal character at position 1 expected '.' or '['"{code}

The same works for other languages like Simple or Groovy. However, when I use xpath:


{code:java}
String expression = "\\/path/to"
DefaultCamelCatalog catalog = new DefaultCamelCatalog();
catalog.validateLanguageExpression(ClassLoader.getSystemClassLoader(), "xpath", expression);{code}

I get a success back. 

However, when I use some regular Java code


{code:java}
try {
    Processor proc = new Processor(false);
    XPathCompiler xpath = proc.newXPathCompiler();
    xpath.compile(expression);
    return "valid";
}catch (SaxonApiException e) {
    return e.getMessage();
} {code}

I get


{code:java}
Invalid character '\\' (x5c) in expression{code}

I would expect some similar as the above, or something like "Unable to perform XPath operation. Invalid character '\' in expression " when using the validateLanguageExpression from the catalog.
