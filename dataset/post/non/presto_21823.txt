Add support for the basic format of ISO8601 
The ISO 8601:2004 section 2.3.3 defines a the *basic format* as values like this: "20010822T030405.321-1100". 

The current presto supports only the *extended format* (values like this "2001-08-22T03:04:05.321-11:00")

## Expected Behavior or Use Case

Support the basic format. The basic unit tests are defined in #18287. 

## Presto Component, Service, or Connector
This is probably a feature used from an external dependency, the one that parses the date and timestamps.

## Context
The context is the same where the ISO 8601 values are currently used.
