[Iceberg]Support identity/bucket transform for UuidType in Iceberg connector
In the Iceberg spec, columns of type `uuid` support being specified identity/bucket transform in a partitioned table, refer to [here](https://iceberg.apache.org/spec/#partition-transforms). We have supported `UuidType` in Iceberg connector, so it better to support identity and bucket transform for `UuidType` as well according to Iceberg spec.

## Expected Behavior or Use Case

Support identity and bucket transform for columns of type `TimeType` in Iceberg table 

## Context

Support as many types as possible for partition transforms according to Iceberg specification.
