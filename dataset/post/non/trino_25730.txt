Support SQL privileges in Iceberg connector
This is carried over from [slack](https://trinodb.slack.com/archives/CJ6UC075E/p1741743986544889) so we keep the traction of the discussion. `TrinoCatalog` should have interface methods to connect the operations on SQL privileges for the underlying catalog types if they support them. For example [OpenHouse catalog](https://openhousedb.org/docs/User%20Guide/Catalog/SQL#grant-revoke) supports `GRANT`/`REVOKE`.
