Issue in deserialisation using Kryo5Codec
<!--
Upgrade to Redisson PRO https://redisson.pro with advanced features.
-->
Upgraded Java version from 11 to 21. This meant that `FstCodec` couldn't be supported, hence I migrated the codec to Kryo5Codec. So the updated redisson with Kryo5Codec is unable to read data written by FstCodec (old redisson version 3.11.3).


**Expected behavior**
It is expected to return a map

```
private RMapCache<String, Integer> apiRateLimitMinuteWiseMapCache;
apiRateLimitMinuteWiseMapCache = redissonClient.getMapCache(MAP_NAME_FOR_MINUTE_WISE);
```

```
@Bean

    final org.springframework.core.io.Resource redisConfigDetail = resourceLoader.getResource(redisConfigPath);
    final Config config = Config.fromYAML(redisConfigDetail.getInputStream());
    if (config.isSentinelConfig())
      config.useSentinelServers();
    else
      config.useSingleServer();
    return Redisson.create(config);
  }
```
