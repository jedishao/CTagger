camel-jbang - --max-* options with --dev fails to terminate the Camel context
When we'd like to run a Camel script once and then immediately self-terminate it, we'd run the command:
{code}
camel run hello.java --max-messages=1
{code}
and it works just as expected. However, when we add {{--dev}} to the above command, it starts to fail to terminate the context and thus the process.
{code}
camel run hello.java --max-messages=1 --dev
{code}

The same issue goes for {{\-\-max\-idle\-seconds}} and {{--max-seconds}} as well.

Normally it wouldn't be an issue because it doesn't make much sense to use {{\-\-max\-*}} and {{\-\-dev}} at the same time, but it becomes an issue when we run a Camel script on VS Code, where the [Debug Adapter for Apache Camel|https://github.com/camel-tooling/camel-debug-adapter] always attaches {{--dev}} to the launcher command.
