The "Max columns to merge" setting is confusingly displayed
### Affected Version

28.0.1

### Description

In the latest version of the Druid Router page, I noticed that the Compaction task configuration for `Max columns to merge` defaults to `0`. However, the actual default value is `-1` (means unlimited). When switching to the JSON configuration, it shows as `"maxColumnsToMerge": null`. This seems a bit confusing.
