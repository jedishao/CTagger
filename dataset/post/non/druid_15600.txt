Correct the column `used_flag_last_updated` in the version 28.0.0 release note
### Affected Version

28.0.0

### Description

![image](https://github.com/apache/druid/assets/8108788/33e4275b-164e-4b52-9242-39d6343ac9fb)

In the version 28.0.0 of Apache Druid, the column `used_flag_last_updated` was renamed to `used_status_last_updated` in https://github.com/apache/druid/pull/14868 which also belongs to version 28.0.0. Therefore, this upgrade note doc is outdated, we should correct this part to avoid any confusion.
