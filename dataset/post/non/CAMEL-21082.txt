camel-jbang init command is deleting existing routes/files when using --dir option
{noformat}
jbang '-Dcamel.jbang.version=4.7.0' camel@apache/camel init firstone.camel.yaml --dir=target-folder
{noformat}

the firstone.camel.yaml file is created

{noformat}
jbang '-Dcamel.jbang.version=4.7.0' camel@apache/camel init secondone.camel.yaml --dir=target-folder
{noformat}

the firstone.camel.yaml file is deleted (without warning) and secondone.camel.yaml is created
