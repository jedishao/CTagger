Use more appropriate GC logging

Quickly looking at the breakdown of trace, debug, and info:

{noformat}
grep trace logs/gc.log | wc -l
    7771
grep debug logs/gc.log | wc -l
     188
grep info logs/gc.log | wc -l
    1065
{noformat}

In summary, we're seeing almost 9K worth of debug and trace log lines for every 1K of INFO, and the debug and trace doesn't have any value for a user that would leave it unset.  Really interested users might want this, but they should know how to enable it.

We should use the INFO settings by default: 

{noformat}
JVM_OPTS="$JVM_OPTS -Xlog:gc=info:file=${CASSANDRA_LOG_DIR}/gc.log:time,uptime,pid,tid,level:filecount=10,filesize=10485760"
{noformat}
