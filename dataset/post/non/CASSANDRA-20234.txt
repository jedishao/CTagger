CBUtil serialization of UTF8 does not handle all UTF8 properly
The following error was presented to the user from java driver

{code}
Caused by: java.lang.ArrayIndexOutOfBoundsException: Index 512 out of bounds for length 6
	at com.datastax.driver.core.Responses$Result$Kind.fromId(Responses.java:339)
	at com.datastax.driver.core.Responses$Result$1.decode(Responses.java:306)
	at com.datastax.driver.core.Responses$Result$1.decode(Responses.java:303)
{code}

The issue is that there is an off-by-1 issue with track warnings serialization where the estimated size and the actual size don’t match, which cause the client to read result kind of 512 (which isn’t valid)
