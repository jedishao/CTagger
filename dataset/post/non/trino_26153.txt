Add timestamp column to MySQL Event Listener table
The MySQL Event Listener creates a table in the relevant database with the trino query history. However this table doesn't include a `query_start_time` or similar column. You can use LEFT or SUBSTRING functions to extract the timestamp, but this doesn't index well by default if e.g. i want to pull the queries ran in the last `n` days.

Altering the table after or adding a column to a derived table and then indexing can also take a long time and take up a lot of space if the table is sufficiently large. It would be great if we could easily run date range queries on an included TIMESTAMP or epoch column
