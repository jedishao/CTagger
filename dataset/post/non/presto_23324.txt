Constant folding fails during case statement with mixed long decimal and integral types
The following query fails:

```sql
SELECT CASE 1 WHEN 0.111111111 THEN 2 WHEN 3 THEN 4 END;
```

And the following query succeeds:

```sql
SELECT CASE 1 WHEN 0.11111111 THEN 2 WHEN 3 THEN 4 END;
```

The former fails because `0.111111111` is treated as a LongDecimal type, whereas the second query (which has one less point of precision) is treated as a ShortDecimal type.  `1` and `0.11111111` are cast to decimals, but for some reason, `3` is not, so when we interpret the comparisons to fold out the case statement, it fails with the below error (see gist below).

Both expressions should be able to be constant folded.

## Possible Solution
