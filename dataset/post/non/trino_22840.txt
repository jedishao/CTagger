Metadata can't resolve `$internal$json_string_to_array_cast` built in function

Following query fails in hive with projection pushdown enabled as  `ConnectorExpressionTranslator` can't resolve [$internal$json_string_to_array_cast function](https://github.com/trinodb/trino/blob/master/core/trino-main/src/main/java/io/trino/sql/planner/ConnectorExpressionTranslator.java#L295-L297).  Issue could be related to [IrExpressionOptimizer generating different call Expression](https://github.com/trinodb/trino/blob/master/core/trino-main/src/main/java/io/trino/sql/ir/optimizer/rule/SpecializeCastWithJsonParse.java#L54-L57) than the [expected one](https://github.com/trinodb/trino/blob/master/core/trino-main/src/main/java/io/trino/operator/scalar/JsonStringToArrayCast.java#L34-L44). Same problem could exist with`$internal$json_string_to_map_cast` and `$internal$json_string_to_row_cast`.

```
trino:tpch> create table hive.default.t1 as select cast(row('[1]', '[2]') as row(a varchar, b varchar)) as col;
```
