## Code and Configuration

Controller class
```
    @GetMapping("/read")
    public Collection<String> readFromRedis(@RequestParam(value = "exchange") String exchange, @RequestParam(value = "symbol") String symbol) {
        return this.redisDataReader.readKey(exchange, symbol);
    }
```

readKey method
```

    public Collection<String> readKey(String exchange, String symbol) {
        String encodedSymbol = URLEncoder.encode(symbol, StandardCharsets.UTF_8);
        String key = exchange + "~" + encodedSymbol;
        RScoredSortedSet<String> scoredSortedSet = redissonClient.getScoredSortedSet(key);
        var result = scoredSortedSet.readAll();
        return result;
    }

```
RedissonClient bean creation

```
   @Bean(destroyMethod = "shutdown")
    public RedissonClient redisson() throws IOException {
        Config config = Config.fromYAML(new File("config", "redis.yml"));
        RedissonClient client = null;
        try {
            client = Redisson.create(config);

            // for debug purpose
            log.debug("configured redis settings: {}", client.getConfig().toYAML());

        } catch (Exception e) {
            log.error("Redis creation failed. Shutting down!");
            shutdownHelper.initiateShutdown(1);
        }
        return client;
    }
```
