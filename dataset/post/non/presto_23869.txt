Duplicated expressions cause issue in RowExpressionInterpreter
```
SELECT 
  CAST(x AS BIGINT) AS z 
FROM 
  (
    SELECT 
      CAST(NULL AS VARCHAR) AS x, 
      CAST(NULL AS VARCHAR) AS y 
    FROM 
      (
        VALUES 
          NULL
      ) AS empty(empty) 
    WHERE 
      FALSE
  ) 
WHERE 
  y = '2024-10-17' 
LIMIT 
  3000
```
