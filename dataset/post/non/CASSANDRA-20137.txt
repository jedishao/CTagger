Duplicit values for uuid column in cassandra-stress
In case of command
{code:java}
cassandra-stress user profile=abc.yaml ...{code}
and yaml file:
{code:java}
table_definition: | 
  CREATE TABLE prftest1.process_data (
  id uuid,
  id2 uuid,
  data blob,
  PRIMARY KEY (id, id2)

columnspec: 
  - name: id 
    population: seq(1..10) 
  - name: id2 
    population: seq(1..10)
  - name: data 
    size: uniform(5..10) 
    population: seq(1..100){code}
the values for +id2+ (with type {+}uuid{+}) are all the same (not random). 

 

NOTE: in case of type +bigint+ for +id+ and {+}id2{+}, the values for +id2+ are random items.
