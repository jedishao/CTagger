To improve accord interoperability test coverage, need to extend the harry model domain to handle more possible CQL states
Interop touches every read/write path and as such the testing demand needs to cover the full domain as well with proper validation.  We need to extend harry’s model logic to handle more possible states such as: by token, and filtering/index (native to the model); the larger CQL domain is planned and expected to be follow up work in their own JIRAs.
