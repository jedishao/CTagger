JDBC: Some joins fails when query does a table scan

I have a postgresql connector that works for some queries, but fails when a join does a table scan.
This fails on trino:472 and trino:474

Some queries fails with this error:
`Query 20250415_092620_00004_zqcx4 failed: Maximum allowed column name length is -2 but next synthetic id has length 1`

An example query that fails
```
select
 u.id
from cockroachdb.public.users u 
join cockroachdb.public.tangibles t on t.user_id = u.id 
limit 1
```
