Delta Lake/ABFS: "No FileSystem for scheme 'abfs'" when using Trino with Azure Data Lake Storage Gen2
When using Trino (latest official Docker image) with the Delta Lake connector and Hive Metastore, I am unable to access Delta Lake tables stored in Azure Data Lake Storage Gen2 (ABFS).

I always get the following error:
org.apache.hadoop.fs.UnsupportedFileSystemException: No FileSystem for scheme "abfs"

Environment

Trino: trinodb/trino:latest
Delta Lake connector
Hive Metastore (MariaDB)
Azure Data Lake Storage Gen2 (ABFS) with OAuth
docker-compose.yml with TRINO_PLUGIN_AZURE_ENABLE=true
Relevant configuration
No extra FileSystem configs in delta.properties or hive.properties

Expected behavior
Trino should register the "abfs" FileSystem and allow querying Delta Lake tables in ADLS Gen2.

Actual behavior
Always fails with "No FileSystem for scheme 'abfs'".

How to reproduce

Start Trino with Delta Lake and Hive Metastore as per documentation.
Try to register or query a Delta Lake table in ABFS.

Thank you!
