/etc/cassandra/cassandra-jaas.config does not exist in Packages install
When installing cassandra 4.1.5 wth the debian packaged installer the file cassandra-jaas.config  does not exist.

When enabling JMX authentication in the cassandra-env.sh you uncomment the line JVM_OPTS="$JVM_OPTS -Djava.security.auth.login.config=$CASSANDRA_CONF/cassandra-jaas.config" 

It is expecting this file to be in this location (which maps to /etc/cassandra/) and it is not.
