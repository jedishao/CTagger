[FeatureRequest] Monitoring metrics for supervisors  status
### Description

Currently, there is no way of monitoring the state of supervisors' health via monitoring [metrics](https://druid.apache.org/docs/latest/operations/metrics/). 

I would like to request a metric (or set of metrics) to report the following:

* Supervisor health status: whether a supervisor is healthy or not. ([Druid API](https://druid.apache.org/docs/latest/api-reference/supervisor-api/#supervisor-information)).
* Supervisor current state/status: e.g.: `RUNNING`,  `SUSPENDED`, etc ... ([List of possible states](https://druid.apache.org/docs/latest/ingestion/supervisor#status-report))

### Motivation

* To be able to monitor the status of Druid supervisors via monitoring metrics.
* Supervisor is a critical piece of Druid when performing streaming ingestion.
