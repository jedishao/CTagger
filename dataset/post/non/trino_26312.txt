GCS native FS implementation is slower than non-native legacy implementation
After switching from non-native Hadoop implementation to the native GCS implementation in version 476, I noticed a huge decrease in total input data rates across the cluster (2-3X) which subsequently affected all the queries performance. You can see in the attached screenshot how the input data rates went up significantly after switching to the non-native implementation (after the red line)
