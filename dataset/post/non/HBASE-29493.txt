In starting of the cache the block is stored in ramCache and later we drain it to backingMap async. This test work fine if we only interact with ramCache but sometime drain get completed just before we try to get the block again after eviction. Wheneve the block moves to backingMap it start the ref from fresh so either 1 or 2. And because of this Assertion in the if fails.
