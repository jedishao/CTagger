CSE from AND/OR
If someone does:

f(x) not like '%x' AND f(x) not like '%y' AND f(x) not like '%z' ...

We don't CSE f(x). But we should be able to! We can probably do this as a expression simplification - any (common) subexpression that's in the first predicate (after reordering), we can do it as a CSE. Can be useful for tool generated queries
