Option to set DSCP codes on network traffic
I would like to add the possibility to set DSCP codes on network traffic from Cassandra. I was thinking of one value for traffic from the native port and different values for inbound and outbound internode traffic. To configure this in the yaml file I like to add something like this:

 
{noformat}
dscp_code:
  enabled: false
  native_dscp: 0
  internode_outbound_dscp: 0
  internode_inbound_dscp: 0{noformat}
