Create table using import command gives ddl pointing to incorrect location
Repro steps:

create external table test_a (val string) partitioned by (pt string);
insert into test_a partition (pt ='1111') values ("asfd");
export table test_a partition (pt='1111') to '/tmp/test_a';
import table test_b from '/tmp/test_a';

Under the location of test_b, there is no partition directory or data file, instead the partition "pt=1111" resides under the managed location of test_b.
