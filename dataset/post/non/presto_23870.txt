## Perplexing parentheses annotation usage in update document

In the document of the `update` statement, the synopsis section is like:
```SQL
UPDATE table_name SET [ ( column = expression [, ... ] ) ] [ WHERE condition ]
```
where the usage of parentheses '(' and ')' seems to be perplexing, as they will not appear in real statements.
A referenced similar usage of parentheses annotation is in `alter function` statement document:
```SQL
ALTER FUNCTION qualified_function_name [ ( parameter_type[, ...] ) ]
    RETURNS NULL ON NULL INPUT | CALLED ON NULL INPUT
```
The parentheses will actually appear in real statement.

To avoid misunderstanding, I suggest remove the '(' and ')' parentheses annotation from the `update` document.
