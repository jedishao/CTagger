Session is missing in some abstract methods in BaseArrowFlightClientHandler.java

## Expected Behavior or Use Case
We have an implementation of arrow flight server connector, which implements the presto-base-arrow-flight module. In that, I want to attach the presto QueryId to the request I am sending to the flight server. 
This can be done easily by taking the queryId from session, if the session is available there.
`session.getQueryId()`

In most of the methods in BaseArrowFlightClientHandler, session is passed as an argument.
But the session is not passed in these two methods : 
1. protected abstract FlightDescriptor getFlightDescriptorForSchema(String schemaName, String tableName);
2. protected abstract FlightDescriptor getFlightDescriptorForTableScan(ArrowTableLayoutHandle tableLayoutHandle);
