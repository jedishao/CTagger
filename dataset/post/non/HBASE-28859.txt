Migrate to GitHub Checks API for PR Precommit
Our PR pre-commit check is configured to leave comments on the PR with its build results. Especially for our 2.x branches, it is leaving upwards of 4 comments per build. This results in a lot of bot spam, which is distracting from human conversations. I've mitigated the issue via HBASE-28642, but it would be better if the bot didn't leave comments, but instead used the [Checks API|https://docs.github.com/en/rest/checks]. I believe that Yetus is already able to do this, and is configured to do so. I think we need to engage with INFRA to get our auth token adjusted.
