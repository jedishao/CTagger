Iceberg JDBC catalog config properties not available in Trino
Trino Iceberg plugin exposes only a limited subset of Iceberg JDBC Catalog configuration properties - see [IcebergJdbcCatalogConfig.java](https://github.com/trinodb/trino/blob/master/plugin/trino-iceberg/src/main/java/io/trino/plugin/iceberg/catalog/jdbc/IcebergJdbcCatalogConfig.java).

Iceberg supports additional configuration properties, including those which control its internal JDBC connection pool behavior:

* `retryable_status_codes` - https://github.com/apache/iceberg/blob/main/core/src/main/java/org/apache/iceberg/jdbc/JdbcClientPool.java#L73
* `clients` - https://github.com/apache/iceberg/blob/main/core/src/main/java/org/apache/iceberg/jdbc/JdbcClientPool.java#L62

`retryable_status_codes` are especially useful - being able to configure those would resolve issues like #16284.

Please add these (and other, if possible) Iceberg configuration properties to Trino Iceberg plugin configuration.
