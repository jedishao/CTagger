Druid loading lookups failed to iterate over fetched data
Druid loading lookup failed to iterate over fetched data.

### Affected Version

Starting from v28.0.0 to v30.0.1

### Description

Steps to reproduce the issue:
1- Create a loading lookup that has a JDBC connection
2- Wait for a couple of minutes until the lookup is created and registered
3- Try to get the values of the lookup
4- You should see an error saying that it cannot iterate over fetched data
