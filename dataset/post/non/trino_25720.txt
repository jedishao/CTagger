Iceberg equality deletes with struct type columns should be supported
From Iceberg documentation on [equality-delete-files](https://iceberg.apache.org/spec/?h=equality#equality-delete-files) and [identifier-field-Ids](https://iceberg.apache.org/spec/?h=equality#identifier-field-ids), row type should be allowed in the equality delete columns but we get
```
Caused by: java.lang.UnsupportedOperationException: Type not supported as partition column: row(a varchar, b varchar, c varchar)
	at io.trino.plugin.iceberg.IcebergPageSink.getIcebergValue(IcebergPageSink.java:417)
	at io.trino.plugin.iceberg.delete.TrinoRow.<init>(TrinoRow.java:35)
	at io.trino.plugin.iceberg.delete.EqualityDeleteFilter.readEqualityDeletes(EqualityDeleteFilter.java:74)
	at io.trino.plugin.iceberg.IcebergPageSourceProvider.readDeletes(IcebergPageSourceProvider.java:417)
```
The cause of this is that we are reusing `IcebergPageSink::getIcebergValue` which is tailored for partitioning columns that have different restrictions.

Since `io.trino.plugin.iceberg.delete.TrinoRow` is only used in the delete files, we can have a separate method to load the values without applying the same restrictions for partitioning columns.

From the spec, using required `REAL`/`FLOAT` or `DOUBLE` columns for equality deletes should be failed.

Aside from these, the error message right now is misleading to the end users.
```
Caused by: java.lang.UnsupportedOperationException: Type not supported as partition column: row(a varchar, b varchar, c varchar)
```
