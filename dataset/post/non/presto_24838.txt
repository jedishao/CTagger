[Iceberg]Support identity/bucket/year/month/day/hour transform for TimestampWithTimeZoneType in Iceberg connector
In the Iceberg spec, columns of type `timestamp tz` support being specified identity/bucket/year/month/day/hour transform in a partitioned table, refer to [here](https://iceberg.apache.org/spec/#partition-transforms). We have supported `TimestampWithTimeZoneType` in Iceberg connector, so it better to support identity, bucket, year, month, day, and hour transform for `TimestampWithTimeZoneType` as well according to Iceberg spec.

## Expected Behavior or Use Case

Support identity, bucket, year, month, day, and hour transform for columns of type TimestampWithTimeZoneType in Iceberg table

## Context

Support as many types as possible for partition transforms according to Iceberg specification.
