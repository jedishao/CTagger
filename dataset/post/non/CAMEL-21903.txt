camel-jbang: Adjustable container image name on Kubernetes export
When exporting projects with the Camel JBang Kubernetes plugin the Kubernetes manifest has the container image name set as part of the deployment in {*}_src/main/jkube_{*}.

This prevents users from customizing the container image name with *_jkube.container-image.name_* setting. Instead of adding the container image name to the deployment resource we should set this in the Maven pom.xml as property {_}*jkube.container-image.name*{_}. Then users may overwrite this default property when calling the Maven build.
