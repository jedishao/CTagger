Examples fail to build on JDK 22
<!-- Please answer these questions before submitting a bug report. -->

### What version of gRPC-Java are you using?
`v1.65.1`

### What is your environment?
MacOS, Docker, Eclipse Temurin 22.

### What did you expect to see?
[Quickstart example](https://grpc.io/docs/languages/java/quickstart/) builds successfully.

### What did you see instead?
[Quickstart example](https://grpc.io/docs/languages/java/quickstart/) build fails with the following error:

```

```

### Steps to reproduce the bug
```
git clone -b v1.65.1 --depth 1 https://github.com/grpc/grpc-java && \
docker run --rm --mount type=bind,source=$PWD/grpc-java,target=/home/grpc-java --workdir /home/grpc-java/examples eclipse-temurin:22 ./gradlew installDist
```

### Notes
Examples build successfully on JDK 21.
