Make NESSIE_REFERENCE_HASH session property settable and validated
The current NESSIE_REFERENCE_HASH is not settable and defaulted to null, which makes it actually not used. The Nessie reference hash is used to identify a specific commit on a Nessie reference branch. If it's not set then it's defaulted to the latest branch. We should make it settable, and do basic validations if it's set.

See https://github.com/prestodb/presto/pull/21501
