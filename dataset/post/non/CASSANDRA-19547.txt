4.1.4 Cassandra fails on bootstrap on arm64 due to JNA 5.6.0
https://issues.apache.org/jira/browse/CASSANDRA-17019 only fixed Cassandra 4.0.0. 
Cassandra 4.0.12 and 4.1.4 are still using JNA 5.6.0. Causing those versions to fail on Apple M1/M2.

Currently, you can work around by replacing the jar in the lib folder. For example, if you are using ccm on mac:
```

cp ~/.ccm/repository/4.0.0/lib/jna-5.13.0.jar ~/.ccm/repository/4.1.4/lib/jna-5.13.0.jar

```
