Logout button for authenticators/ authentication extensions
### Description

In the pac4j extension, once a user is correctly authenticated, there is no option in the console to logout from the client provider used to login. Currently post the expiry of the authenticated token, the user simply gets logged out which is an unnatural way to log a user out. Even in the basic authenticator the same functionality does not exist, I have not looked into other extensions.
An overall addition of logout functionality would be appreciated.

### Motivation

Please provide the following for the desired feature or change:
- Any feature allowing for authorised login should allow for logout from the console directly via the console.
