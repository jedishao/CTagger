Presto on Spark for SQL Server Connector Error: Catalog doesn't support page sink commit.
Initially I opened this as usage post and did not hear anything. Given that I could not find any documentation in Presto Docs that says  that SQL Server Connector is not supported for this feature, Im going to assume its a bug.

To reproduce, I followed the instructions [here](https://prestodb.io/docs/current/installation/spark.html) and my spark-sbmit looks like the following:
```
spark-submit 
--master spark://localhost:7077 
--executor-cores 4 
--conf spark.task.cpus=4
--class com.facebook.presto.spark.launcher.PrestoSparkLauncher 
  presto-spark-launcher-0.289.jar 
--package presto-spark-package-0.289.tar.gz 
--config ./presto/config.properties 
--catalogs ./presto/catalog 
--catalog sqlserver 
--schema dbo 
--file ./presto/jobs/insert_transform.sql
```
