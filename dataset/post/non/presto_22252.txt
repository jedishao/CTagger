Add metrics from scan planning in Iceberg connector
Iceberg provides a `MetricsReporter` interface that allows users of the reference library to understand various performance and functional characteristics of the library.  We can expose these metrics so understand where future improvements may be made in our Iceberg integration, and to understand if any pathological performance problems are due to statistics collection or scan planning in Iceberg.

## Expected Behavior or Use Case
Better visibility into the Iceberg library

## Presto Component, Service, or Connector
Iceberg connector

## Possible Implementation
Leverage `tableScan.metricsReporter(...` and integrate it with the RuntimeStats framework (this is currently undocumented, see #21514 to add documentation for this framework).
