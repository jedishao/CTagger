Changing the queryFrameWork in Calcite*Tests may have sideeffects
the method named `requireMergeBuffers(1)` ; changes the field `queryFramework` which may change the behaviour of later testcases

adding this testcase to `CalciteQueryTest` creates 2 failing tests
```java
  @Test
  public void testMergeBufferSettingHasSideEffect() {
    requireMergeBuffers(1);
  }
```
