[native] Document v1/operation end point
Prestissimo workers support "HTTP GET v1/operation" endpoint to assist in debugging production issues.

## Message Format

`HTTP GET v1/operation/<target>/<action>?<param1>=<value1>&<param2>=<value2>...&<paramN>=<valueN>`

## Send message using curl

`curl "hostname:7777/v1/operation/target/action?params"`

Example:

`curl "hostname:7777/v1/operation/systemConfig/setProperty?name=shutdown-onset-sec&value=7"`

## Supported commands


* connector/clearCache
  * parameters: name, id
  * Clears connector's WS File Handle Cache. Example: name="prism", id="deltoid_prism".

* connector/getCacheStats
  * parameters: name, id
  * Returns stats of connector's WS File Handle Cache. Example: name="prism", id="deltoid_prism".

* systemConfig/setProperty
  * parameters: name, value
  * Sets System Config's property value.

* systemConfig/getProperty
  * parameters: name
  * Returns System Config's property value.

* veloxQueryConfig/setProperty
  * parameters: name, value
  * Sets Velox Query Config's property value.

* veloxQueryConfig/getProperty
  * parameters: name
  * Returns Velox Query Config's property value.

* task/listAll	
  * parameters: limit	
  * Return brief info on all tasks in the TaskManager.

* task/getDetail	
  * parameters: id	
  * Returns debug information in json format about task with given id. Run output through the unescape twice!

* debug/trace	
  * parameters: 	
  * Returns status of traces.
