[docs] Add Session Properties to Hive Connector
Add a new _Hive Session Properties_ topic to [Hive Connector](https://github.com/prestodb/presto/blob/master/presto-docs/src/main/sphinx/connector/hive.rst) doc. The new topic should be similar to the existing [Hive Configuration Properties](https://github.com/prestodb/presto/blob/master/presto-docs/src/main/sphinx/connector/hive.rst#hive-configuration-properties) topic. 

The content of the new topic can be gathered by pulling together the mentions of hive session properties scattered throughout the page [Hive Connector](https://github.com/prestodb/presto/blob/master/presto-docs/src/main/sphinx/connector/hive.rst) into a new topic. 

**A note about scope:** 
This issue is intended only as a restructuring of existing documentation, and it should not be expanded to become a comprehensive list of all (currently undocumented) Hive session properties. A hunt for undocumented Hive session properties should be a separate issue. 

## Expected Behavior or Use Case
New  _Hive Session Properties_ topic in the  [Hive Connector](https://github.com/prestodb/presto/blob/master/presto-docs/src/main/sphinx/connector/hive.rst) documentation.

## Presto Component, Service, or Connector
Documentation. 

## Context
As part of a discussion in #25021 ([comment one](https://github.com/prestodb/presto/pull/25021#issuecomment-2877469514) and [comment two](https://github.com/prestodb/presto/pull/25021#issuecomment-2880454121)) it was mentioned that the Iceberg Connector doc has separate topics for Configuration Properties and Session Properties. 

I opened this issue to allow people to discuss if adding a new _Hive Session Properties_ topic in [Hive Connector](https://github.com/prestodb/presto/blob/master/presto-docs/src/main/sphinx/connector/hive.rst) is a good idea.
