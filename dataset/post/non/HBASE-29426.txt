Define a tiering value provider and refactor custom tiered compaction related classes
This is to implement the pluggable value provider, so that custom tiered compaction can be made generic enough to perform tiering based on the value provided according to use case specific logic. For example, the date for the tiering comparison may be embedded within a portion of the row key, so a custom value provider implementation that knows how to parse such value from the row key could be configured accordingly.

This is also adapt the logic from the custom cell qualifier as a built-in implementation of the tiering value interface.
