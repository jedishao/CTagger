[native] task/getDetail?id=xyz crashes with std::out_of_range: out of range in dynamic array
Looks like the crash happens in Task::toJson when accessing driverObj[index++]:

```
  folly::dynamic driverObj = folly::dynamic::array;
  int index = 0;
  for (auto& driver : drivers_) {
    if (driver) {
      driverObj[index++] = driver->toJson();
    }
  }
```

We should use driverObj.push_back(driver->toJson()); or change driverObj to folly::dynamic::object.
