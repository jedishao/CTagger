[native] Presto protocol script adds extra license from *.inc files
<!--- Provide a general summary of the issue in the Title above -->
<!--- Look through existing open and closed issues to see if someone has reported the issue before -->

When generating presto protocol files, special include files *.inc have a license header. The script will place the entire inc file in the resulting generated protocol source files, including the header. 

Example at https://github.com/prestodb/presto/blob/4caf30f756da7b660b78142633220677a98a3b26/presto-native-execution/presto_cpp/presto_protocol/connector/arrow_flight/presto_protocol_arrow_flight.h#L41 

The script should be fixed to exclude the header when inserting the special include files. Previous discussion at https://github.com/prestodb/presto/pull/24914#discussion_r2055066915
