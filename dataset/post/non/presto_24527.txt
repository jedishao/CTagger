[native]Add metrics for S3FileSystem in Prestissimo
<!--- Provide a general summary of the feature request or improvement in the Title above -->
<!--- Look through existing open and closed feature proposals to see if someone has asked for the feature before -->

Presto Java supports S3FileSystem metrics, and we want to add this feature in Prestissimo as well.

## Expected Behavior or Use Case
<!--- Tell us how it should work -->

Prestissimo supports both Promethus metrics at worker level and runtime stats at query level. To achieve the parity with Presto Java, I think we need implement the worker level metrics. Whether adding the the query-level stats need further consideration.

## Presto Component, Service, or Connector
<!--- Tell us to which service or component this request is related to -->

Metrics

## Possible Implementation
<!--- Not obligatory, suggest ideas of how to implement the addition or change -->

The worker level metric can be implemented by defining new metrics and adding new tasks in PeriodicTaskManager.
As for the query level stats, the storageStats_ introduced in https://github.com/facebookincubator/velox/pull/12200/files#diff-a915a0b3e072ef4a052dbb06719358c0896ab8a8370b042ae41b10ec64ac4202R180 can be used to collect and update the stats for file systems.
