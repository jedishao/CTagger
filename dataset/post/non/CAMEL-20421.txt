KnativeProducer creates Platform Http Service in JBang
The Knative component consumer leverages the Platform Http service in order to provide a Http endpoint that is called by the Knative broker subscription.

Therefore the Knative component starts the MainHttpServer when run with Camel JBang.

In case the route uses only the Knative producer the Http Platform service is not necessary because the producer connects to the Knative broker as a client. However Camel JBang always starts the Http platform service when the Knative component is involved.

We should only use the Http platform service when a Knative consumer is involved.
