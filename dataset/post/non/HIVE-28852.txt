Enhanced HMSHandler partition logs for get_partitions expression calls
The current implementation of {{get_partition}} calls for expressions in the {{HMSHandler}} class does not pick up the filter correctly, leading to potential issues in retrieving partition information. This patch aims to enhance the logging for these calls, providing more comprehensive and detailed logs.
This change is needed post HIVE-27894

*Patch Details:*
 * This is an addendum patch to the previous implementation.
 * Enhances logging within {{get_partition}} calls for expressions to ensure that filters are correctly picked up and logged.
