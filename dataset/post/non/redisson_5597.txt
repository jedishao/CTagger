org.redisson.misc.RedisURI cannot be cast to java.lang.Comparable
**Expected behavior**
connect to the AWS redis serverless cluster

**Actual behavior**
```
Caused by: java.lang.ClassCastException: org.redisson.misc.RedisURI cannot be cast to java.lang.Comparable

```
I guess this was introduced with the fix of #5589 :
```
            CompletableFuture<List<RedisURI>> ipsFuture = serviceManager.resolveAll(clusterNodeInfo.getAddress());
            CompletableFuture<Void> f = ipsFuture.thenAccept(addresses -> {
                if (addresses.size() > 1 && clusterNodeInfo.containsFlag(Flag.MASTER)) {
                    addresses.sort(null);
                    Collections.shuffle(addresses, new Random(serviceManager.getId().hashCode()));
                }
                RedisURI address = addresses.get(0);
```
`RedisURI` doesn't implement Comparable, so cannot be called sort on it.
