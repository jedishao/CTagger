Trino JDBC driver 470 and newer requires Java 11 or higher
The Trino JDBC driver version 470 (and newer) requires Java 11 or higher; however [the docs state that Java 8 or higher](https://github.com/trinodb/trino/blob/e9ab2269e1467128f34bb8f45d2838daf25647b1/docs/src/main/sphinx/client/jdbc.md?plain=1#L13-L15) is the requirement.

Error message: `java.lang.UnsupportedClassVersionError: io/trino/jdbc/TrinoDriver has been compiled by a more recent version of the Java Runtime (class file version 55.0), this version of the Java Runtime only recognizes class file versions up to 52.0`
