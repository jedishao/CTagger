camel-core - Make it easier to configure SSL using XML and YAML DSL
You can configure this in classic XML DSL (spring) (see CAMEL-20774) and in camel-main/SB you can configure this via properties in camel.ssl.

However it would be great to have it first-class in XML IO and YAML DSL as well so its easier to configure there also and for tooling. Configure SSL is complex and this can help with better tooling assistance.
