Camel JBang update command
Add a new command to Camel JBang (update) that can be used to update Camel, Camel Spring Boot and Camel Quarkus applications.
The update command has two sub-commands:
* *list* gather the possible updates searching for camel-upgrade-recipes, camel-spring-boot-upgrade-recipes and quarkus-update-recipes versions. The following information should be printed:
** VERSION - Camel version
** RUNTIME - Camel, Camel Quarkus, Camel Spring Boot
** RUNTIME VERSION - empty for Camel, Quarkus version, or Spring Boot version
** DESCRIPTION - Recipe description (Migrate to version xxx)
* *run $VERSION* execute the update to the given version using openrewrite in case of Camel or Camel Spring Boot or quarkus maven plugin update in case of Camel Quarkus
