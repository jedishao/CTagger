Skip check for DirectIO when initializing tools
After CASSANDRA-19812 using sstabledump throws exceptions on startup in deployments
where the conf file is not relative to {{path/to/cassandra/tools/bin}} or with a process that does not have permissions to create the commit log directory or files within it. It presumably applies to other offline tools, but I haven't tested yet.

The new block size check for DirectIO makes the dirs/files, but isn't needed for tools, so can be skipped on tool initialization.
