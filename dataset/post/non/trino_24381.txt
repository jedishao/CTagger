Impossible to use SASL_SSL in Kafka event listener
Kafka event listener tells that configuration for kafka client should be defined in `kafka-event-listener.client-config-overrides` as key=value separated by comma.
But if value contains `=`, bootsrap of coordinator fails. Param 'sasl.jaas.config' always contains `=`. Example of value:
```
org.apache.kafka.common.security.plain.PlainLoginModule required username="admin" password="admin";
```

So it is not possible to send events to kafka with SASL_SSL.


Kafka event listener [documentation](https://trino.io/docs/current/admin/event-listeners-kafka.html#configuration) states that the configuration for the Kafka client should be defined in `kafka-event-listener.client-config-overrides` as key=value pairs separated by commas. However, if a value contains the `=` character, the coordinator's bootstrap process fails. 
For example, the parameter sasl.jaas.config always contains `=`, as shown below:
```
org.apache.kafka.common.security.plain.PlainLoginModule required username="admin" password="admin";
```
As a result, it is impossible to send events to Kafka using SASL_SSL.
