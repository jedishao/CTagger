Incorrect comparator usage in FinalizingPostAggregators

For aggregators which have a non-trivial finalization `AggregatorFactory#getResultType() != AggregatorFactory#getIntermediateType()`  (so essentialy those which will most likely need some work to be done).

The comparator is derived for the underlying `aggregator` for the `postAggregator` [here](https://github.com/apache/druid/blob/30c59042e0cde3c76392afa3ba73d0830b11b0a5/processing/src/main/java/org/apache/druid/query/aggregation/post/FinalizingFieldAccessPostAggregator.java#L124) - so a comparision of finalized values might be tried with the aggregator's comparator.

This could cause an exception in case the postAggregators output  is being used to order the rows by it.

Example query:
```
select dim1,e
from (SELECT dim1, EARLIEST(f1) e FROM druid.numfoo GROUP BY 1 ORDER BY 2 LIMIT 10) t
order by 1 limit 2
```
