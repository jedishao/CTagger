Column stats computation fails for TIMESTAMPLOCALTZ columns when hive.strict.timestamp.conversion is true
Steps to reproduce

 

create table testq(tz timestamp with local time zone DEFAULT TIMESTAMPLOCALTZ'2016-01-03 12:26:34 America/Los_Angeles' );
analyze table testq compute statistics for columns tz;

 

error :Casting DATE/TIMESTAMP types to NUMERIC is prohibited
