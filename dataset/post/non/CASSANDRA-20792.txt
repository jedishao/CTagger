Replace deprecated EndpointSnitchInfoMBean usage with LocationInfoMBean
Replace all usage of the deprecated EndpointSnitchInfoMBean with LocationInfoMBean in nodetool commands and related code.
 

The EndpointSnitchInfoMBean interface has been deprecated since CEP-21 (see CASSANDRA-19488) and should be replaced with LocationInfoMBean. This task involves updating all nodetool commands and related code that currently use the deprecated MBean.

EndpointSnitchInfoMBean is used in several nodetool commands:
 * CommandUtils.java - for getting datacenter information
 * Ring.java - for displaying ring information
 * Status.java - for displaying node status
 * ListPendingHints.java - for displaying hint information
