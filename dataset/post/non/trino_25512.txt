Skip row type without fields in Iceberg
Iceberg allows a column with struct type without fields, even though the row type in Trino requires at least 1 field. 
We should skip such unsupported columns instead of failures. We can reproduce by adding the following test to TestIcebergV2:
```java
    @Test
    void testRowWithoutField()
    {
        try (TestTable table = newTrinoTable("test_row_without_field", "(id int)")) {
            Table icebergTable = loadTable(table.getName());
            icebergTable.updateSchema().addColumn("nested", Types.StructType.of()).commit();

            assertQueryReturnsEmptyResult("SELECT * FROM " + table.getName());
        }
    }
```
