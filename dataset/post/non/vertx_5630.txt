Implementation of Software Transactional Memory
### Describe the feature

I currently want to implement a requirement where each player verticle needs to purchase the same set of goods. The data of the goods will be held by the store verticle, similar to a flash sale scenario. Players need to pay money, and the quantity of goods must be accurately deducted to avoid overselling. At the same time, players should not have their money deducted if there are no available goods. This may require a mechanism similar to Software Transactional Memory (STM) to fulfill the requirement. Is there a common solution in Vert.x for this kind of problem?
