Docs Update: Graceful shutdown request needs X-Trino-User header
Not a huge deal, but the [docs](https://trino.io/docs/current/admin/graceful-shutdown.html) show this as an example api request for graceful shutdowns on worker nodes:
```
curl -v -X PUT -d '"SHUTTING_DOWN"' -H "Content-type: application/json" \
    http://worker:8081/v1/info/state
```

Without an `X-Trino-User` header, the request results in `401 Unauthorized`. 

It'd be nice if the docs include the header so that future users know to add it. 

I've outlined some of my learnings on the Trino slack [here](https://trinodb.slack.com/archives/CFSDUNJ4W/p1718309319833329?thread_ts=1718287184.124219&cid=CFSDUNJ4W).
