`3.27.2 - 3.37.0` clusterServersConfig configuration with `lazyInitialization=true` will cause the service to get stuck during startup and not start completely
### Redis version

aws 7.1

### Redisson version

3.37.0

### Redisson configuration

```yaml
spring:
  redis:
    redisson:
      config: |
        clusterServersConfig:
          nodeAddresses:
            - "rediss://test-redis-0001-001.test-redis.xxxxx.xxxx.cache.amazonaws.com:6379"
          password: xxxxxxxxxxxxxxxxxx
          scanInterval: 10000                     
          sslEnableEndpointIdentification: false  
          connectTimeout: 60000                   
          timeout: 20000                          
          idleConnectionTimeout: 60000            
          dnsMonitoringInterval: -1               
          masterConnectionPoolSize: 128           
          slaveConnectionPoolSize: 128            
        protocol: RESP3                           
        threads: 32                               
        nettyThreads: 72                          
        lazyInitialization: true
```

_No response_
