Support error handler in Camel JBang bind command
A Pipe resource is able to specify an error handler in addition to a source and a sink. The bind command in Camel JBang should be able to also specify an error handler.

The error handler specification in the Pipe can be a sink (e.g. a Kamelet reference), endpoint URI, log error handler or noErrorHandler.

The bind command should provide a new option (--error-handler) that receives the error handler in the same way as source and sink are specified on the command.
