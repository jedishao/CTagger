Credential leakage when using kafka connector with schema registry
we have a kafka connector with schema registry.  
this schema registry is protected by auth.

According to documentation https://trino.io/docs/current/connector/kafka.html#confluent-table-description-supplier, currently trino doesn't support auth for registry in any other way other then passing credentials in connection string
```
  connector.name=kafka
  kafka.table-description-supplier=CONFLUENT
  kafka.confluent-schema-registry-url=https://${ENV:KAFKA_SCHEMA_REGISTRY_USER}:${ENV:KAFKA_SCHEMA_REGISTRY_PASS}@${ENV:KAFKA_SCHEMA_REGISTRY_URL}
  kafka.hide-internal-columns=false
  kafka.nodes=kfk01:9092,kfk02:9092,kfk03:9092
  kafka.config.resources=/etc/trino/kafka-configuration.properties
  ```

however, if we pass those creds in this way, we can see them in bootstrap log:
