camel-kafka: consolidate commit management behavior between component and endpoint
The behavior of using a NoopCommitManager by default is [different if the configuration is done via component instead of via endpoint|https://camel.zulipchat.com/#narrow/stream/257298-camel/topic/Kafka.20-.20misleading.20documentation.20for.20manual.20commits/near/407802601]. In the component-based configuration it uses a SyncCommitManager instead of a NoopCommitManager as written in the documentation.
