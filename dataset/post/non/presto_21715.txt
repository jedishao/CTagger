[Native] Adding functions in Prestissimo
All the Presto native function implementations are currently in Velox. These functions have unit tests as well and 
very useful Fuzzer tests.
In the Prestissimo WG meeting [last week](https://docs.google.com/document/d/1oL0KVf_02_P_kIfNs2oZVwB60_PqHBNou6MzRAS1fbM/edit#heading=h.o85nkj3afpgg), there was a discussion on how to improve the C++ developer community in the Presto Project.
One thought was to allow trivial functions to be written in Prestissimo instead of Velox. We wanted to start with
the "fail" function first. https://github.com/prestodb/presto/issues/20742
But this does mean some functions continue to live in Velox while others live in Prestissimo. We will also need to add
Fuzzer testing in Prestissimo.
The scope of this issue is to discuss this further and conclude.
