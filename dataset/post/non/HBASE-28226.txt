The flush table operation encountered an NPE and failed.
Executing a merge region before the flush table is completed will result in an NPE error for the flush table and cause it to fail

Triggering logic
 # Execute the flush table command.
 # Merge regions before the flush is completed.
 # After the merge is completed, the two parent regions will be cleaned up.
 # An NPE will be reported when the flush operation is performed on that parent region.
