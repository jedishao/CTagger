8.0

3.45.1

None, it is not related to how Redisson configured.

### What is the Expected behavior?

_No response_

### What is the Actual behavior?

Method org.redisson.cache.AbstractCacheMap.removeExpiredEntries() use many CPU?

### Additional information

How can we override the method 'org.redisson.cache.AbstractCacheMap.removeExpiredEntries()' in 'LRUCacheMap' to resolve this issue?


```
  @Override
  protected boolean removeExpiredEntries() {
    if ( timeToLiveInMillis == 0 && maxIdleInMillis == 0 ) {
      return false;
    }

    boolean removed = false;

    Iterator<CachedValue<K, V>> it = queue.iterator();
    while ( it.hasNext() ) {
      CachedValue<K, V> cachedValue = it.next();
      if ( isCachedValueExpired( cachedValue ) ) {
        if ( map.remove( cachedValue.getKey(), cachedValue ) ) {
          onValueRemove( cachedValue );
          removed = true;
        }
      }
      else {
        break;
      }
    }
    return removed;
  }
```
