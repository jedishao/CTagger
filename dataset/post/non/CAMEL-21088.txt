camel-jbang: Support Kubernetes export options in run command
The Camel JBang Kubernetes run command is based on the export command. Some of the options available on the export are not available in the run command.

We should aim to have almost identical configuration options for export and run because run can be seen as a export + automatic deployment.

Some of the export options (e.g. --quiet) may be set statically in the run command though because it does not make sense to have these options configurable on the run command.
