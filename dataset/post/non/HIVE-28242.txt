Using SEQUENCE instead of NOTIFICATION_SEQUENCE table
NOTIFICATION_SEQUENCE table currently holds 1 record and is accessed by Hive using select for update. Will it be better to use a sequence instead?

This is because sequences can cache values in memory for each session and reduce the number of changes in the background table (as well as the frequency of related locking and serialization).

refer https://mariadb.com/kb/en/sequence-overview/
