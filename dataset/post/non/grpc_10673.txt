OutlierDetection does not provide a Status description when ejecting
Although RPCs should not fail because of OutlierDetection, as it makes sure there are still some working addresses, passing down a Status without a description can make debugging hard:
https://github.com/grpc/grpc-java/blob/bdb0c72d45a5bbadfc3125ae639c256f7b6ea9a5/util/src/main/java/io/grpc/util/OutlierDetectionLoadBalancer.java#L328-L329
