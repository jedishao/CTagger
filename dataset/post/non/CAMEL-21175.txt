camel-jbang - automatically add package name when creating a Camel route with Java DSL in a src/main/java subfolder
I think it would be convenient to automatically add package name when creating a Camel route with Java DSL in a src/main/java subfolder.
it will allow to use it directly inside Camel Quarkus and Camel Spring Boot projects.

Having a package name still allow to launch with Camel Jbang directly.
