AsyncIterator CompletionStage is not completed exceptionally, when connection to Redis gets read timeout
### Redis version

Mock Redis server used, com.github.fppt.jedis-mock:1.1.4

### Redisson version

3.45.0

### Redisson configuration

CONFIG.setNettyThreads(10)
.useSingleServer().setConnectionPoolSize(10)
.setConnectionMinimumIdleSize(10)
.setTimeout(150)
.setRetryAttempts(0)
.setAddress("jedis-mock-redis-localhost-address");

### What is the Expected behavior?

The CompletionStage from the AsyncIterator's `hasNext` method to complete exceptionally.

### What is the Actual behavior?

The CompletionStage from the AsyncIterator's `hasNext` method completes normally.

### Additional information

Hello,
 
We're using the AsyncIterator<V> valuesAsync(String keyPattern, int count) method from RMap to retrieve values, based on a certain key pattern.
 
However, we've encountered an issue, that when the connection to the Redis hits a read timeout, the CompletionStage from AsyncIterator's hasNext method isn't completed exceptionally - it completes normally and the result from stage is false. It is not clear when the resulting collection is empty because of the timeout and when it's empty because there are no elements in the Redis.
