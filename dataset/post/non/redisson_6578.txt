**Description:**

When using Redisson 3.37, invoking getMap("myMap") and attempting to retrieve a specific value with a known key (e.g., "key1") results in all entries in the Redis hash being fetched. This is inefficient and unexpected when the intent is to retrieve only a single value.

Currently, the `getMap` interface only supports retrieving the full map and does not offer a method to directly fetch a single key’s value in a lazy or optimised way.

**Expected Behaviour:**

There should be a direct way to retrieve the value of "key1" from a Redis hash map ("myMap") without fetching the entire hash.

_Current Workaround (Inefficient):_

```java
RMap<String, String> map = redissonClient.getMap("myMap");
String value = map.get("key1");  // But this causes all hash keys to be fetched
```

Enhance the `getMap` or expose an alternative method to efficiently fetch a single value from the Redis hash (e.g., a lazy get(key) that avoids pulling the whole map).
