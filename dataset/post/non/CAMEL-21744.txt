camel-openapi-java - Make security configurable
https://swagger.io/specification/#fixed-fields

From the spec, the _security_ field is a declaration of which security mechanisms can be used across the API. The list of values includes alternative Security Requirement Objects that can be used. Only one of the Security Requirement Objects need to be satisfied to authorize a request. Individual operations can override this definition. The list can be incomplete, up to being empty or absent. To make security explicitly optional, an empty security requirement ({}) can be included in the array.

This integration may be harder to implement, and most probably runtimes should provide custom implementations.
