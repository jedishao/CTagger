Support AWS S3 Tables in Iceberg
AWS [S3 tables](https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-tables.html) are a new bucket type that support storing table in the Apache Iceberg format.

Trino should support querying S3 tables out of the box using the [S3 tables catalog for Iceberg](https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-tables-integrating-open-source.html).
