Update commitlog_sync_period for modern hardware
We've used {{commitlog_sync_period: 10000ms}} as long as I can remember.  I think the original setting of 10 seconds made sense when spinning disks were the norm, but now that they're the outlier we should update this to be more appropriate for modern hardware.  I generally lower this to 2000ms when using disaggregated storage, and have heard some folks use sub second for NVMe, but haven't done it myself.  I think as a default, we can safely bring this down to 2 seconds.
