[Bug] approx_percentile not returning same data type as input
According to [documentation](https://trino.io/docs/current/functions/aggregate.html#approximate-aggregate-functions), `approx_percentile(x, percentage)` return type is supposed to be the same as input. However, when `Decimal(21,0)` is passed as input, return type is `real` 

```
SHOW COLUMNS FROM table1;
```
Output:
col1, decimal(21,0)
col2, varchar

```
CREATE TABLE table2 AS
SELECT
   col2 as id,
   approx_percentile(col1, .5) as percentTest
FROM table1
GROUP BY col2 ;

SHOW COLUMNS FROM table2;
```
Output:
id, varchar
percentTest, real
