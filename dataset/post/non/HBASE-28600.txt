Enable setting blockcache on-heap sizes in bytes
Specifying blockcache and memcache sizes as a percentage of heap is not always ideal. Sometimes it's easier to specify exact values rather than backing into a percentage. Let's introduce new configuration settings (perhaps named similarly to {{hbase.bucketcache.size}}) that accept byte values. Even nicer would be if these settings accepted human-friendly byte values like {{512m}} or {{10g}}.
