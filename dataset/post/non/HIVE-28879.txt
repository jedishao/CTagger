Federated Catalog support
Add a new capability that enables HiveCatalog to seamlessly access tables stored in Hive Metastores and any other registered external Catalog.
{code:java}
CREATE CATALOG [IF NOT EXISTS] <catalog_name>
PROPERTIES (
  'catalog-type'='rest',
  'uri'='https://iceberg-with-rest:8181/'
)
{code}
example: [https://iceberg.apache.org/docs/1.4.0/flink-ddl/]

TYPES:
 * HIVE (default),
 ** External / Iceberg
 ** ACID
 * HADOOP,
 * REST
 * GLUE
 * NESSIE
 * JDBC
 * Kafka, Druid, Hbase, etc

conf sample: [https://github.com/apache/polaris/blob/main/getting-started/trino/trino-config/catalog/iceberg.properties]
