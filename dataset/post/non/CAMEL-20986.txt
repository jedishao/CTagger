camel-ai: improve chunking support
Currently, when loading data into a VectorDB, applications have to implement chunking on their own. This is typically done as a processor (which then uses LangChain4J [Document Splitter|https://docs.langchain4j.dev/tutorials/rag/#document-splitter] features or implement their own). 

We could make this simpler by implementing a specialized chunking DSL that abstracts this process and simplify loading the data to those databases.
