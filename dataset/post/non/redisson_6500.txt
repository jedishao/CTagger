Does Redisson guarantee that all getAsync() calls have completed once batch.execute() returns?
Here is my code:
```java
RBatch batch = redisClient.createBatch();
List<Order> orders = new ArrayList<>();
for (String orderId : orderIds) {
    RBucketAsync<Order> bucket = batch.getBucket(orderId);
    bucket.getAsync().onComplete(((o, e) -> orders.add(o)));
}
batch.execute();
```
The question is will in this code all `getAsync` calls be completed after `batch.execute` method returns? Or should I additionally iterate over list of futures after the `batch.execute()` is completed? Something like this:
```java
List<RFuture<Order>> futures = new ArrayList<>();
for (String orderId : orderIds) {
    RBucketAsync<Order> bucket = batch.getBucket(orderId);
    RFuture<Order> future = bucket.getAsync();
    futures.add(future);
}
batch.execute();

// Wait for all async operations to complete
for (RFuture<Order> f: futures) {
    orders.add(f.get());
}
```
