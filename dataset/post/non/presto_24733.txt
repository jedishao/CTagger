Support more Iceberg Metadata columns
https://prestodb.io/docs/current/connector/iceberg.html#extra-hidden-metadata-columns
So far Presto only supports querying the $path and $data_sequence_number metadata columns. We will need to add more columns. For more see https://iceberg.apache.org/javadoc/1.8.1/org/apache/iceberg/MetadataColumns.html. 
The first several we should support

- [DELETE_FILE_PATH](https://iceberg.apache.org/javadoc/1.8.1/org/apache/iceberg/MetadataColumns.html#DELETE_FILE_PATH)
- [IS_DELETED](https://iceberg.apache.org/javadoc/1.8.1/org/apache/iceberg/MetadataColumns.html#IS_DELETED)
