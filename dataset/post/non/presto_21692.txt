kCounterSpillPeakMemoryBytes defined as a HISTOGRAM type but recorded as a regular metric
<!--- Provide a general summary of the issue in the Title above -->
<!--- Look through existing open and closed issues to see if someone has reported the issue before -->
kCounterSpillPeakMemoryBytes Metric is of HISTOGRAM type defined [here](https://github.com/prestodb/presto/blob/master/presto-native-execution/presto_cpp/main/common/Counters.cpp#L205C2-L210C12): 

```
 DEFINE_HISTOGRAM_METRIC(
      kCounterSpillPeakMemoryBytes,
      1l * 512 * 1024 * 1024,
      0,
      20l * 1024 * 1024 * 1024, // max bucket value: 20GB
      100);
```
Recorded as regular metric, instead histogram must use RECORD_HISTGRAM_METRIC:
https://github.com/prestodb/presto/blob/master/presto-native-execution/presto_cpp/main/PeriodicTaskManager.cpp#L620
