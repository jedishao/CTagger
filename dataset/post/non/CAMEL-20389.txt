Fix incorrectly named integration tests
There are a few components with tests not following our naming standards (*Test.java for unit tests and *IT.java for integration tests). 

They need to me renamed to ensure they run with the appropriate plugin.

The component camel-salesforce also contains some tests named using *IntegrationTest.java pattern, but that [component configures the failsafe plugin accordingly and has a build and setup process that is significantly more complex than the typical Camel component|https://github.com/apache/camel/blob/2e9ea98ef5435d897709d81f0d300061d8d213c1/components/camel-salesforce/camel-salesforce-component/pom.xml#L308-L490].
