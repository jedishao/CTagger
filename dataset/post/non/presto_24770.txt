Solution for uniform and consistent Data Partitioning in Watsonx.data via Presto

## Describe the problem you faced

* I am using Presto to connect to Watsonx.data, where I have a table containing 160 rows. I want to partition this data into training and testing sets. Specifically, I am looking for a Presto SQL function that can assign a uniformly distributed random number to each row, allowing me to randomly split the data. Based on the assigned random values, I plan to allocate 50% of the rows to the training set and the remaining 50% to the testing set.I initially tried using the rand() function in Presto, which provides the desired random distribution for partitioning the data. However, I need the partitioning to be consistent across query executions—that is, the same rows should be assigned to the training and testing sets every time I run the query. I am looking for a way to generate deterministic random values for each row to achieve a reproducible split.
