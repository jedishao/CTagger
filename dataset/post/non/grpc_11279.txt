netty-shaded bazel target overridden to target which does not have package io.grpc.netty.shaded.io.grpc.netty
After migrating from workspace to bzlmod on compile of my code i started to receive an error
`<path>/GrpcServer.java:11: error: package io.grpc.netty.shaded.io.grpc.netty does not exist
import io.grpc.netty.shaded.io.grpc.netty.NettyServerBuilder;`
It's because grpc-java overrides it to it's own target https://github.com/grpc/grpc-java/blob/master/MODULE.bazel#L153 which differs from original maven shaded netty https://github.com/grpc/grpc-java/blob/master/netty/shaded/BUILD.bazel#L5.

I've managed to bypass it only with archive_override and removing maven.override directives from MODULE.bazel of grpc-java
