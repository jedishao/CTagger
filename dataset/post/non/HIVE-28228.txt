Remove redundant sources maven profile
The sources maven profile was introduced in HIVE-5717 among others to package source code into a .jar and publish it to maven. However, after adding Apache pom as parent in HIVE-6608 the sources profile is now redundant; it is subsumed by the [apache-release profile|https://github.com/apache/maven-apache-parent/blob/c124276ad15e2eb05fde5029e8e2e6187bf05053/pom.xml#L428].
