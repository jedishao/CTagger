camel-jackson - Allow to configure stream reader constraints
If you have big payloads (such as 20mb) then jackson has some limits that can cause it to not parse this by default

[https://github.com/spring-projects/spring-boot/issues/34709]

We should make it easier to configure in Camel so users can load bigger payalods. And maybe also have bigger default as jackson has
