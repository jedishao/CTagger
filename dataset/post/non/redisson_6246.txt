RScheduledExecutorService registered with WorkerOptions delays 10 seconds Quarkus shutdown 
### Redis version

7.4.1

### Redisson version

3.37.0

### Redisson configuration

quarkus.redisson.single-server-config.address=redis://localhost:6379
quarkus.redisson.single-server-config.password=null
quarkus.redisson.threads=16
quarkus.redisson.netty-threads=32

### What is the Expected behavior?

_No response_

### What is the Actual behavior?

Tested on plain Quarkus 3.8.6 LTS.
The class below requests a `RScheduledExecutorService`  and registers a `WorkerOptions` to it.
If you restart Quarkus (by pressing "s" on developer console or by simply adding an empty line in the code and making a rest call), Quarkus restart in about ten seconds. 

![image](https://github.com/user-attachments/assets/14e4af45-ae33-4fe5-80b5-e1dcacb6ac6d)

But if you comment the `executor.registerWorkers(options)` line

![image](https://github.com/user-attachments/assets/f1baa826-6965-4474-b1db-b9585571d9a2)

and make the same test you notice that Quarkus restarts in less than 1 second, as expected in the Quarkus environment.

![image](https://github.com/user-attachments/assets/dc9c177f-ceb8-4c79-9deb-33364baec511)

Maybe the delay is expected, because Redisson is make some cleanup on shutdown

```
package org.acme;

import io.quarkus.runtime.ShutdownEvent;
import io.quarkus.runtime.StartupEvent;
import jakarta.enterprise.context.ApplicationScoped;
import jakarta.enterprise.event.Observes;
import jakarta.inject.Inject;
import org.jboss.logging.Logger;
import org.redisson.api.RScheduledExecutorService;
import org.redisson.api.RedissonClient;
import org.redisson.api.WorkerOptions;

@ApplicationScoped
public class LifecycleListener {

    @Inject
    Logger logger;

    @Inject
    RedissonClient redisson;

    private WorkerOptions getOptions() {
        WorkerOptions options = WorkerOptions.defaults()
                // Defines workers amount used to execute tasks.
                // Default is 1.
                .workers(1);
        return options;
    }

    void onStart(@Observes StartupEvent evt) {
        logger.infov("onStart {0}", evt.toString());
        RScheduledExecutorService executor = redisson.getExecutorService("myExecutor");
        WorkerOptions options = getOptions();
        executor.registerWorkers(options); // To faster Quarkus restart comment this line
    }

    void onStop(@Observes ShutdownEvent evt) {
        logger.infov("onStop {0}", evt.toString());
    }

}

```
