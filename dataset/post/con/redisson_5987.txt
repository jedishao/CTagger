### Additional information

I would like to utilize it in a scheduled task, The task was executed successfully, and the key was successfully added to Redis, However, the tryLock() method returned false, I believe that the return results of tryLock() and isLock() should be consistent under any circumstances.

Below is my code snippet:

    @Scheduled(cron = "0 0/5 * * * ? ")
    public void execute() {
        RLock lock = redissonClient.getLock("LOCK-KEY");
        boolean locked=false;
        try {
            log.debug("1: locked, {}, isLock: {}", locked, lock.isLocked());
            locked = lock.tryLock(0, 5, TimeUnit.MINUTES);
            log.debug("2: locked, {}, isLock: {}", locked, lock.isLocked());
            TimeUnit.SECONDS.sleep(2);
            log.debug("3: isLock: {}", lock.isLocked());
            if (locked) {
                log.debug("加锁成功...");
            }
        } catch (Exception e) {
            log.error("异常", e);
        } finally {
            // lock is not being released.
        }
    }
