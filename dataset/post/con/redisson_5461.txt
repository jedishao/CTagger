If the lock is not obtained, an exception occurs

Redission Java
1）version：3.17.4
2）code

```java
@Scheduled(cron = "${data.schedule}")
    public void execute() {
        RLock rLock = redissonClient.getLock(key);
        try {
            if (rLock.tryLock(10, TimeUnit.MILLISECONDS)) {
                dataService.handlerOtherService();
            }
        } catch (InterruptedException e) {
            log.error("中断异常：",e);
            Thread.currentThread().interrupt();
        } finally {
            if (rLock.isLocked() && rLock.isHeldByCurrentThread()) {
                rLock.unlock();
            }
        }
    }
```
In a 5-master and 5-slave environment, the lock is added in this way. When the lock is not obtained, an exception occurs
