Don't synchronize on stats update in ThriftHiveMetastore
We have a cluster online. Recently, we found that a large number of queries are in the QUEUED state, but there are very few queries in the RUNNING state in the entire cluster. This thread seems to be motionless, causing the entire cluster to fail to operate normally. I looked at the code and found that the `updateTableStatistics` API was synchronized.

```
public synchronized void updateTableStatistics(HiveIdentity identity, String databaseName, String tableName, Function<PartitionStatistics, PartitionStatistics> update)
```

I found that trino has removed `synchronized`(https://github.com/trinodb/trino/pull/2154/files), so we should be able to do the same.
