FairLock don't work with tryLock, but works with lock
### Redis version

5.0.13

### Redisson version

R3.15.6 R3.32.0

### Redisson configuration

I use threads to lock same key. each thread process data of list one by one, try lock before process and unlock after process. FairLock+tryLock don't work as expected. but FairLock+Lock works.
```
for(int i=0;  i<5; i++) {
    final int idx = i;
    ListenableFuture future = listeningExecutorService.submit(new Callable<String>() {
        @Override
        public String call() {
            for(int j=0; j<50; j++) {
                RLock lock = redisson.getFairLock("test");
                boolean locked = false;
                try {
                   // use lock works
                    //lock.lock(60, TimeUnit.SECONDS);
                    //System.out.println("getLock:\t" + idx + "\t"+ j);
                    // use tryLock some threads got locked = false after 60 second
                    locked = lock.tryLock(60, 60, TimeUnit.SECONDS);
                    if (locked) {
                        System.out.println("getLock:\t" + idx + "\t" + j);
                    } else {
                        System.err.println("LockErr:\t" + idx + "\t" + j);
                        System.err.println(new Date().getTime() - date.getTime());
                    }
                   // emu data process
                    Thread.sleep(2000);
                } catch (InterruptedException e) {
                    throw new RuntimeException(e);
                } finally {
                    // uncomment when use tryLock
                    if (locked)
                      lock.unlock();
                }
            }
            return "";
        }
    });
 }
```
