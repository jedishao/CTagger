Locks not working with NameMapper
### Redis version

6.2.6

### Redisson version

3.27.2

### Redisson configuration

```java
public class RedisConfig implements RedissonAutoConfigurationCustomizer {

    private final NameMapper nameMapper;

    public RedisConfig(NameMapper nameMapper) {
        this.nameMapper = nameMapper;
    }

    @Override
    public void customize(Config cfg) {
        if (cfg.isClusterConfig()) {
            cfg.useClusterServers().setNameMapper(nameMapper);
        } else {
            cfg.useSingleServer().setNameMapper(nameMapper);
        }
    }

    @Component
    public static class KeyPrefixNameMapper implements NameMapper {

        @Value("${redis.key-prefix}")
        private String keyPrefix;
        private int prefixLen;

        @PostConstruct
        void init() {prefixLen = keyPrefix.length()+2;}

        @Override
        public String map(String name) {
            return keyPrefix + "::" + name;
        }

        @Override
        public String unmap(String name) {
            return name.substring(prefixLen);
        }
    }
}
```

Let the key-prefix be "crt"
