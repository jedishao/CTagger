Is their any way to check the thread status? so the watchdog renew listener can stop to renewing lock?
I try to add new RedissonBatchLock instead of RedissonMultiLock recently.
I thought the Watchdog would check the lock thead state, but i found it doesn't check it , so when lock thread is TERMINATED , it will still renewing lock.

here is test code
```
    @Test
    public void testRenewedWhenThreadStopped() throws InterruptedException {
        final CountDownLatch countDownLatch = new CountDownLatch(1);
        Thread thread1 = new Thread(() -> {
            RLock lock1 = getRedissonClient().getLock("test123");
            boolean result = lock1.tryLock();
            assertThat(result).isTrue();
            countDownLatch.countDown();
        });
        thread1.start();
        countDownLatch.await();
        TimeUnit.SECONDS.sleep(40);
        RLock lock = getRedissonClient().getLock("test123");
        assertThat(lock.isLocked()).isFalse();
    }
```
The thread1 is TERMINATED , but Watchdog  will still renewing lock.
**Maybe we can save the lock thread an check it?** Or course we can't get thread by threadId when invoke tryLockAsync method with threadId param,
**so there is another question, Why add tryLockAsync method with threadId param?**
when invoker  invoke tryLockAsync method with threadId param,  it is very likely that they hold a thread object(they created or get form thread poll or current thread), so they would invoked like `lock.tryLockAsync(thread.getId())` .
So if we support check thread status, can we use tryLockAsync(Thread thread) instead of tryLockAsync(long threadId)
