Stack overflow in AsyncProcess if retry too much
In AsyncProcess, we resubmit the retry task in the same thread
{code}
  // run all the runnables
      for (Runnable runnable : runnables) {
        if ((--actionsRemaining == 0) && reuseThread) {
          runnable.run();
        } else {
          try {
            pool.submit(runnable);
          } 
          ......
{code}

But, if we retry too much time. soon, stack overflow will occur. This is very common in clusters with Phoenix. Phoenix need to write index table in the normal write path, retry will cause stack overflow exception.
