with Postgres rdbms for metastore and dbnotification enabled, hive DDL SQL query fails 
with postgres rdbms for hive-metastore any DDL fails when dbnotification is enabled, the reason being a lock on the notification sequence is required, which for Postgres requires the column-names and table names to enclosed in "(double quotes) as we are using direct SQL and not going through datanucleus and  postgres is case sensitive.
