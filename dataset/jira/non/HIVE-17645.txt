MM tables patch conflicts with HIVE-17482 (Spark/Acid integration)
MM code introduces 

HiveTxnManager txnManager = SessionState.get().getTxnMgr()


in a number of places (e.g DDLTask.generateAddMmTasks(Table tbl)).  HIVE-17482 adds a mode where a TransactionManager not associated with the session should be used.  This will need to be addressed.
