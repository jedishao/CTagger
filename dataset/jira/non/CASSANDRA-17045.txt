Add minor upgrade/downgrade/mixed mode support in in-jvm dtests
It should be possible to write in-jvm dtests where we upgrade from an earlier minor version to the current one, and since we support downgrading between minors we should add some tests for that.
If possible it would be nice to provide a new test target running all the in-jvm dtests, but where some random nodes in the in-jvm clusters are running a previous minor version to exercise a mixed mode cluster.
Goal is to be able to catch issues like CASSANDRA-17042 early.
