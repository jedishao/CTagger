Netty library causing issue while running spark on yarn in PSuedodistributed mode
While running in psuedodistributed mode,there is different version of netty-all library in hdfs (4.0.52), this is fine till you try to run spark on it. The spark 3.0.1 comes with netty-all 4.1.47.
Now both the libraries get loaded in classpath and thus spark submit fails with method error.
