CRLF of the script causes the startup service command to fail
Script file should be LF, should not be CRLF, this will lead to the script can not be implemented, the service can not start.
The following documents are required CRLF to be replaced by LF:
bin/beeline.
bin/hive.
bin/hiveserver2.
bin/hplsql.
bin/metatool.
bin/schematool.
