java.lang.IllegalArgumentException during Cassandra 4.x upgrade
This has happened only twice so far and only on the first node being upgraded in a large cluster, so not sure it would be easy to repro, but the steps took to hit this were the following on an existing Cassandra 3.11.6 cluster:
 * nodetool drain
 * stop Cassandra
 * install Cassandra 4.0.1 binaries
 * start Cassandra
