Provide an option to skip shading of jars
Maven shade plugin does not have option to skip. Adding it under a profile can help with skip shade reducing build times.
Maven build profile shows druid and jdbc shade plugin to be slowest (also hive-exec). For devs not working on druid or jdbc, it will be good to have an option to skip shading via a profile. With this it will be possible to get a subminute dev build.
