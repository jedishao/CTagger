Multipile identical CacheConfig log messages in a log file and refactoring around CacheConfig inheritance
There are two issues here:
1. CacheConfig is logged multiple times (some times on adjacent lines) in log file. The reason for this is: 

 LOG.info(this) 

 in CacheConfig constructor. So when CacheConfig and any derived class is instantiated message appears multiple times in a log. The message itself doesn't have any context and look identical. Logging CacheConfig from outside constructor will fix this issue.
2. During debugging its noticed that CacheConfig is meant for in memory block cache but is used for different caches (in some cases for non in memory block caches). This can be improved by refactoring the inheritance of CacheConfig.
