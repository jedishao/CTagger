Make capacity/validity/updateinterval/activeupdate for Auth Caches configurable via nodetool
Currently Auth Caches configuration options (capacity/validity/updateinterval/activeupdate) exposed via JMX or yaml only. We need to introduce a nodetool setauthcachecconfig and nodetool getauthcachecconfig commands.
Also we could think of some VT-based alternative to nodetool. But I feel there is no need to have a separate table for Auth Caches configs. It would be an overhead. Ideally we need to have a separate VT that shows/sets all the configs, but it is out of the scope.
