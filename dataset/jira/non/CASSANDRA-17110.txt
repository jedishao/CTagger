CEP-15: (Accord) Transaction outcomes must be replicated to an optimal number of replicas
Transaction outcomes that are defined by the transaction should not be replicated, and outcomes that are computed from existing records (and as such were not replicated as part of the original transaction) should only be replicated to a single primary shard. This complicates execution, however, without MVCC as the shards from which we had to read the original value cannot delete their state until they know the updated value is replicated durably. One simple option here might be to replicate any new values only to those shards on whom the value's computation depended, so that any shard that receives this new value is safely able to report what the outcome of the transaction is (but is unable to participate in a recomputation of that part of the transaction).
