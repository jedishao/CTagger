Regex column referencing in aggregate functions/group by
The following works as expected:

set hive.support.quoted.identifiers=none;
SELECT `(id|created_at)?+.+`
FROM test_table
WHERE date between "2017-07-01" and "2017-08-01";


However the query fails when adding count/group by like as follows:

set hive.support.quoted.identifiers=none;

SELECT count(*), `(id|created_at)?+.+`
FROM test_table
WHERE date between "2017-07-01" and "2017-08-01"
GROUP BY `(id|created_at)?+.+` ;


Currently this fails with an error. Would it be feasible to implement this feature?
