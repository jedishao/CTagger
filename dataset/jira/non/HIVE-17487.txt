Example fails on the Hive Getting started page
There is an example on Hive Getting Started page using the MovieLens100k dataset. The mapper is defined as a python script in the following way:

import sys
import datetime

for line in sys.stdin:
  line = line.strip()
  userid, movieid, rating, unixtime = line.split('\t')
  weekday = datetime.datetime.fromtimestamp(float(unixtime)).isoweekday()
  print '\t'.join([userid, movieid, rating, str(weekday)])


which is correct assuming you're using the python 2 series. The following code works with both 2 and 3 series:

from __future__ import print_function
import sys
import datetime

for line in sys.stdin:
  line = line.strip()
  userid, movieid, rating, unixtime = line.split('\t')
  weekday = datetime.datetime.fromtimestamp(float(unixtime)).isoweekday()
  print('\t'.join([userid, movieid, rating, str(weekday)]))


I think this should be corrected.
