camel-core - Deprecate InterceptStrategy
This API is org.apache.camel.spi.InterceptStrategy an old api that is intended for Camel internally to be used, and it reveals some of the internals with definition / async processor and whatnot.
Only the intercept eip is using it, but we should make it use its own way instead and deprecate org.apache.camel.spi.InterceptStrategy
We do not want Camel end users to use this interface.
