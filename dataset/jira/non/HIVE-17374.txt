I'm using a pig script to repopulate the data in the table. I don't know if this error happens when using Spark.

The way I see it, there's two possible bugs here:
 1. TRUNCATE TABLE should delete the partition directories
 2. HCatalog should handle existing partition directories correctly.

I'm happy to provide any more information you may want, and help with an eventual patch.
