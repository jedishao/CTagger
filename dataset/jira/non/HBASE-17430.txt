dead links in ref guide to class javadocs that moved out of user APIs.
The ref guide currently has one or more links to some javadocs that are no longer in our user apis. unfortunately they link via a google search which prevents the dead link detector from finding them.
e.g. in architecture.adoc

Instead, they create small files similar to symbolic link files, named link:http://www.google.com/url?q=http%3A%2F%2Fhbase.apache.org%2Fapidocs%2Forg%2Fapache%2Fhadoop%2Fhbase%2Fio%2FReference.html&sa=D&sntz=1&usg=AFQjCNEkCbADZ3CgKHTtGYI8bJVwp663CA[Reference files], which point to either the top or bottom part of the parent store file according to the split point.


We should instead directly link to the correct location, e.g. http://hbase.apache.org/devapidocs/org/apache/hadoop/hbase/io/Reference.html
