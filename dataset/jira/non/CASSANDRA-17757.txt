A user should not be able to manually remove ephemeral snapshots
in CASSANDRA-16911 we introduced the "-e" flag to nodetool listsnaphots which are returning ephemerals as well. An operator might try to remove these snapshots by hand. This should not be possible as these snapshots are there for repair to work on and manual removal breaks it. To be complete, these snapshots are removed as part of repair mechanism automatically, or they are removed on the next reboot upon node' start. They should never be removed by a human.
