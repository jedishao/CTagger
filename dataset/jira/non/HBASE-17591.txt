Update documentation to say distributed log replay defaults to 'false'
As consequence of HBASE-12577, `hbase.master.distributed.log.replay` is no longer default true. But in the documentation, it is still noted as default true as follows:

To enable distributed log replay, set hbase.master.distributed.log.replay to true. This will be the default for HBase 0.99 (HBASE-10888).
