be sure that bean wiring support optional properties with {{?value}} syntax
Make sure that bean wiring support something like:


 flow: 
    beans: 
      - name: local-es
        type: "#class:org.apache.camel.component.elasticsearch.ElasticsearchComponent"
     properties: 
         - propname: {{?propvalue}}


where propvalue might or might not be present in the properties and should be set only if present.
