Adding Network Counters in ABFS
Network Counters to be added in ABFS:



CONNECTIONS_MADE
Number of times connection was made with Azure Data Lake


SEND_REQUESTS
Number of send requests


GET_RESPONSE
Number of response gotten


BYTES_SEND
Number of bytes send


BYTES_RECEIVED
Number of bytes received


READ_THROTTLE
Number of times throttled while read operation


WRITE_THROTTLE
Number of times throttled while write operation

Adding these counters as part of AbfsStatistic already made in HADOOP-17016.
Increment of counters across Abfs Network services.
