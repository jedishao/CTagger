Allow wait timeout and number of RS's to be configurable in RSGroups tests.
In trying to help in debug the RSGroup tests, the wait timeout being a fixed value can cause failures for the test due to general slowness. It would be nice if the wait timeout could be configurable.
Using more regionservers (than the default of 4) could also be configurable.
Finally, it also appears that IntegrationTestRSGroups doesn't function with a minicluster (only against a distributed cluster).
