Incorrect cassandra.logdir on Debian systems
The Debian packaging patches bin/cassandra to use /var/log/cassandra for logs, it does so conditionally however, only if CASSANDRA_LOG_DIR is unset. This occurs after cassandra-env.sh is sourced though, which also sets CASSANDRA_LOG_DIR if unset (to $CASSANDRA_HOME/logs).  The result is that -Dcassandra.lodir is set to /usr/share/cassandra/logs on Debian systems.
