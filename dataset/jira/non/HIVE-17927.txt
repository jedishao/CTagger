Pre-Warm Hive on Spark Driver
Hive-on-Spark has an option to pre-warm executors, it would be good to have an option to pre-warm the HoS driver.
Basically, submit the HoS application as soon as possible, rather than waiting until a query is ready to be submitted. This can help startup time for the first query run in a HoS session. The application can be setup in the background while queries are being compiled.
