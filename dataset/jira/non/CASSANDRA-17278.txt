Finalize and formalize canonical set of pre-commit tests for circleci
See wiki article
See dev list discussion
While a lot of good work went into this on CASSANDRA-16882 and subsequent tickets, there is still some dissent on the right set of canonical jobs we should require on circleci before a merge, when certain job suites might be acceptable to skip if ever, and the configuration output itself.
Success criteria here:
1. Ratify the canonical circleci job suites to be run on all commits pre-merge if using circleci
2. Determine JDK's that need to be run pre-merge
3. Update the circleci config files to match this by default
4. Determine a majority consensus on whether circle should auto-run on push or not, and integrate a "one-command" way to toggle to the alternate version + correct provisioning size (low, mid, high) to smooth out dev workflows and satisfy multiple competing personas
5. Document the above in the Cassandra confluence wiki and testing sites
