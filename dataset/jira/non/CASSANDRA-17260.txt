Antora site.yml in-tree so in-tree html can be generated (again)
With the migration of the doc to asciidoc and antora we (intentionally) lost the ability to generate in-tree html via `ant gen-doc`.
This was intentional as our first priority was publishing the docs to the website.
But it is also beneficial to have plain html docs bundled into our packages (tar, deb, rpm, docker, etc), so tackling this was expected and planned for a later date.
