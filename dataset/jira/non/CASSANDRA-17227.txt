Synthetic heap OOM generation should only run with the presence of on OOM JVM options
The synthetic heap OOM generation introduced in CASSANDRA-15214 assumes Cassandra always runs with the related on OOM JVM options, e.g. -XX:+ExitOnOutOfMemoryError. So that the synthetic heap OOM can trigger the handler.
If the Cassandra process does not start with any of those on OOM options, the synthetic heap OOM generation should not run.
