XPath support for namespaces
Issue HIVE-1027 added UDF for XPath queries. However, it does not support setting namespaces (as mentioned in this comment).
Unfortunatelly, for real world xml data, it is quite hard to use the feature without the namespaces. The underlying Java API supports the namespaces, so it should be quite easy - just to allow some additional parameter for namespace setting. This is how a similar function on Oracle is defined.
