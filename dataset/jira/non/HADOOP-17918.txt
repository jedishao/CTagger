memory field in SequenceFile.Sorter java int overflow
memory field in SequenceFile.Sorter, can cause run method in SequenceFile.Sorter.SortPass enter an endless loop.
If you set the "io.sort.mb" attribute to a value greater than 2050, as a result of


this.memory = conf.getInt(CommonConfigurationKeys.IO_SORT_MB_KEY, CommonConfigurationKeys.SEQ_IO_SORT_MB_DEFAULT) * 1024 * 1024;

, memory field java int overflow, may become negative, so memoryLimit field in SequenceFile.Sorter.SortPass will be negative too, lead to run method in SequenceFile.Sorter.SortPass enter an endless loop.
