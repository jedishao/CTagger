Provide fallbacks for callqueue.impl and scheduler.impl
As mentioned in parent Jira, we should provide default properties for callqueue.impl and scheduler.impl such that if properties with port is not configured, we can fallback to default property. If "ipc.8020.callqueue.impl" is not present, fallback property could be "ipc.callqueue.impl" (without port). We can take up rest of the callqueue properties in separate sub-tasks.
