Add support in CQLSH for COPY FROM / TO in compact Parquet format
CQL supports only CSV as a format for import and export. A binary big data format such as Avro and/or Parquet would be more compact and highly portable to other platforms.
Parquet does not require a schema, so it appears the easier format to support.
The existing syntax supports adding key value pair options, such as FORMAT = PARQUET
     COPY table_name ... FROM 'file_name'[, 'file2_name', ...] 
                     [WITH option = 'value' [AND ...]]
Side by side comparisons of CSV and Parquet show a 80% plus saving in disk space.
