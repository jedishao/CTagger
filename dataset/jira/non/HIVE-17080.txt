Overwrite does not work when multi insert into same table different partition
Repo:

create table foo(k string, v string) partitioned by (dt string) stored as orc;
insert into table foo partition(dt='00') values('k1', 'v1');
insert into table foo partition(dt='01') values('k2', 'v2');


Run query:

from (
select * from foo
) t
insert overwrite table foo partition(dt='00') select t.k, t.v where t.k = 'k1'
insert into table foo partition(dt='01') select t.k, t.v where t.k = 'k2';


Note that is overwrite for partition dt='00'
expect result

0: jdbc:hive2://localhost:10000/default> select * from foo;
+--------+--------+---------+
| foo.k  | foo.v  | foo.dt  |
+--------+--------+---------+
| k1     | v1     | 00      |
| k2     | v2     | 01      |
| k2     | v2     | 01      |
+--------+--------+---------+
4 rows selected (0.125 seconds)


Actual result:

0: jdbc:hive2://localhost:10000/default> select * from foo;
+--------+--------+---------+
| foo.k  | foo.v  | foo.dt  |
+--------+--------+---------+
| k1     | v1     | 00      |
| k1     | v1     | 00      |
| k2     | v2     | 01      |
| k2     | v2     | 01      |
+--------+--------+---------+
4 rows selected (0.125 seconds)


Explain result says MoveTask for partition dt = '0' repalce is false:
