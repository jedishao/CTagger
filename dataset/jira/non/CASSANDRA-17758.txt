URL for KEYS in Debian installation returns a redirect
On the page https://cassandra.apache.org/doc/latest/cassandra/getting_started/installing.html the Debian package instructions has a line:
`curl https://www.apache.org/dist/cassandra/KEYS | sudo apt-key add -`
that should be updated to
`curl https://downloads.apache.org/cassandra/KEYS | sudo apt-key add -`
 
https://www.apache.org/dist/cassandra/KEYS currently returns a redirect.
