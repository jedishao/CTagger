camel-microprofile-config: CamelMicroProfilePropertiesSource loadProperties cannot handle empty property values
Since CAMEL-17831 any routes in Camel Quarkus that contain property placeholders have started to fail.
https://github.com/apache/camel-quarkus/issues/3739
It seems that CamelMicroProfilePropertiesSource.loadProperties cannot deal with empty String properties as it treats the property lookup as mandatory.
