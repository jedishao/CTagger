Move metastore specific itests
There are a number of tests in itests/hive-unit/.../metastore that are metastore specific.  I suspect they were initially placed in itests only because the metastore pulling in a few plugins from ql.
Given that we need to be able to release the metastore separately, we need to be able to test it completely as a standalone entity.  So I propose to move a number of the itests over into standalone-metastore.  I will only move tests that are isolated to the metastore.  Anything that tests wider functionality I plan to leave in itests.
