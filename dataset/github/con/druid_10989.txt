NPE happens when index task provide empty HDFS file list and the time trunk lock is disabled
The NullPointerException "taskLockHelper is not initialized yet" will happen for index task with the following conditions:
- append mode
- disable time trunk lock
- empty input HDFS file list 

### Affected Version
0.20
