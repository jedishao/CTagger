Unable to acquire RLock after failover - "none of slaves are synced" (even with latest build)
<!--
Try Redisson PRO https://redisson.pro with ultra-fast performance and support by SLA.
-->

**Expected behavior**
All redisson nodes should be able to continue to obtain an RLock after a failover
**Actual behavior**
One node is no longer able to obtain an RLock lock after performing a redis failover

**Steps to reproduce or test case**
1. Create elasticache redis cluster with cluster mode enabled, multiAZ enabled
2. Create and connect 2 instances of Redisson, and create an RLock (same lock name utilized in both nodes)
3. Trigger aws elasticache maintenance/failover test:
`aws elasticache test-failover --replication-group-id dev-generic-failtest --node-group-id 0001`

**Redis version**
6.2.6, 6.0.5

**Redisson version**
3.18.1-SNAPSHOT (I built the latest master branch as of today 11-29-2022, which includes everything up to and including commit `44ca1122603897c1971f8800a55ec6944f442079`)

I saw the commit since latest milestone for https://github.com/redisson/redisson/issues/4621 so I wanted to test with this fix, however it seems this commit did not solve this problem in this case.

**Redisson configuration**
```
  Config config = new Config();
  ClusterServersConfig clusterServers = config.useClusterServers()
          .setRetryInterval(3000)
          .setTimeout(30000)
          .setReadMode(ReadMode.SLAVE)
```
- Using a TLS/SSL connection via "rediss://" connection string to the AWS elasticache configuration endpoint
- We are also using a nameMapper
- Rest of configuration is defaults

I created a simple test application to confirm and reproduce this issue (simple use of local cached maps and RLock). 2x instances of the same application attempt to get the same lock, and when one gets it is then sleeps for 5s to emulate work and releases). The above exception repeats whenever attempting to acquire the RLock forever on this node.  The other node (same application) operates just fine.  This is error scenario repeatable.

Sample code:
```
    MainApp() {
        LOG.info("Starting up test...");

        int count = -1;
        RLocalCachedMap<Object, Object> testMap = redissonConnection.getRedisson()
                .getLocalCachedMap("cachedmap", LocalCachedMapOptions.defaults().syncStrategy(LocalCachedMapOptions.SyncStrategy.UPDATE)
                        .reconnectionStrategy(LocalCachedMapOptions.ReconnectionStrategy.CLEAR));
        RLock rCacheInitializationLock = redissonConnection.getRedisson().getLock("cachedmap_lock");

        testMap.preloadCache();
        String shortId = redissonConnection.getRedisson().getId().substring(0, 7);

        testMap.put(shortId + "_increasing", ++count);
        testMap.put(shortId + "_timestamp", System.currentTimeMillis());
        Map<Object, Object> localCachedMap = testMap.getCachedMap();

        LOG.info("starting main loop in " + this.getClass().getName());
        Thread printingHook = new Thread(testMap::clear);
        Runtime.getRuntime().addShutdownHook(printingHook);

        while (true) {
            try {
                LOG.info("getting lock, is currently locked: {}", rCacheInitializationLock.isLocked());
                rCacheInitializationLock.lock();
                LOG.info("obtained lock, beginning sleep");
                Thread.sleep(5000);
                LOG.info("mynode: {}, current time: {} local cache:", shortId, System.currentTimeMillis());
                localCachedMap.forEach((key, value) -> LOG.info("{}: {}", key, value));

                LOG.info("mynode: {}, current time: {} real cache:", shortId, System.currentTimeMillis());
                testMap.forEach((key, value) -> LOG.info("{}: {}", key, value));

                LOG.info("writing values");
                testMap.put(shortId + "_increasing", ++count);
                testMap.put(shortId + "_timestamp", System.currentTimeMillis());
                LOG.info("releasing lock");
                rCacheInitializationLock.unlock();
                LOG.info("released lock");
            } catch (Exception ex) {
                ex.printStackTrace();
            }
        }
    }
```
