awaitTermination() should throw an exception when start() is not be called
<!-- Please answer these questions before submitting a bug report. -->

### What version of gRPC-Java are you using?
1.39.0
### What is your environment?
<!-- operating system (Linux, Windows,...) and version, jdk version, etc. -->
Windows10 X64 OracleJDK8
### What did you expect to see?
`server.awaitTermination()` throw an exception when `server.start()` was not called.
### What did you see instead?
`server.awaitTermination()` is valid and block current thread, but the services are not actually start.
### Steps to reproduce the bug
```
io.grpc.Server server = NettyServerBuilder.forPort(6565).addService(new GreeterImpl()).build();
//server.start();
// Server is not started but awaitTermination() still block current thread.
server.awaitTermination();
```
