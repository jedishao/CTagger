Hi,

We recently upgraded our Redisson version from 3.13.3. to 3.17.7 and facing a weird Locking behavior in Redis Sentinel mode only, Standalone and Cluster Mode are working just fine. 

We are running a background thread which processing records from database and acquires distributed lock using lock.tryLock method. The application works fine for sometime but after 1-2 hours this background thread gets stuck on acquiring the lock and its hanged forever and its not even respecting the waitTime or leaseTime.

This issue is only observed is 3.17.7 version and Redis running in Sentinel mode.
In 3.13.3 this was working as expected as expected for all Redis modes.

We have not noticed any failover activity on server side when this issue happens. I think there's some regression that got introduced. 

Is there a solution to this problem?
Will upgrading to 3.18.1 solve this problem @mrniko ? 

P.S: We cannot upgrade beyond 3.18.1 because later version have introduced Kryo 5 as compile time dependency and we are running on Kryo 4.

Thanks.
