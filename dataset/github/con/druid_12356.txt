HttpRemoteTaskRunner#scheduleSyncMonitoring Infinite loop
HttpRemoteTaskRunner#scheduleSyncMonitoring may cause Infinite loop

### Affected Version
v21.1

### Description

The ChangeRequestHttpSyncer start and stop messages are printed cyclically on the master node.
like blow

![image](https://user-images.githubusercontent.com/13789954/159125355-dfe79739-26e6-49c4-83c8-41f00f626194.png)

```java
 private void scheduleSyncMonitoring()
  {
    workersSyncExec.scheduleAtFixedRate(
        () -> {
          log.debug("Running the Sync Monitoring.");

          try {
            for (Map.Entry<String, WorkerHolder> e : workers.entrySet()) {
              WorkerHolder workerHolder = e.getValue();
              if (!workerHolder.getUnderlyingSyncer().isOK()) {
                synchronized (workers) {
                  // check again that server is still there and only then reset.
                  if (workers.containsKey(e.getKey())) {
                    ...
                   // add and remove same worker in map iter loop
                    removeWorker(workerHolder.getWorker());
                    addWorker(workerHolder.getWorker());
                  }
                }
              }
            }
          }
          catch (Exception ex) {
            if (ex instanceof InterruptedException) {
              Thread.currentThread().interrupt();
            } else {
              log.makeAlert(ex, "Exception in sync monitoring.").emit();
            }
          }
        },
        1,
        5,
        TimeUnit.MINUTES
    );
  }
```
> add and remove same worker in map iter loop may cause infinite loop

removeWorker(workerHolder.getWorker());
addWorker(workerHolder.getWorker());
