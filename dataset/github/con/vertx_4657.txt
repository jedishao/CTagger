Verticle still serves event bus events after undeployment complete
### Version

4.4.1

### Context

Verticles serve event bus events even after undeployed.
This happens when on verticle `start(Promise)` method active eventloop thread switched to some other thread.
I don't know if that's expected behaivor, but result looks like a bug.

### Do you have a reproducer?
2 tests that shows this bug and correct one without an issue.
https://pastebin.com/Tzi5GGAq

### Steps to reproduce

1. Create a verticle which overrides start(Promise) make consumers and handle start promise in another thread.
2. Fire event, it processes.
3. Undeploy verticle and wait for undeployment
4. Fire event - it still processes

### Extra
I don't know if that intentional. But looks like you should switch back on eventloop thread after start promise is handled.
Docs not showing that it can cause that type of a problem.
