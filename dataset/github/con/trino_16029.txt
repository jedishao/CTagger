FTE can dead lock in certain cases
Introduced by https://github.com/trinodb/trino/pull/15514

It is possible when there's enough tasks to be scheduled in the queue to stop the split enumeration process. However it is possible for a number of tasks to be already running and have an incomplete set of splits. Since the split enumeration is blocked active tasks will not get the final splits assigned and never finish blocking the scheduling queue that blocks the split enumeration process.
