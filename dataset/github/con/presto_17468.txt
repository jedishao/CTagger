ScanFilterAndProjectOperator performance skew in code gen filter
In my product environment with 98 worker (each worker has 40 cores with 80 processor).
jdk version : openjdk-11.0.10


Conside the query1 with filter fos_type='Android' :
`
SELECT "fdate", "fos_type", "fapp_version",count(distinct "fuser_id")
FROM db1.table1
WHERE "fdate" >= 20220302 AND "fdate" < 20220309 AND "fos_type" ='Android'
GROUP BY "fdate","fos_type", "fapp_version" ;
`

and query2 without fos_type filter：
`
SELECT "fdate", "fos_type", "fapp_version",count(distinct "fuser_id")
FROM db1.table1
WHERE "fdate" >= 20220302 AND "fdate" < 20220309 
GROUP BY "fdate","fos_type", "fapp_version" ;
`
query1 take 40 seconds while query2 only take 2 seconds.
 I repeat these query much times and the result is the same.
