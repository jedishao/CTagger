Thread Leak
### What version of gRPC-Java are you using?
1.33.0
### What is your environment?
<!-- operating system (Linux, Windows,...) and version, jdk version, etc. -->
OpenJRE 15 on Linux and Windows

### What did you expect to see?
I'm trying to receive chat messages via a long running stream.

### What did you see instead?
GRPC permanently spawns new threads while reading from the stream without closing them.

My function which i use to receive the messages looks like the following:
```
    @Override
    public void run() {
        if (receivingIterator == null) receivingIterator = chatSync.beginReceive(Empty.newBuilder().build());
        try {
            if (receivingIterator.hasNext()) {
                ChatMessage message = receivingIterator.next();
                lockedQueue.Put(message);
            }
        } catch (io.grpc.StatusRuntimeException e) {
            receivingIterator = chatSync.beginReceive(Empty.newBuilder().build());
            Bukkit.getLogger().info("Chat Sync Connection Failed created new one!");
        }
    }
```
