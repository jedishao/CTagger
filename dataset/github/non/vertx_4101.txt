Add promise.resolve and promise.reject
#### Describe the feature

In javascript, the [Promise API](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise#static_methods) provides two useful utility methods `Promise.resolve` and `Promise.reject` for quickly turning a value into something wrapped by a promise. It would be nice to have this feature included with the core Promise.java class.

#### Use cases

For example, I've seen the [following](https://github.com/eclipse-vertx/vert.x/blob/11ab144725e551be591118831377101015e1392c/src/main/java/io/vertx/core/shareddata/impl/AsynchronousCounter.java#L41) [code](https://github.com/eclipse-vertx/vertx-sql-client/blob/cbfcbe635cf1dae84f20c1ad47d5feab01160b07/vertx-sql-client/src/main/java/io/vertx/sqlclient/impl/SqlClientBase.java#L111) [snippet](https://github.com/eclipse-vertx/vertx-http-proxy/blob/68216557cba5cc3ad7aa309f3d2ee2c37c1cb3d1/src/main/java/io/vertx/httpproxy/impl/HttpProxyImpl.java#L263) used in the codebase

```java
protect void myFunc () {
  // ...
  Promise<String> promise = Promise.promise();
  promise.complete("Some val");
  return promise.future();
}
```

which is rather verbose. It would be nice if I could just write

```java
return Promise.resolve("Some val").future();
```
for those last three lines.
