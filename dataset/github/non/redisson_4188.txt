Major Performance Degradation in RedissonScoredSortedSet.readAll function starting from redisson 3.10.0
**Expected behavior**
Response should be received within 1-2 seconds

**Actual behavior**
Response is received in around 1 Hour 20 minutes in following versions in production system -
redisson (3.13.6) and netty (4.1.52.Final) 
redisson (3.14.1) and netty (4.1.54.Final)
redisson (3.15.0) and netty (4.1.58.Final)
redisson (3.16.8) and netty (4.1.73.Final)

Performance is degraded starting from redisson version 3.10.0, in version 3.9.1 its quick within 1-2 seconds.

**Steps to reproduce or test case**

Following program can be used to visualize the performance degradation not exactly same with production system.

```
import java.io.File;
import java.io.IOException;
import java.text.SimpleDateFormat;
import java.util.Date;
import org.redisson.Redisson;
import org.redisson.api.RScoredSortedSet;
import org.redisson.api.RedissonClient;
import org.redisson.config.Config;

public class TopologyRedisClient
{
   public static void main(String[] args) throws IOException
   {
      Config config = new Config();
      config = Config.fromYAML(new File("./sentinel-topo.yaml"));
      RedissonClient redisson = Redisson.create(config);

      RScoredSortedSet<Object> scoredSortedSetStartTime = redisson.getScoredSortedSet("sie-topo:idsByStartTime");
      RScoredSortedSet<Object> scoredSortedSetEndTime = redisson.getScoredSortedSet("sie-topo:idsByEndTime");

      int documentsToInsert = 0;
      int loopSize = 1;
      if (args.length != 0)
         loopSize = Integer.valueOf(args[0]);
      if (args.length >= 2)
         documentsToInsert = Integer.valueOf(args[1]);
      for(int i =0 ; i <documentsToInsert; i ++)
      {
          boolean startAdded = scoredSortedSetStartTime.add(i, "FixedString Value" + i);
          boolean endAdded = scoredSortedSetEndTime.add(i, "FixedString Value" + i);
          if (i !=0 && i % 100000 == 0 )
              System.out.println("Inserted count;" + i );
      }

      new Thread(new RedisThread(loopSize, scoredSortedSetStartTime, scoredSortedSetEndTime)).start();
   }

   static class RedisThread implements Runnable{
      int loopSize;
      RScoredSortedSet<Object> scoredSortedSetStartTime;
      RScoredSortedSet<Object> scoredSortedSetEndTime;


      RedisThread(int loopSize, RScoredSortedSet<Object> scoredSortedSetStartTime, RScoredSortedSet<Object> scoredSortedSetEndTime)
      {
         this.loopSize = loopSize;
         this.scoredSortedSetEndTime = scoredSortedSetEndTime;
         this.scoredSortedSetStartTime = scoredSortedSetStartTime;
      }

      @Override
      public void run(){

         for(int i =0 ; i <loopSize; i ++)
         {
            System.out.println(new SimpleDateFormat("yyyy-MM-dd HH:mm:ss.SSS").format(new Date()) + ";Scored startTime set sizeOnly = "  + scoredSortedSetStartTime.size());
            int readAllSize = scoredSortedSetStartTime.readAll().size();
            System.out.println(new SimpleDateFormat("yyyy-MM-dd HH:mm:ss.SSS").format(new Date()) + ";Scored startTime set readAll size = "  + readAllSize);
            System.out.println(new SimpleDateFormat("yyyy-MM-dd HH:mm:ss.SSS").format(new Date()) + ";Scored endTime set sizeOnly = "  + scoredSortedSetEndTime.size());
            readAllSize = scoredSortedSetEndTime.readAll().size();
            System.out.println(new SimpleDateFormat("yyyy-MM-dd HH:mm:ss.SSS").format(new Date()) + ";Scored endTime set readAll size = "  + readAllSize);
         }
      }
   }
}
```
