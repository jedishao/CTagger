trying to add same ranom uuid to every row
```
with data as (
   select uuid()
)
SELECT *
FROM fruits 
  cross join data;
```

Expected:
       every row to to have the same uuid
Actual:
       every row has a different uuid

only workaround I found is:

```
with runid as (
   select uuid() as runid
),
runidf as (
   select count(*), runid from runid group by runid
),
fruitswithid as (
     select *
     from fruits, runidf
)
select * from fruitswithid
```
