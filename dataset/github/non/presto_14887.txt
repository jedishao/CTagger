nearest_point function
I would be interested if Presto's Geospatial functions could be expanded to include something similar to the ST_ClosestPoint function in PostGIS.

Suppose I have a point A and a polygon P. I would like to find the point on P nearest to A. 

If there are multiple satisfying points on P with this property, returning any, all, or an arbitrary point would all be acceptable outcomes. Null could be returned if the input geometry is empty.
