Possible misbehaviour array_agg when using as window functions (with ordering by)
Hey,

I've found a weird behaviour in the `array_agg` when applying with window functions.
I want to understand if it's valid.

To simplify the question, let's assume we have a table like this:
```
A  |  B  |  C  |
----------------
1  | 2   | 1   |
2  | 2   | 2   |
```

And you write:
```
SELECT
    A,
    array_agg(A) OVER (PARTITION BY B) as array,
    count(A) OVER (PARTITION BY B) as count
FROM example
```

The result will be (as expected):

```
A  |  arr    | count |
------------
1  | [2,1]   | 2     |
2  | [2,1]   | 2     |
```
(note that the order of the array is random)

But, if you want to order the array somehow, you could write:

```
SELECT
    A,
    array_agg(A) OVER (PARTITION BY B ORDER BY C) as array,
    count(A) OVER (PARTITION BY B ORDER BY C) as count,
FROM example
```

Then, the result will be:
```
A  |  array    | count |
---------------------
1  | [1  ]  |    1     |
2  | [1,2]  |    2     |
```

And I was expecting is something like:
```
A  |  agg    | count |
------------
1  | [1,2]   | 2     |
2  | [1,2]   | 2     |
```
(the order of the array is based on C)

Do you think it is a valid behaviour?
