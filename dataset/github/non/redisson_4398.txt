When using Redisson with Quarkus, env variable override hides unrelated properties from application.properties
Hello, I'm facing an issue with the following details:

**Expected behavior**
When setting an env variable override, it shouldn't affect unrelated properties.

**Actual behavior**
When overriding something set in application.properties via env variable, ALL Redisson settings in application.properties are hidden and treated as null, only env variable properties are taken into consideration.

**Steps to reproduce or test case**
Use reproducer repo: https://github.com/peterhuba/redisson-env-variable-issue

Steps to reproduce:
* set environment variable to override property set in application.properties: export QUARKUS_REDISSON_SINGLESERVERCONFIG_PASSWORD=mbdev
* set breakpoint to RedisURI.class, line 28
* run quarkus dev --suspend, attach debugger
* observe that variable URI is null, even though the address is set in the application.properties
apparently overriding a property via an env variable overrides ALL Redisson properties, those not passes as env variable too are treated as null.

**Redis version**
6.2.6

**Redisson version**
redisson-quarkus-20: 3.17.4

**Redisson configuration**
quarkus.redisson.single-server-config.address=redis://localhost:6379
quarkus.redisson.single-server-config.password=wrongpassword
then using env variable QUARKUS_REDISSON_SINGLESERVERCONFIG_PASSWORD as outlined in reproducer's README.md
