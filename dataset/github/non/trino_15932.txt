Support changing Delta table protocol versions
We have several Delta Lake features in progress that require a minimum writer version of > 2:
- [Writing CDC Events](https://github.com/trinodb/trino/pull/15453)
- [Check Constraints](https://github.com/trinodb/trino/pull/14964) 

Users should be able to set a default writer/reader protocol version for newly created tables via a config property in `DeltaLakeConfig`, and should be able to upgrade the protocol versions of existing tables to enable new features. For reference, the Iceberg version of this uses `ALTER TABLE SET PROPERTIES` [link](https://trino.io/docs/current/connector/iceberg.html#alter-table-set-properties).
