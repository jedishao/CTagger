UnsupportedOperationException after Netty 4.1.60 update
### What version of gRPC-Java are you using?
1.36.0

### What is your environment?
macOS, jdk11

### What did you expect to see?
Server can process a request which contains `content-length` header.

### What did you see instead?
A [change in Netty 4.1.60](https://github.com/netty/netty/commit/89c241e3b1795ff257af4ad6eadc616cb2fb3dc4#diff-09d9f8d0eacbca5a34ea3b3d3817b0adc115bf21d7908e976447073df0fd92fcR403) introduces usage of the `Http2Headers#setLong(..)` method, but grpc-java's custom header implementations do not implement this method (e.g. throw `UnsupportedOperationException`).
