CVEs in Netty dependency
There are multiple moderate security issues in the netty version (4.1.59.Final) brought in by the Redisson library. See https://github.com/netty/netty/security/advisories where 4.1.77.Final is the most recent version with fixed CVEs (4.1.82.Final is absolute latest right now).

This may not generally be an issue when communicating with trusted Redis servers, but brought into an application that also uses netty with other sources, it could be harder to use a safe version of netty.
