# Add support of access control for nested columns 

For nested columns, our current access control only supports the top level columns. We want to add support of access control to more complex data structures. 

Proposed API https://docs.google.com/document/d/1nnVDsrMHjITRLh91yPzUH7-9YiH4DX71ZyAqktva6sI/edit#
