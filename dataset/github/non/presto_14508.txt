Presto ignores 'left' or 'full' when doing joins
Hi!  Even if I put 'left' or 'full', Presto does not actually perform a 'left' or 'full' join.

I'm guessing there is a built in option to change this.  It feels like the default should be to act like SQL (and do left or full when specified).  My configs don't have any join properties set.
https://prestodb.io/docs/current/admin/properties.html

I'm curious if this is an issue with the Pinot connector.

I can give more DB schema if needed.  I'm guessing this is a common issue.
I'm using a recent image: apachepinot/pinot-presto:0.236.0


------------------------------

presto> select platforms.platform_id as "platform.platform_id",
platforms.name as "platform.name",
date(date_trunc('day',events.timestamp)) as "events.date", sum(events.clicks) as "events.clicks"
from mysql.adsmgr.platforms as platforms
left join pinot.default.events as events
on events.platform_id = platforms.platform_id
where date(date_trunc('day',events.timestamp)) >= date('2020-04-01')
and date(date_trunc('day',events.timestamp)) < date('2020-04-07')
and platforms.platform_id = 1
group by platforms.platform_id, platforms.name, date(date_trunc('day',events.timestamp))
order by platforms.platform_id asc, platforms.name asc, date(date_trunc('day',events.timestamp)) asc
limit 100;
