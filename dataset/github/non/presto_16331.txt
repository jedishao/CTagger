Correct the FROM clause of the MV relation union-ed when expanding an MV
The FROM clause of the MV Relation comprising UNION is not correct, https://github.com/prestodb/presto/blob/cf2011ef6744fbba3325e02b6cc46cd15e644664/presto-main/src/main/java/com/facebook/presto/sql/analyzer/StatementAnalyzer.java#L1367

We should always do
```sql
...
UNION ALL
SELECT * FROM my_mv
```
when expanding an MV.

That is, if an original query against my_mv is
```sql
SELECT my_col
FROM (
    SELECT my_col
    FROM my_mv
) t
```

After query rewrite, it should be like
```sql
SELECT my_col
FROM (
    SELECT my_col
    FROM (
        mv_def_sql_with_partition_predicates
        UNION ALL
        SELECT * FROM my_mv
    ) my_mv
) t
```

However, what we have right now seems to be
```sql
SELECT my_col
FROM (
    SELECT my_col
    FROM (
        mv_def_sql_with_partition_predicates
        UNION ALL
        SELECT *
        FROM (
            SELECT my_col
            FROM my_mv
        ) t
    ) my_mv
) t
```
