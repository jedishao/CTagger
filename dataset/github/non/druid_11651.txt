Improve exception message for invalid kafka configuration
### Description

There is a HTTP 500 error when using the Load-Data wizzard to load data from kafka with an invalid kafka configuration. 
The error shows as follows

![image](https://user-images.githubusercontent.com/6525742/131681364-c03d9be6-cce5-4c58-8f13-9af395fe4d59.png)

This error message is helpless and gives no hint on how to fix it. Instead we need to check the error log of overlord or the HTTP response for more information.

The HTTP response shows

```json
{
"cause1":"org.apache.kafka.common.config.ConfigException: Invalid url in bootstrap.servers: 127.0.0.1",
"servlet":"default",
"cause0":"org.apache.kafka.common.KafkaException: Failed to construct kafka consumer",
"message":"org.apache.kafka.common.KafkaException: Failed to construct kafka consumer",
"url":"/druid/indexer/v1/sampler",
"status":"500"
}
```

Only after seeing these messages I know that this problem is caused by the invalid `bootstrap.servers` which misses the port number by accident.

To improve the user experience, I'm suggesting to improve error message by:
1.  showing the `message`, `cause0` , `cause1` fields on the web-console to give more error details
2. catching the `org.apache.kafka.common.config.ConfigException` when constructing `KafkaConsumer` to give more accurate exception messages

I will open a PR later to do this.
