Redisson can't (de)serialize Java records (Java 17)
**Expected behavior**
Being able to store and retrieve Java 17 records to/from Redis using Redisson.

Whenever we call either `RBucket#get` or `RBucket#set` method with a Java 17 record instead of a class, the following stacktrace is thrown:

This seems to be an issue with the `jboss-marshalling` (https://github.com/jboss-remoting/jboss-marshalling) dependency used by Redisson, and its use of the `Unsafe#objectFieldOffset` method here: https://github.com/jboss-remoting/jboss-marshalling/blob/main/api/src/main/java/org/jboss/marshalling/reflect/SerializableField.java#L58

**Steps to reproduce or test case**

Create any Serializable record class, for example:

```java
public record MyRecord(String value) implements Serializable {}
```

Then try to set an instance of this record in a Redis instance using Redisson. The provided stacktrace should occur.

**Redis version**
Docker image `bitnami/redis:5.0.11`

**Redisson version**
Redisson `3.17.1`

**Redisson configuration**
Roughly:

```java
    private Config buildSentinelRedissonConfig(final String[] sentinelEndpoints, final boolean checkSentinelsList, final String sentinelMasterName, final String requiredPassword, final int connectTimeout, final int readTimeout) {
        final Config config = new Config();
        final SentinelServersConfig sentinelServersConfig = config.useSentinelServers();

        sentinelServersConfig
                .setCheckSentinelsList(checkSentinelsList)
                .setMasterName(sentinelMasterName)
                .addSentinelAddress(sentinelEndpoints)
                .setTimeout(readTimeout)
                .setConnectTimeout(connectTimeout);

        if (!isNullOrEmpty(requiredPassword))
            sentinelServersConfig.setPassword(requiredPassword);

        return config;
    }

```
