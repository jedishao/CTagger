Quickstart Hadoop Container is built off of very old base image
Our Hadoop Quickstart container that can also be used for integration testing by devs is built on top of centOS 6.6. Just getting the image to build so I can run Hadoop Integration tests is proving to be a pain (issues with yum repositories, outdated curl libraries, etc.) I think it is in the best interest of the project to explore updating this image as it is very useful for the quickstart tutorial and is also helpful for integration tests.
