Postgresql partitionned tables not working anymore since 0.273

```
CREATE TABLE public.table (
	"date" date NOT NULL,
	customer_id varchar NOT NULL,
	network varchar NULL
)

CREATE TABLE partitions.table_202001 PARTITION OF public.table FOR VALUES FROM ('2020-01-01') TO ('2020-02-01');

```

There is nothing in the logs, a direct select return an error "table does not exist". 
Checking the git diff, I don't find anything specific which could be related. there was a driver update, but I tried the new version in a short program on my side and partitions are working as expected.
