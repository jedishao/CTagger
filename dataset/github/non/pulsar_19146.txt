### What did you expect to see?

The client should not receive duplicated responses for the same request

### What did you see instead?

Duplicated ack response for one ack request.
```shell
2023-01-04T19:33:49,654+0800 [pulsar-client-io-1-1] WARN  org.apache.pulsar.client.impl.ClientCnx - AckResponse has complete when receive response! requestId : 360167214930368447, consumerId : true
2023-01-04T19:33:49,654+0800 [pulsar-client-io-1-1] WARN  org.apache.pulsar.client.impl.ClientCnx - AckResponse has complete when receive response! requestId : 360167214930368448, consumerId : true
```

### Anything else?

This is caused by the brokerInterceptor. 
```java
 consumer.messageAcked(ack).thenRun(() -> {
                if (hasRequestId) {
                    ctx.writeAndFlush(Commands.newAckResponse(
                            requestId, null, null, consumerId));
                }
               brokerInterceptor.messageAcked(this, consumer, copyOfAckForInterceptor);
            }).exceptionally(e -> {
                if (hasRequestId) {
                    ctx.writeAndFlush(Commands.newAckResponse(requestId,
                            BrokerServiceException.getClientErrorCode(e),
                            e.getMessage(), consumerId));
                }
                return null;
            });
```
After processing the `messageAck` request,
1.  broker will send a successful response to the consumer
2. broker will interceptor by brokerInterceptor

If the brokerInterceptor throws an exception,  this exception is caught by the broker too, and then sends a failed response to the consumer.
This failed response has the same requestId as the successful response, this means the consumer will receive two responses for one request.What's more, the failed response will be discarded directly, since the requestId has been removed by the successful response. So we can't get any exception or error logs from both the broker or the consumer.

There are some other places has the same problem, like:  handleSubscribe, buildProducerAndAddTopic.
