Regression: Indexer nodes dont announce realtime segments in 0.19


### Affected Version

0.19

### Description

To reproduce, use indexer nodes with kafka ingestion and upgrade cluster to 0.19 from 0.18.1.

You will notice that none of the queries in realtime time range return any results. Distributed Tracing will show you that broker never sends query to indexer nodes.

Downgrading indexer node to 0.18 (while keeping rest of cluster in 0.19) makes the problem go away.
