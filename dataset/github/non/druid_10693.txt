 ```sql
select * from sys.segments 
where datasource = 'test_s_d_prabh_1'
order by "num_rows" desc
```

You'll notice the skewed segment sizes and number of rows.

<img width="1153" alt="Screen Shot 2020-12-13 at 10 51 13 PM" src="https://user-images.githubusercontent.com/4270624/102038907-76a75a80-3d96-11eb-9258-decd98501450.png">


Notice that [as per docs](https://druid.apache.org/docs/latest/ingestion/native-batch.html#single-dimension-range-partitioning), the config is a soft max, not hard:

> maxRowsPerSegment | Soft max for the number of rows to include in a partition

-------------------
