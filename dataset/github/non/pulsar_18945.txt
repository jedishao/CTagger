[improve] pulsar CLI tools should return exit code 1 instead of -1 on error

- [X] I searched in the [issues](https://github.com/apache/pulsar/issues) and found nothing similar.


### Motivation

The pulsar CLI seems to be inconsistent with respect to return codes.  Pulsar perf returns a `-1` which is actually invalid because it's outside the range of acceptable linux return codes (0-255), and thus it's translated to 255.
https://tldp.org/LDP/abs/html/exitcodes.html

Unless there is a use case for multiple return codes, and they are well documented, the pulsar CLI commands should stick with `0` for ok and `1` for error.

### Solution

Update pulsar-cli tools (pulsar-perf, pulsar-client, etc) to use `1` instead of `-1` as the exit code on error.
