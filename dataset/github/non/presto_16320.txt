Add PrestoConnection getProperties public method to be able to get presto connection properties at runtime
I'm using the QueryInterceptor interface in conjunction with externalCredentials presto connection property to provide authetnication tokens. 

The use case I'm working on requires the creation of unique tokens for every interaction. Therefore the originally token passed through the externalCredentials property might not be valid for upcoming interactions. (This all during a presto connection used through Tableau UI) .

New connections are created for this kind of interactions because the value of the externalCredentials property must be different for every one of them.  Currently there's no way to get the properties used to open the original connection. However there is a away of getting the PrestoConnetion instance in use through the interceptedStatement parameter in the QueryInterceptor preProcess method.  If we had a getProperties public method in PrestoConnection the properties used to open the initial connection could be read and used.  This will remove the need of rereading properies from a property file (which is the way the orinal connection works)
