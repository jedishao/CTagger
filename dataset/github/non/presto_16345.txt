The postgresql data field numeric is not recognized.
The fields whose type is numeric can be queried in the PG database.
However, run the query SQL statement in presto.
SHOW COLUMNS FROM postgresql.public.test_table;
It's not found.


pgDDL:
```
CREATE TABLE "public"."test" (
  "id" int4 NOT NULL,
  "num" numeric,
  "str" varchar(255) COLLATE "pg_catalog"."default",
  CONSTRAINT "test_pkey" PRIMARY KEY ("id")
)
;
```
prestoSQL:
```
SHOW COLUMNS FROM pg.public.test;
```
result:
```
id,integer,"",""
str,varchar(255),"",""
```
