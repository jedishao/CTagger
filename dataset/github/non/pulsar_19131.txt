[Bug] ttl expiration block due to no-recoverable exception even if autoSkipNonRecoverableData=true
### Search before asking

- [X] I searched in the [issues](https://github.com/apache/pulsar/issues) and found nothing similar.


### Version

Linux with pulsar 2.8.4 version

### Minimal reproduce step

1. set autoSkipNonRecoverableData=true 
2. create a new topic t and set TTL for it
3. create a subscription for this topic
4. produce some message on this topic
5. simulate `no such entry` or `ledger not exist`
6. see the TTL  expiration will block

### What did you expect to see?

TTL expiration task should skip the no-recoverable data if autoSkipNonRecoverableData=true
