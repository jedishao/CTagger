We are using redisson 3.17.6 in spring boot 1.5 application to communicate with AWS's Elasticache redis nodes.
The service experience lot of traffic at times for a few APIs which call redis (2500-4000 requests per minute)
During these spikes, at times we experience a lot of RedisResponseTimeoutException, RedisTimeoutException, etc

We have increased our netty thread count to 64. other parameters are set to defaults.
We do not see much detailed info on netty threads, we have increased from 32 to 64 & still seeing the issue. Not sure about the impact if it is brought to 128 or more. How do we calculate this ?
