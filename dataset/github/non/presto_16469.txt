Alluxio local cache won't reload the scope and quota after server restart
As we found in the code, local cache won't reload the scope and quota for the existing cache pages after server restart.  Because the scope and quota information are just in the memory so far.  The current implementation will set the global scope and unlimited quota to each page recovered from the local disk after the restart.

We think the cache scope and quota should be persisted in local cache's metadata.  

Let's track the discussion and the code change of this issue here.
