**Steps to reproduce or test case**
1.  Create Quarkus app and add extension
```
$ quarkus create app com.example:test-redisson:1.0
$ cd test-redisson
$ quarkus extension add org.redisson:redisson-quarkus-20:3.17.5
```
2. Update application.properties
```
quarkus.redisson.single-server-config.address=redis://redis-master.services:6379
quarkus.redisson.single-server-config.username=username
quarkus.redisson.single-server-config.password=some-password
quarkus.redisson.threads=3
quarkus.redisson.netty-threads=3
```
4. If using an VScode, it will complain about unknown properties, 
5. Perform Quarkus build , it will complain about the  unknown properties `quarkus build`
6. Performing Quarkus dev, will complain about the  unknown properties in runtime
