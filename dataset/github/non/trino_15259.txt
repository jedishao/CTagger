Document how the Hive connector can anonymously access a public S3 bucket
Issue #6127 requested a mechanism to allow the Hive connector to anonymously access a public S3 bucket. It turns out that it is possible to achieve this via configuration:

In the catalog properties, specify the `NoOpSigner` for anonymous S3 requests from the connector:

```
hive.s3.signer-class=com.amazonaws.auth.NoOpSigner
```

And, in `conf/metastore-site.xml`, specify the `AnonymousAWSCredentialsProvider`, either globally or on a per-bucket basis:

```xml
<!-- Global configuration -->
<property>
    <name>fs.s3a.aws.credentials.provider</name>
    <value>org.apache.hadoop.fs.s3a.AnonymousAWSCredentialsProvider</value>
</property>
```

or

```xml
<!-- Per-bucket configuration -->
<property>
    <name>fs.s3a.bucket.BUCKETNAME.aws.credentials.provider</name>
    <value>org.apache.hadoop.fs.s3a.AnonymousAWSCredentialsProvider</value>
</property>
```
