Feature request: Provide function to merge TDigest across multiple columns
Sometimes we need to create a TDigest from merging existing digests that appear in different columns of the source table.  It's possible to do this in a couple ways with UNION or CROSS JOIN UNNEST to get them in separate rows, but it would be nice to allow this behavior in `merge` or in a separate function.  

If there's no objections, I can take a swing at this.
