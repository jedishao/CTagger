Pulsar broker with TLS failing when function worker enabled
**Describe the bug**
Pulsar broker not able to start when functionsWorkerEnabled set to true.

Pulsar Broker has TLS Enc enabled
```
tlsRequireTrustedClientCertOnConnect=true
tlsCertificateFilePath=/volume/broker/certs/tls.crt
tlsKeyFilePath=/volume/broker/certs/tls.key
tlsTrustCertsFilePath=/volume/broker/certs/ca.crt
```
Pulsar Proxy has TLS Env enabled
```
brokerClientTrustCertsFilePath=/volume/broker/certs/ca.crt
tlsEnabledWithBroker=true
tlsEnabledInProxy=true
tlsCertificateFilePath=/volume/broker/certs/tls.crt
tlsKeyFilePath=/volume/broker/certs/tls.key
tlsTrustCertsFilePath=/volume/broker/certs/ca.crt
```
We have configured function_worker.yml to use same certificates to connect with broker. But it fails on startup due to next error:
`PKIX path building failed: sun.security.provider.certpath.SunCertPathBuilderException: unable to find valid certification path to requested target`

here is the config:

```
useTls: true
# For TLS:
# brokerServiceUrl: pulsar+ssl://localhost:6651/
pulsarServiceUrl: pulsar+ssl://localhost:6651/
# For TLS:
#webServiceUrl: https://localhost:8443/
pulsarWebServiceUrl: https://localhost:8443/
brokerClientTrustCertsFilePath: /volume/broker/certs/ca.crt

tlsEnabled: true
tlsCertificateFilePath: /volume/broker/certs/tls.crt
tlsKeyFilePath: /volume/broker/certs/tls.key
tlsTrustCertsFilePath: /volume/broker/certs/ca.crt
```
**To Reproduce**
Steps to reproduce the behavior:
1. Enable TLS on Broker
2. Enable functionsWorkerEnabled=true
3. Configure function_worker.yml to use TLS to connect broker

**Expected behavior**
If certificates are fine should be able to start up without issues


**Additional context**
We have made it work by changing a property on broker.conf to true
`tlsAllowInsecureConnection=true`
