For SELECT from MV, do not validate the original SELECT query shape
Right now, during SELECT from MV, we validate the original SELECT query shape in processMaterializedView(), which is not correct. What we should validate is the query shape of MV definition sql. We don't have restriction on the SELECT query against MV.
Current code: https://github.com/prestodb/presto/blob/cf2011ef6744fbba3325e02b6cc46cd15e644664/presto-main/src/main/java/com/facebook/presto/sql/analyzer/StatementAnalyzer.java#L1329
