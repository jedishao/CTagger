Since `405`, Mysql catalog that uses `zeroDateTimeBehavior=convertToNull`, fails with  `"localDateTime" is null`

```
connection-url=jdbc:mysql://localhost:3306?zeroDateTimeBehavior=convertToNull

// Mysql table
CREATE TABLE `test_tbl` (
  `dt_col` datetime DEFAULT NULL
);
INSERT INTO `test_tbl` VALUES ('0000-00-00 00:00:00');
```
