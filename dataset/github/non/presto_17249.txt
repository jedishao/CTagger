Clean up ColumnConverter's getTypeMetadata Interface 
While we are using `String` to represent type metadata, it would be good to have a separate `TypeMetadata` class or even interface in the next PR. Passing strings would be ambiguous to the interface. The new `TypeMetadata` class could contain `Optional<String>` field. If it is an interface, we can also have encoding and decoding methods out of it. That can help us to remove many `if (optional.isPresent())` branches
