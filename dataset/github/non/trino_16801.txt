When the string is converted to timestamp, an error occurs if there is a null value
version:410

hive connector

```
select count(1)
from tmp.tb1
where ptime>=20230327133000
and ptime<20230327133500
and btime>=timestamp '2023-03-27 13:30:00'
and btime<timestamp '2023-03-27 13:35:00';
```

`Query ... failed: Error opening Hive split hdfs://ns/user/hive/warehouse/tmp.db/tb1/ptime=20230327133000/1149649d418e3408-9e313ae500000002_1249039613_data.0.parq (offset=0, length=30682): null value in entry: [btime]=null`
