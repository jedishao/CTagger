When we choose to delete all the data of the specified datasource, delete the datasource directory in HDFS
### Description

Druid 0.18.

I use HDFS as the deep storage of Druid. When I use kill to delete all the segments of the specified datasource, I find that there is still a directory named datasource on HDFS, even if there is no data in the directory.
For example, if I delete all data whose datasource is test, there is still a directory named test in the specified storage location of hdfs.

### Motivation

Maybe this is unnecessary or even unreasonable.
When we choose to delete all the data of the specified datasource, it is meaningless to keep the datasource directory.
