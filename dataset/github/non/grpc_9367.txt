### What is your environment?

### What did you expect to see?
client code should correctly resolve target specifications and connect to servers just as it used to in 1.46.0 and earlier
### What did you see instead?
exceptions related to target name resolution / parsing after migration to 1.47.0
### Steps to reproduce the bug

given the following client code:
````java
public static void main(String[] args) throws Exception {
	final var channel = ManagedChannelBuilder
			.forTarget(args[0])
			.usePlaintext()
			.build();  // line 21
	final var storageService = RecordStorageGrpc.newBlockingStub(channel)
			.withDeadlineAfter(10, TimeUnit.SECONDS);
	final NewRecordId recordIdResponse = storageService.store(  // line 24
			Record.newBuilder().setContent("contents").build());
	channel.shutdown().awaitTermination(5, TimeUnit.SECONDS);
}
````
