Queries fail when using native text file reader on S3 objects with empty Content-Type header
Since Trino version 409, a previously working query has started to fail with `java.lang.IllegalArgumentException: Could not parse ''` when using the native text file reader.

The query is against a Glue table containing AWS ALB logs. The log files are gzip compressed and get delivered to S3 with an empty Content-Type header.

When `text-file.native-reader.enabled=false`, or with Trino version <=408, there query completes as expected.

When `text-file.native-reader.enabled=true` (the default since 409) then queries fail with this stacktrace:
