Cannot prepare statement when it contains `position` function 
I'm using trino 410 in docker, out of the box installation:

```
docker pull trinodb/trino
docker run -p 8080:8080 --name TRINO trinodb/trino
```

And connect to it with:

```
jdbc:trino://localhost:8080/memory/default
```

Try the following program:

```java
try (PreparedStatement s = connection.prepareStatement("""
    select position(? in substring(?, ?))
    """)) {

    int i = 1;
    s.setString(i++, "c");
    s.setString(i++, "abcdecde");
    s.setInt(i++, 5);

    try (ResultSet rs = s.executeQuery()) {
        while (rs.next()) {
            println(rs.getInt(1));
        }
    }
}
```
