presto-cli: mTLS support via cacert, cert, and key arguments
It would be nice to use mTLS to be able to connect to presto. We use a zero trust solution in front of all of our endpoints and in order to authenticate this is necessary. 

For example, with `curl` we can do something like this for an internally hosted service

```
curl \
  --key "$HOME/.ssh/company/login-key.pem" \
  --cacert "$HOME/.ssh/company/login-cacert.pem" \
  --cert "$HOME/.ssh/company/login-cert.pem" \
  https://service.internal.company.com:8443/route
```

Would like if we could feed in the same arguments into the presto cli as well. This would prevent us from having to setup a localhost proxy that passes in the mTLS records on our behalf and prevent us from having to configure presto-cli to hit that proxy instead of our real domain.
