Support Accumulo 2.x
Attempting to create an internal table using the Accumulo connector fails silently with no log messages and reports that the table was created successfully. Attempting to [create an external table](https://prestodb.io/docs/current/connector/accumulo.html#external-tables) using the Accumulo connector fails with an exception.

Per [discussion on the community slack](https://prestodb.slack.com/archives/C07JH9WMQ/p1615839501028200), this could be due to a jar mismatch and [changes in the underlying thrift protocol](https://prestodb.slack.com/archives/C07JH9WMQ/p1615845528032900?thread_ts=1615839501.028200&cid=C07JH9WMQ).

## Version Details

Accumulo 2.0.1
Presto 0.248
Zookeeper 3.5.5
