Query with REST API doesn't finish
Hi. I'm developing a python program to find long query and kill it then send Slack notification. I thought the simplest way to solve it, use [Presto REST API](https://prestodb.io/docs/current/develop/client-protocol.html). Our company uses presto EDA cluster for inner analysis usage, so it runs well, but my simple query with REST API doesn't run well. More detail, it runs with 100% RUNNING state, but it never stops.

Presto version: 0.254.1

```sql
-- Anomaly query detection
SELECT  query_id
    , query
    , queued_time_ms
FROM    system.runtime.queries
WHERE   (state = 'QUEUED' AND queued_time_ms >= 2 * 60 * 1000)
    OR  (state = 'RUNNING' AND analysis_time_ms >= 10 * 60 * 1000)
```

When query runs with Redash, there's no problem. Only qurey with REST API has problem.
