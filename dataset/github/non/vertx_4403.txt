Context differs in outbound interceptor from sending context
### Version

4.3.0 and 4.3.1

### Context

While lifting from 4.2.7 to 4.3.0 I discovered that our "contextual data" tests broke. It appears that the context used to send an eventbus message is a different instance than the one that runs the outbound eventbus interceptor, causing a (null) value to propagate instead of the current set value, due to empty context (local) data.

### Do you have a reproducer?

```java
@ExtendWith(VertxExtension.class)
class RegressionTest {

  @RegisterExtension RunTestOnContext rtoc = new RunTestOnContext();

  @BeforeEach
  void setUp(Vertx vertx, VertxTestContext testContext) {
    EventBus eb = vertx.eventBus();

    eb.addInboundInterceptor(
        ctx -> {
          Context context = Vertx.currentContext();
          System.out.println("(inbound) context : " + context);
          MultiMap headers = ctx.message().headers();
          String currentValue = Objects.requireNonNullElse(headers.get("key"), "");
          System.out.println("(inbound) current header value = " + currentValue);
          context.putLocal("key", currentValue);

          ctx.next();
        });

    eb.addOutboundInterceptor(
        ctx -> {
          Context context = Vertx.currentContext();
          System.out.println("(outbound) context : " + context);
          MultiMap headers = ctx.message().headers();
          String currentValue = Objects.requireNonNullElse(context.getLocal("key"), "");
          System.out.println("(outbound) current context value = " + currentValue);
          headers.add("key", currentValue);

          ctx.next();
        });

    testContext.completeNow();
  }

  @Test
  void aTest(Vertx vertx, VertxTestContext testContext) {

    String valueToPropagate = "myValue";

    vertx
        .eventBus()
        .consumer(
            "test-address",
            message -> {
              Context context = Vertx.currentContext();
              System.out.println("(consumer) context : " + context);
              String currentValue = context.getLocal("key");
              System.out.println("(consumer) currentValue = " + currentValue);
              testContext
                  .verify(() -> assertThat(currentValue).isEqualTo(valueToPropagate))
                  .completeNow();
            });

    Context currentContext = Vertx.currentContext();
    currentContext.putLocal("key", valueToPropagate);

    System.out.println("(test) context : " + currentContext);

    vertx.eventBus().send("test-address", "");
  }
}
````
