vertx run ./helloworld.js fails with "Failed in deploying verticle java.lang.ClassNotFoundException: ./helloworld.js"
### Version

4.1.3

### Context

Command line `vertx run` fails on javascript files using Vert.x 4 (4.1.3). Tried on Linux (Centos 7), MacOS (Monterey), with both Java 1.8.0 and 11.

The same command succeeds using Vert.x 3 (3.9.13).

See Steps to reproduce for details and stack trace.

Using Centos 7 and OpenJDK 11.
