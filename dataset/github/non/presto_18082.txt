Optimize hash computation for grouping sets
Currently we generate GroupId operator and then hash on all the groups. But this will repeatedly compute the hash for the same field. An optimization would be to compute individual hashes as an array and use the group id to combine them accordingly.

example: grouping sets( (x, y), (x, z))

will produces all (x,y) and (x,z) pairs and combine the value so we hash x twice, Instead if we build an array of hashes for x,y,z and then we can simply combine them as per the grouping set thus avoiding dupe computation of hash for x
