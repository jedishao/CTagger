SpatialJoin not activated for ST_Distance(p, q) BETWEEN d1 and d2
The conditions

```
ST_DISTANCE(p1.p, p2.p) < 4 AND ST_DISTANCE(p1.p, p2.p) > 2
```
and
```
ST_DISTANCE(p1.p, p2.p) between 2 and 4
```

are the same, but the first triggers a Spatial Join and the second does not.  Example queries:

```
EXPLAIN (TYPE DISTRIBUTED)
WITH points AS (
  SELECT
    ST_POINT(x, y) AS p
  FROM (
    VALUES
      (1, 1),
      (2, 2)
  ) AS t (x, y)
)
SELECT
  *
FROM points p1,
  points p2
WHERE
  ST_DISTANCE(p1.p, p2.p) < 4
  AND ST_DISTANCE(p1.p, p2.p) > 2
```

```
EXPLAIN (TYPE DISTRIBUTED)
WITH points AS (
  SELECT
    ST_POINT(x, y) AS p
  FROM (
    VALUES
      (1, 1),
      (2, 2)
  ) AS t (x, y)
)
SELECT
  *
FROM points p1,
  points p2
WHERE
  ST_DISTANCE(p1.p, p2.p) BETWEEN 2 AND 4
```
