Redisson on legacy app
I have a legacy application running Java 8 and Spring 4.0.9. Redisson is 3.17.5. Redis is 7.0.4
The app has been running ok like this for years.
The Redisson client is created like this:
```
  @Autowired
  public RedisCacheService(@Value("${AWS_REDIS_URL:}") String redisUrl) {
    LOG.info("Connecting to Redis at: {}", redisUrl);
    Config config = new Config();
    config.useReplicatedServers().addNodeAddress(redisUrl);
    redisson = Redisson.create(config);
    LOG.info("{} successfully initialized", RedisCacheService.class.getSimpleName());
  }
```
