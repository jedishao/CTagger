Support the SINH function
It's probably not the most important feature request, but I've noticed that trino supports:

- `COS` / `COSH`
- `TAN` / `TANH`
- `SIN`

But not `SINH`:
https://trino.io/docs/current/functions/math.html#trigonometric-functions

From a consistency point of view, would be nice to have it.

Workaround for `SINH(x)`:

```sql
(EXP(x * 2) - 1) / (EXP(x) * 2)
```
