Hyphens in column names fail in where clause
Using column names with hyphens in them in the where clause works in release 0.220.  In releases 0.224 and 0.227, I can no longer use column names with hyphens in them in the where clause.  Other field names with no hyphens work fine in the where clause.  Putting columns with hyphen names in the select clause still works fine.  

This query works:
```
select * from mydb.mytable
where "datehour" = '2019-11-26T17'
limit 1000;
```

This query fails:
```
select * from mydb.mytable
where "datehour" = '2019-11-26T17'
and "cs-host" = 'google.com'
limit 1000;
```
