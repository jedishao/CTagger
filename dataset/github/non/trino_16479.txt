Let io.trino.jdbc.Row implement java.sql.Struct
It's currently not possible to read a `ROW` projection using standard JDBC API (e.g. `java.sql.Struct`):

```java
try (Statement s = connection.createStatement();
    ResultSet rs = s.executeQuery("select row(1, 2)")
) {
    while (rs.next()) {
        System.out.println(rs.getObject(1));
        System.out.println(rs.getObject(1).getClass());
    }
}
```

This produces:

```
{1, 2}
class io.trino.jdbc.Row
```

Where that class in version `409` of the JDBC driver looks like this:

```java
public final class Row
{
...
}
```

It would be nice if this type implemented the `Struct` API for better interoperability
