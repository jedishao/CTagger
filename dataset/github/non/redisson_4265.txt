Writing a custom BaseCodec does not tell you that you should create a public constructor with ClassLoader
Hi, 

Thanks for the awesome work on that Redis client. 

I have a use case where I wanted to write my own `JsonJacksonCodec`, that is because I wanted full control over the `ObjectMapper` used for serialization.
