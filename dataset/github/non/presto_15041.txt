Query xxxx failed: Found string, expecting union 
The error message: **"Query xxxx failed: Found string, expecting union"** appears when executing a select statement for a table created as shown in the example below:

`create table dbo.pr_date( 
 mbr_brth_dt_sk timestamp
) 
with ( external_location = 'xxxx');`

If table is dropped and recreated changing the column name from **mbr_brth_dt_sk** to  **mbrbrth_dt_sk**  or **brth_dt_mbr_sk** select  issue is not observed.
