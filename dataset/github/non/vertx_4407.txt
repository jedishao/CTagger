Wrapped buffers
#### Describe the feature

Add one or more wrapped buffer methods in `io.vertx.core.buffer.Buffer` like the `wrappedBuffer` methods in Netty `io.netty.buffer.Unpooled`.

For example:
```java
  @GenIgnore(GenIgnore.PERMITTED_TYPE)
  static Buffer wrappedBuffer(byte[] bytes) {
    return buffer(Unpooled.wrappedBuffer(bytes));
  }
```

#### Use cases

This could eliminate the need to copy bytes in some scenarios and speed up programs.
