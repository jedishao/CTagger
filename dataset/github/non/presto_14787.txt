max_by and min_by queries fail with PageFile in LBM
In large batch mode with presto native format,  queries with `max_by` or `min_by ` sometimes fail, this is data dependent and not able to reproduce without customer data.

```
create table t1(nationkey int,  bool_features map<varchar, boolean>);
insert into t1 values (1, map(ARRAY['1','3'], ARRAY[True, False]));
select max_by(bool_features, nationkey) from t1 group by nationkey;
```
