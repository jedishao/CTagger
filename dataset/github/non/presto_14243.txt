Not reading fields that start with `$` of a MongoDB collection
As mentioned in #10918 some fields (columns) are not added, thanks to [this StackOverflow question](https://stackoverflow.com/questions/58846447/how-to-query-nested-fields-in-mongodb-using-presto)  I was able to add some fields and query over them. 

However, there is one field that has the next structure:
```
"place" : {
        "$ref" : "place",
        "$id" : ObjectId("XXXXX")
    }
```
I am only interested on the `$id`, so I modified the `_schema` to add that manually like this:

```
{
        "name" : "place",
        "type" : "row($id ObjectId)",
        "hidden" : false
}
```
