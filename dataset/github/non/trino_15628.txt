Dynamic filtering for right join with a outer join in the build source in FTE mode
For the specific scenario in https://github.com/trinodb/trino/pull/15608 (https://github.com/trinodb/trino/issues/15596), we disable dynamic filter collection in fault tolerant execution mode.
The main problem is that current logic for tracking the number of expected partitions for the DF consumer relies on only one DynamicFilterSourceFactory to exist. Making this work with coordination among multiple factories or through multiple consumers could be complicated.
It's not clear if this scenario is worth addressing as the input to such a dynamic filter is likely to be big (result of an outer join).
