ADD/DROP CATALOG(hive) statement with pluginClassloader cast exception
Duplicate ADD/DROP CATALOG(hive) in same catalogName, it occur `HiveTableHandle` Class CAST error.

![image](https://user-images.githubusercontent.com/30573693/227946745-40b458aa-30d4-408d-9b10-77fd41da92c5.png)

**Reproduce steps**:
1. CREATE CATALOG xxx
    using hive
    with("hive.metastore.uri" = 'thrift://127.0.0.1:9093', "hive.metastore.username" = 'xxx');
2. DROP CATALOG xxx
3. CREATE CATALOG again
4. select * from "xxx"."y"."z";
