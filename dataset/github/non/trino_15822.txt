Iceberg connector returns incorrect NULL when a field in row type doesn't exist in Parquet files
```sql
trino> CREATE TABLE iceberg.default.test (c1 row(x integer)) with (format = 'parquet');
spark> ALTER TABLE default.test ADD COLUMN c1.y integer;
spark> ALTER TABLE default.test DROP COLUMN c1.x;
trino> SELECT * FROM iceberg.default.test;
-- NULL
```

The last SELECT statement should return `{y=NULL}` instead of `NULL`. Other file formats (ORC & Avro) return `{y=NULL}` correctly.
