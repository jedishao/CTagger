Provide `role` property in JDBC client
Most modern access systems use a single SYSTEM role for RBAC. However Trino requires to configure catalog roles. This exposes complexity to end users as they have to understand this concept, which is only relevant for Hive.

Can we add a `role` property in the jdbc connector to set the system role?

This can be implemented within the clients using the existing API. For an example implementation, please have a look at https://github.com/trinodb/trino-python-client/pull/341
