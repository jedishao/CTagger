Set table type to MATERIALIZED_VIEW for materialized view after a stable Hive 3.0 upgrade
At the moment, with Hive 2.0, materialized views use TableType.MANAGED_TABLE in metastore.
https://github.com/prestodb/presto/blob/0b1c725441147ef18ea4c48cd9f1ec2d55562e5b/presto-hive-metastore/src/main/java/com/facebook/presto/hive/metastore/thrift/ThriftMetastoreUtil.java#L162

After a stable upgrade to Hive 3.0 which supports TableType.MATERIALIZED_VIEW, we should directly set table type to MATERIALIZED_VIEW when saving table metadata to metastore.
