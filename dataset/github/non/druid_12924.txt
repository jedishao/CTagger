Add useNativeQueryExplain to SQL Query context docs
The [configuration docs](https://druid.apache.org/docs/latest/configuration/index.html#sql) mention that `druid.sql.planner.useNativeQueryExplain` can be overridden per query by the context key `useNativeQueryExplain` .

`useNativeQueryExplain` should be added to [SQL query context](https://druid.apache.org/docs/latest/querying/sql-query-context.html) docs.
