Warn on logical operators AND and OR expressions without explicit parenthesization 
When there are complex queries - especially those generated by tools/scripts, mixing AND and OR freely without explicit parenthesization can have surprising results as the operator precedence may not be what the user expected/wanted.

For example:
```
select true or false and false;
 _col0                
-------
 true  

select (true or false) and false;
 _col0                
-------
 false 
```
So if during the AST building phase, if we see that an AND (OR) expression node is being built with OR(AND) expression on the left or right without explicit parentheses, we should warn the user about it.
