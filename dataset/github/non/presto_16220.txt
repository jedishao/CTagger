columnMappings structure of ConnectorMaterializedViewDefinition should contain mappings for multiple base tables
Right now during create mv, the columnMappings structure is only populated with the mapping of mv to only one base table, given it is deduced from Field.getOriginColumnName() of Analysis. In the case that mv sql has Join, Union, etc, that links more than one base tables, correct SELECT from & REFRESH needs the columnMappings to be populated for all base tables.
