Add a way to know what kind of MultiType is (List or Map)
#### Describe the feature
Add a way to know what kind of type MultiType is (list or map)
Currently you can only do that through reflection (by checking the map is null or not) or try/catch for get(index)

#### Use cases
Whenever having a response parser without exactly knowing what the command returns.

I have made a fork at https://github.com/OOP-778/vertx-redis-client and implemented MultiType#isMap(),  but if anyone of the contributors can implement it would be awesome!
