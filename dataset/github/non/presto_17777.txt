Migrate existing functions to adapt Runtime Metric unit
As unit is introduced to runtime metrics - https://github.com/prestodb/presto/issues/17633, functions like the [following one](https://github.com/prestodb/presto/blob/master/presto-hive-common/src/main/java/com/facebook/presto/hive/HiveFileContext.java#L82-L87) needs to adopt the new signature with unit.

```JAVA
    public void incrementCounter(String name, long value)
    {
        if (verboseRuntimeStatsEnabled) {
            stats.addMetricValue(name, value);
        }
    }
```
