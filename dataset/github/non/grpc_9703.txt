```

// stub.getCallOptions().getDeadline(); this is in the catch block of the above exception
```

I can reliably reproduce this.

Here's my code, at a high-level.
```java
private static SomeResponse sendRequestWith(int n) {
  final String target = getTarget(); // impure, target can change on subsequent calls
  if (target == null) {
    return null;
  }

  s = targetToStub.getKey(target);
  stub = s.withDeadlineAfter(5, TimeUnit.SECONDS);
  try {
    LOGGER.info(stub.getCallOptions().getDeadline().toString()); // 4.999579700s from now
    return stub.myRpcName(SomeRequest.newBuilder().setN(n).build());
  } catch (StatusRuntimeException e) {
    e.printStackTrace();
    LOGGER.info(stub.getCallOptions().getDeadline().toString()); // 4.997062700s from now
    LOGGER.info(Boolean.toString(stub.getCallOptions().getDeadline().isExpired())); // false
    return sendRequestWith(n);
  }
}
```
