Query failure (redirection missing) when reading Iceberg materialized view via Hive connector, with redirects enabled
The product test `TestIcebergHiveViewsCompatibility` ensures both an Iceberg connector with hive metadata backing and the hive connector play in concert when returning and using Views. With materialized views, they work in concert for listing the names. They fail when trying to `SELECT` from the MV using the hive connector. While I don't believe `SELECT` from Iceberg Materialized Views is supported by the Hive connector, the error message returned when running a select was `SerDe is not present in StorageFormat`. This originates from the `getInfo` Hive metadata call specifically the line:

```
Optional<String> tableDefaultFileFormat = HiveStorageFormat
                .getHiveStorageFormat(table.getStorage().getStorageFormat())
                .map(HiveStorageFormat::name);
 ```
