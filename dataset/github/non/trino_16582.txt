Syntax error prompt optimization
In the case of complex sql, the error message of the current sql syntax error is difficult for people to quickly locate the error location when we use jdbc. Can we optimize this?
As an example, for the following sql：
```sql
select * from tpcds.sf1.call_censdfsdfsdfsdfdsfdsfdsfdsfdsfdsfter'1'abchjdeqbjkfvbqekbvkw
```
currently:
```shell
Query failed (#20230316_094942_00004_c4rki): line 2:37: mismatched input ''1''. Expecting: '(', ',', 'CROSS', 'EXCEPT', 'FETCH', 'FULL', 'GROUP', 'HAVING', 'INNER', 'INTERSECT', 'JOIN', 'LEFT', 'LIMIT', 'MATCH_RECOGNIZE', 'NATURAL', 'OFFSET', 'ORDER', 'RIGHT', 'TABLESAMPLE', 'UNION', 'WHERE', 'WINDOW', <EOF>.
```
expected:
```shell
Query failed (#20230316_094942_00004_c4rki): line 2:37: mismatched input ''1'':
fdsfdsfter'1'abchjdeqbj
          ^^^
Expecting: '(', ',', 'CROSS', 'EXCEPT', 'FETCH', 'FULL', 'GROUP', 'HAVING', 'INNER', 'INTERSECT', 'JOIN', 'LEFT', 'LIMIT', 'MATCH_RECOGNIZE', 'NATURAL', 'OFFSET', 'ORDER', 'RIGHT', 'TABLESAMPLE', 'UNION', 'WHERE', 'WINDOW', <EOF>.
```
