Addition to Google Cloud Storage Configuration Properties
Currently, Trino supports only two properties to connect with GCS-based Hive.

1. hive.gcs.json-key-file-path
2. hive.gcs.use-access-token

For other connectors of GCS, there is an option to authenticate using service-account mail, private-key-id, and private-key. It will be good to have a feature on Trino wherein we can authenticate with GCS using hive using the above three pieces of information. 

For eg.

1. hive.gcs.service.account.mail
2. hive.gcs.service.private.key.id
3. hive.gcs.service.private.key
