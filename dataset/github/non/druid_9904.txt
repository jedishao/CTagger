Fail to compact overlapping segments
### Affected Version

Found in 0.16.x and 0.18.x.

### Description

Compaction task will create segments with `VersionedIntervalTimeline` conflicting when compacting overlapping segments without explicitly specifying segment granularity. Coordinator will constantly fails to poll latest segment records from metadata db when there is an error caused by `VersionedIntervalTimeline` conflicting. And therefore the indexing tasks will constantly fail on segment publishing stage.
