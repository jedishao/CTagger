I have gRPC bi-directional stream service using client side customized name resolver and load balancer. There is 10% possibilities the servers from cluster will crash after server get the request. I have to make the client retry the call iteratively 
 to the next server until I get the successful response.
The gRPC build in retry and my customized retry all work when server return corresponding status code like "UNAVAILABLE", however, the retry is not working for client time out with "DEADLINE_EXCEEDED" error. 

Because I have to return a `CompletableFuture`, I could not resolve it by adding call into a loop (suggested from here: https://github.com/grpc/grpc-java/issues/8177#issuecomment-841742274)
I found retry could work if I put some code into `onError`, it looks naive.
```
public void onError(final Throwable t) {
     retryCounter.incrementAndGet();
     if (Status.fromThrowable(t).getCode() == Status.Code.DEADLINE_EXCEEDED && retryCounter.get() < 3 ) {
         completableFuture.complete(helloWithRetry(header).join());
     } else {
         completableFuture.completeExceptionally(t);
    }
}

```

How could I retry the call gracefully?

```
   class HelloRetry {
        AtomicInteger retryCounter = new AtomicInteger(0);
        HelloRequest request;
        HelloRetry(final HelloRequest request, final Metadata header) {
            this.request = request;
        }

        CompletableFuture<HelloReply> helloWithRetry(final Metadata header) {
            GreeterGrpc.GreeterStub metadataStub = MetadataUtils.attachHeaders(noneBlockingStub, header);
            CompletableFuture<HelloReply> completableFuture = new CompletableFuture<>();
            StreamObserver<HelloRequest> requestStreamObserver = metadataStub.withDeadlineAfter(1 * 10, TimeUnit.SECONDS).sayHelloStreaming(
                new StreamObserver<HelloReply>() {
                    @Override
                    public void onNext(final HelloReply value) {
                        completableFuture.complete(value);
                    }

                    @Override
                    public void onError(final Throwable t) {
                        retryCounter.incrementAndGet();
                        completableFuture.completeExceptionally(t);
                    }

                    @Override
                    public void onCompleted() {
                    }
                });
            try {
                requestStreamObserver.onNext(request);
            } catch (RuntimeException ex) {
                requestStreamObserver.onError(ex);
            }
            requestStreamObserver.onCompleted();
            return completableFuture;
        }
    }

    public CompletableFuture<HelloReply> sayHelloStream(final HelloRequest request) {
        Metadata headers = new Metadata();
        headers.put(REQUEST_TENANT_NAME, "Test");
        headers.put(REQUEST_IDENTIFIER, request.getName());

        HelloRetry helloRetry = new HelloRetry(request, headers);
        CompletableFuture<HelloReply> completableFuture = helloRetry.helloWithRetry(headers);

        return completableFuture;
    }
}
```
