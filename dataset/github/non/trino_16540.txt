Add support for casting CHAR to JSON and vice versa
I'm using trino 410 in docker, out of the box installation:

```
docker pull trinodb/trino
docker run -p 8080:8080 --name TRINO trinodb/trino
```

Using connector:

```sql
use memory.default;
```

This is currently not possible:

```sql
select cast(cast('[]' as char(2)) as json)
```

It fails with:

> SQL Error [58]: Query failed (#20230314_101434_01595_cwcqn): line 1:8: Cannot cast char(2) to json

A `CHAR` type has to be cast to `VARCHAR` prior to casting it to `JSON`:

```sql
select cast(cast(cast('[]' as char(2)) as varchar) as json)
```

I don't really see a good reason for this limitation, though?
