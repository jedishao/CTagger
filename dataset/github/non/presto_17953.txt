Presto with JDK 16+ performance not good compare with AMD/ARM
I'm trying to test presto v0.273.2 performance with OpenJDK 16/17. But the release version cannot be launched. So I recompile presto with OpenJDK 16/17. But still has some exceptions. When compiling must add many JVM options like "--add-opens java.base/java.lang=ALL-UNNAMED" to maven and when launching must add the same options to jvm.config. And then I can test my workload. 

I tested performance with on 3 nodes(1 coordinator, 2 workers) on AWS cloud. It's to run SF10 TPC-H workload with m6i(ICX), m6g(ARM) and m6a(AMD). 
The result shows:
1. with OpenJDK 8, m6i got 1.15X speedup compare with m6g and 1.11X speedup compare with m6a. 
2. with OpenJDK 16, m6i got 1.08X speedup compare with m6g and 1.07X speedup compare with m6a.
3. with OpenJDK 17, m6i got 1.03X speedup compare with m6g and 1.00X speedup compare with m6a.

I also test with TPC-DS, the performance of some queries dropped nearly 50% with 16/17. Is it caused by the JVM options or have any other reasons? It seems that OpenJDK 16/17 even 18 support for presto is not good enough.

If you know the reasons for performance lost, please tell me.
