Presto's LEFT JOIN unnecessarily scans a table even if no columns are selected from it
A Left JOIN query does both table scan operations when the query output only references from the left side of the table scan, resulting in unnecessary table scan of the right-side table scan. 

![image](https://user-images.githubusercontent.com/32091981/103499135-e93ab180-4dfb-11eb-8c0a-0f32e5bb5533.png)

In this case, the output variables out of left table `t1` are guaranteed to be unique, therefore could prune the `t2` scan
