CertificateUtils can't parse private keys which contain the key type in the header/footer line
<!-- Please answer these questions before submitting a bug report. -->

### What version of gRPC-Java are you using?
1.52.1

### What is your environment?
Linux, Java 11

### What did you expect to see?

When calling  `io.grpc.util.CertificateUtils.getPrivateKey(InputStream is)` on an RSA private key which has a header of the value `-----BEGIN RSA PRIVATE KEY-----` I would expect the key to be returned.

### What did you see instead?

Instead it throws a `java.security.InvalidKeyException: Missing key encoding`

### Steps to reproduce the bug

Call the above method with a private key where the header and footer have the text "RSA" in the BEGIN/END lines.
