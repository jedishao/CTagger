NullPointerException if GET /admin/v2/namespaces/public/default/maxTopicsPerNamespace
**To Reproduce**

Start `apachepulsar/pulsar:2.10.0`

You can start Pulsar in docker with: `docker run -it -p 8080:8080 apachepulsar/pulsar:2.10.0 bin/pulsar standalone`

Wait for 30-60sec.

Then run

`curl localhost:8080/admin/v2/namespaces/public/default/maxTopicsPerNamespace`

or 

`pulsar-admin namespaces get-max-topics-per-namespace public/default`
