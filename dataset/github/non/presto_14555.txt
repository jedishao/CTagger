In the above profile, the jbyte_disjoint_arraycopy was all from copying the decompressed dictionary before any filter can be evaluated. This method is calling `dictionaryDataStream.next()` for each byte array, then truncate the string and update the offsets array. It can be optimized in two aspects:

1. Do not copy the dictionary if no rows pass the filter: this requires evaluating the filter on the dictionary without copying from InputStream to StreamReader.
2. Calculate total length and read the data in one shot
