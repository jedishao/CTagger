Extend `CREATE FUNCTION` syntax to support external function
## Syntax
On top of syntax proposed in #13254, Add `<external body reference>` to `<routine body>`
```
<routine body> ::= <return statement>  | <external body reference>

<return statement> ::= RETURN <expression>

<external body reference> ::= EXTERNAL [ NAME <external routine name> ]

<external routine name> ::= <identifier>
```

Add `JAVA` to `<language name>`
```
<language name> ::= SQL | identifier
```
