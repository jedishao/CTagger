Improve geometrical operations efficiency by using JTS instead of Esri 
Improve many geometrical operations  efficiency by using JTS instead of Esri.

- fix incorrect calculation of extreme points in certain cases.
- Polygon WKTs are now required to have closed loops, whereas previously Esri would close the loops for you.
- Certain invalid geometries will now throw an exception on construction, such as ``LINESTRING(0 0, 0 0, 0 0)``.
