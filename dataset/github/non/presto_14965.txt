target and filter types do not match: (ConnectorSession,Block,Object)Slice, (Block,int)Slice
Recently, I upgrade presto from 336 to 339, this sample query couldn't work anymore.
```
SELECT 
data_map[max_id]
FROM ( 
select 
map_agg(
	CAST(acc.id as VARCHAR), 
	map(array['name'],
		array[CAST(acc.name as VARCHAR)])
) as data_map,
max(CAST(acc.id as VARCHAR)) as max_id
FROM account acc GROUP BY acc.group 
)
```

**Analysis**
It seems related to https://github.com/prestosql/presto/pull/4343
in #4343, `Slice` type is removed from `io.prestosql.operator.scalar.MapSubscriptOperator#specialize`, so the targetHandler is ObjectHandler,
but it didn't removed from `io.prestosql.metadata.ScalarFunctionAdapter#getBlockValue`, it still return SliceHandler
