Consolidate default metrics set for all metrics-emitter extensions
Today, many contrib metrics-emitter extensions have their own way to define default set of metrics being emitted. For us, this is hard to maintain. For users, it could be frustrating to see different set of metrics depending on the emitter type they use. See https://github.com/apache/druid/pull/11554#discussion_r736187832 for more details. We should consolidate the way to define default set of metrics.
