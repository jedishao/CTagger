Drop tables does not work in Hive connector (schemas other than default)
Cluster is configured to have  `hive.security=sql-standard` which means Presto would depend on hive for authorization. But it fails to obey those permissions. 
A user is granted insert, delete, update permission on table but they are unable to perform DROP operations on the tables. 

> [4] Query failed (#20210423_015337_00486_tchca): Access Denied: Cannot drop a column from table staging

Note:   `hive.allow-drop-table=true` property  cannot be used when `hive.security=sql-standard`. Cluster fails to boot up.
