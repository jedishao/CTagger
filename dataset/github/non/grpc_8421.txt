Upgrade Android plugins to 4.x
Apparently the new versions _require_ using a `gradle.properties` with specifically set values, for all practical purposes. This will cause trouble because gradle.properties is generally reserved (at least by us) for local options specific to that developer. But now it needs to contain:

```
android.useAndroidX=true
android.enableJetifier=true
```

I don't know what to do about that; add gradle.properties to the repository and accept it will probably be accidentally changed or require devs to create it themselves. The CI can probably just pass `-P` on the command line to gradle if need be.
