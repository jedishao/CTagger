Coordinator full GC due to untracked memory in TableFinishOperator
To reproduce:
1. Set configuration property `hive.collect-column-statistics-on-write` as true.
2. Enable grouped execution and recoverable grouped execution
3. Use a wide table with > 1000 columns


What could be Improved:
1.  Memory used by column statistics data is not tracked.
2. Unnecessary hold of statistics data that should be discarded.
3. Unnecessary track of statistics data that is never accessed.
