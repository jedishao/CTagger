#### Other observations
- The problem occurs only with no explicit dimensions definition in ingestion spec. If I put the definitions `{ "name" : "zoneId", "type" : "string" }, { "name" : "multiValueDimension", "type" : "string" }` in the list of dimensions, it works correctly.
- The problem does not occur if instead of lack of the multi-value field, I put an array with a null or "" (empty string) value in ingested data. Instead of `{"zoneId":"1","timestamp":2524608061000}` -> `{"multiValueDimension": [null], "zoneId":"1","timestamp":2524608061000}` or `{"multiValueDimension": [""], "zoneId":"1","timestamp":2524608061000}`
- The problem occurs exactly after the intermediate flush on disk by playing with the `intermediatePersistPeriod` in ingestion spec. I tried difference values... 1M, 3M, 10M and the wrong result started to appear exactly after the intermediate persistence (tailed the task log and observed when it happened)
- The problem does not reproduce till the intermediate persistence and after hand-off. Once handed-off to histo nodes the result gets corrected.
