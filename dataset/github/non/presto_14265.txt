Refactored scheduler causes high coordinator CPU usage
The refactored scheduler (use-legacy-scheduler=false) can cause high cpu usage in the coordinator.  It looks like some issue of runaway threads, as turning off the legacy scheduler for all future queries did not mitigate the issue, and the cluster needed to be restarted. 

Based on a flamegraph from an affected cluster, 55% of cpu time was spent in  com/facebook/presto/execution/scheduler/SqlQueryScheduler.lambda$addStateChangeListeners$11
