**Is your feature request related to a problem? Please describe.**
No problem, but it would allow for increased security as well as a more AWS-native auth solution.

**Describe the solution you'd like**
It would be great if redisson could support the new IAM-based authentication tokens for AWS elasticache. This is a new feature that AWS has released in their redis engine v7:
[IAM release announcement](https://aws.amazon.com/about-aws/whats-new/2022/11/amazon-elasticache-supports-iam-authentication-redis-clusters/)
[IAM docs for elasticache](https://docs.aws.amazon.com/AmazonElastiCache/latest/red-ug/auth-iam.html)

It looks like it may require the ability to rotate out short lived tokens, thus we may need a way to provide a credential provider to redisson. Perhaps there is an interface that we can implement to provide a token to redisson, similar to the example in the AWS docs with lettuce.

Also would be important to make sure that long/persistent connections are able to continue to be supported beyond 12/24 hour windows.

**Describe alternatives you've considered**
Continue to utilize ACLs with user and usergroup.  This works, however IAM is more secure and doesn't require credential rotation.
