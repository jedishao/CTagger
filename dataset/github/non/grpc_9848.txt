I'm running into an issue with a maven build where, when any of `grpc-netty`, `grpc-netty-shaded`, or `grpc-okhttp` are updated beyond version 1.51.0 (I have seen this at least for versions 1.51.1, 1.51.3, and 1.52.1), the build will just mysteriously hang indefinitely. This issue does not seem to be occurring when updating other grpc maven dependencies, e.g. `grpc-core`, `gprc-stub`, or `grpc-protobuf`.

I have run into the same issue on multiple machines, multiple OSes, with multiple maven versions (including latest 3.8.7 + maven-compiler-plugin 3.10.1). The project is using Java 8.

I'm would venture a guess that this isn't an issue with grpc-java itself, so I'm happy to raise this question/issue elsewhere, but I'm wondering what might have changed with these particular versions to cause this to start happening, since it might help narrow down a simpler repro case. Thanks!
