Allow configuring read-only access in File Based System Access Control
Currently, As a part of Global level security authorization with File-Based Access Control, has only 2 roles: allow, none. There isn't a way to enforce a read-only role at a global level with the other two roles.

It will be good to add support for the read-only role with File-Based Access Control as well instead of just relying upon Read-Only System Access Control.
