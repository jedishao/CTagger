Postgresql connector - aggregate columns missing from view
I'm trying to query a view in Postgres, Presto can only see the count aggregate but not the sum aggregate column

```
presto> show columns from postgresql.tpcds.test_v;
 Column  |   Type   | Extra | Comment
---------+----------+-------+---------
 count   | bigint   |       |
 i_class | char(50) |       |
(2 rows)
```

The same issue happens with a materialized view
```
presto> show columns from postgresql.tpcds.test_mv;
 Column  |   Type   | Extra | Comment
---------+----------+-------+---------
 count   | bigint   |       |
 i_class | char(50) |       |
(2 rows)
```

The views definition in Postgres is as follows:

```
postgres=> select pg_get_viewdef('test_v', true);
             pg_get_viewdef
-----------------------------------------
  SELECT count(item.i_item_sk) AS count,+
     sum(item.i_current_price) AS sum,  +
     item.i_class                       +
    FROM item                           +
   GROUP BY item.i_class;
(1 row)

postgres=> select pg_get_viewdef('test_mv', true);
             pg_get_viewdef
-----------------------------------------
  SELECT count(item.i_item_sk) AS count,+
     sum(item.i_current_price) AS sum,  +
     item.i_class                       +
    FROM item                           +
   GROUP BY item.i_class;
(1 row)
```
