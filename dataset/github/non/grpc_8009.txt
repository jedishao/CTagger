XdsNameResolver does not handle resource revoked and then recovered correctly
If LDS resource is revoked, the xds lbs will be shutdown and switch to empty service config and pick_first, but when exactly the same resource is recovered after revocation, [`shouldUpdateResult`](https://github.com/grpc/grpc-java/blob/v1.36.0/xds/src/main/java/io/grpc/xds/XdsNameResolver.java#L632-L658) is always false, and therefore `updateResolutionResult()` is never called and new service config is never generated.
