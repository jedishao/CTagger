Auto clean up druid_supervisors table
### Description

druid_supervisors table contains terminated supervisors as well. Requesting for a feature wherein these entries are auto cleaned up based on parameters like kill parameters for segments.

Also have an option for cleaning up history.

This can be reproduced by creating a supervisor; terminating the supervisor and checking the druid_supervisors table.

### Motivation

In the absence of this, it would need a manual clean up of druid_supervisors metadata db table, which isn't desirable.
