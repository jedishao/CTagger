Rename primary branch and audit the code for non-inclusive language
This issue is to consider the following changes in language which are outdated and do not promote inclusivity in the community.

The first and most obvious starting point is to rename our primary branch from `master` to something different, preferably `main`.

Additionally, we should do an audit of the code and investigate if there's any instances of similarly non-inclusive language, such as "blacklist" => "blocklist", "whitelist" => "allowlist", etc.

I will keep this issue open until the technical community is satisfied that all references have been sufficiently renamed, and all tools have been updated to the new names.
