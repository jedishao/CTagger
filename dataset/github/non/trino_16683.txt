Add `set_union` aggregate function
Presto supports [`set_union`](https://prestodb.io/docs/current/functions/aggregate.html#set_union) aggregate function:

> `set_union(array(T)) -> array(T)`
> Returns an array of all the distinct values contained in each array of the input

Can we add it to Trino?

Workarounds:
use array handling:
```sql
array_distinct(flatten(array_agg(array_col)))
```
