[Python Schema] Incomplete schema with collections of Enums
**Describe the bug**
Enum symbols are not present in the python schema when the Enum is packed in an Array or a Map. Then, the schema verification done at server side is less precise.

**To Reproduce**
You can run the next tests with and without the proposition of fix.
