TypedJsonJacksonCodec fails to deserialize with "class java.util.LinkedHashMap cannot be cast to ..."
The following exception is thrown when using `TypedJsonJacksonCodec` with `RMap`:
```
Exception in thread "main" java.lang.ClassCastException: class java.util.LinkedHashMap cannot be cast to class
com.example.main.Foo (java.util.LinkedHashMap is in module java.base of loader 'bootstrap'; com.example.main.Foo is in
unnamed module of loader 'app')
```

Minimal code to reproduce:

```kotlin
data class Foo(val id: Int, val name: String)

fun main() {
    val redissonConfig = Config().apply {
        useSingleServer().apply {
            address = "redis://localhost:6379"
        }
    }
    val redissonClient = Redisson.create(redissonConfig)
    val objectMapper = ObjectMapper().registerKotlinModule()

    val fooSource = mutableMapOf(
        1 to Foo(1, "name")
    )

    val mapLoader = object : MapLoader<Int, Foo> {
        override fun load(key: Int?): Foo = fooSource[key]!!
        override fun loadAllKeys(): MutableIterable<Int> = fooSource.keys
    }
    val mapOptions = MapOptions.defaults<Int, Foo>().loader(mapLoader)
    val fooMap: RMap<Int, Foo> = redissonClient.getMap(
        "my-foo-map",
        TypedJsonJacksonCodec(Foo::class.java, objectMapper),
        mapOptions
    )
    try {
        // the first time we .get the value it works, because MapLoader is invoked, Redis gets populated, and it returns a value
        val myFoo = fooMap[1]

        // when we call it again, and value is already in Redis, we get
        // Exception in thread "main" java.lang.ClassCastException: class java.util.LinkedHashMap cannot be cast to class
        // com.example.main.Foo (java.util.LinkedHashMap is in module java.base of loader 'bootstrap'; com.example.main.Foo is in unnamed module of loader 'app')
        val myFooAgain = fooMap[1]
    } finally {
        redissonClient.shutdown()
    }
}
```

Note that I could get identical behavior with regular Java, it's not Kotlin specific. It also reproduces without a `MapLoader` (assuming values already exist in Redis)

OS: macOS monterey 12.3.1

Dependencies:
bitnami redis on docker 6.2
redisson 3.17.1
kotlin 1.6.21
jackson 2.13.2
io.netty:netty-all:4.1.76.Final (support for m1 mac netty native transport)
