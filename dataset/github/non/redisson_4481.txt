**Expected behavior**

Listen to the message and consume

**Actual behavior**

No message was heard

**Steps to reproduce or test case**

1、Start consumers first
     
    @Test
    public void listener() throws IOException {
        String qName = "test";
        RedissonClient redissonClient = TestRedissonClient.redisson();
        RBlockingQueue<Object> blockingFairQueue = redissonClient.getBlockingQueue(qName);
        new Thread(()->{
            while (true) {
                try {
                    log.info("Start delay queue processing thread");
                    Object message = blockingFairQueue.take();
                    log.info("Message received: {}",message);
                } catch (Exception e) {
                    log.error("Delay queue service processing exception!",e);
                }
            }
        }).start();
        log.info("Consumer startup completed");
        System.in.read();
    }

note:  We noticed that this problem can be solved by adding an empty message after the consumer starts. The code is as follows:

    @Test
    public void listener() throws IOException {
        String qName = "test";
        RedissonClient redissonClient = TestRedissonClient.redisson();
        RBlockingQueue<Object> blockingFairQueue = redissonClient.getBlockingQueue(qName);
        new Thread(()->{
            while (true) {
                try {
                    log.info("Start delay queue processing thread");
                    Object message = blockingFairQueue.take();
                    log.info("Message received: {}",message);
                } catch (Exception e) {
                    log.error("Delay queue service processing exception!",e);
                }
            }
        }).start();
        RDelayedQueue<Object> delayedQueue = redissonClient.getDelayedQueue(blockingFairQueue);
        delayedQueue.offer(null, 0, TimeUnit.SECONDS);
        log.info("Consumer startup completed");
        System.in.read();
    }
