Averaging timestampdiff output yields MAX_INT
```
select category, avg(timestampdiff(day, time_parse(started_at), coalesce(time_parse(ended_at), current_timestamp))) as avg_lifespan
from mytable
group by category
order by category
```

`avg_lifespan` for every `category` is always `2147483647`, even when only a single value participates in the average. Other aggregate functions like `min`, `max`, and `sum` yield expected results.

Druid version 0.19.0.
