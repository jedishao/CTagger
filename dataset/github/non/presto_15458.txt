Warn if a simple field is aliased to an existing field
If a table T has 3 columns x, y and z and you see a select like:

SELECT x, y z FROM T

where z (an existing field) is used as an alias to a different field like (y), it may be a case of missing comma and potentially not what the user wanted - especially y and z are the same type. So it's worth giving a warning for that. 

Note that:

SELECT x, y, z z FROM T

is ok because z stays z
