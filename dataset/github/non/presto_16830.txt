Sort by ipaddress does not order ipaddress correctly
Queries order by IP address give the wrong order. Casting `ipaddress` to `varbinary` fixes the problem:
```
presto:tiny> select ip from (values (ipaddress'1.0.0.255'), (ipaddress'1.1.255.255'), (ipaddress'1.0.0.0'), (ipaddress'1.1.0.0')) t(ip) order by ip;
     ip
-------------
 1.0.0.255
 1.1.255.255
 1.0.0.0
 1.1.0.0
(4 rows)

presto:tiny> select ip from (values (ipaddress'1.0.0.255'), (ipaddress'1.1.255.255'), (ipaddress'1.0.0.0'), (ipaddress'1.1.0.0')) t(ip) order by cast(ip as varbinary);
     ip
-------------
 1.0.0.0
 1.0.0.255
 1.1.0.0
 1.1.255.255
(4 rows)
```
