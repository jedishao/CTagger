Cryptic error message when joining tables where not all of the group by columns are used in the join
The following query works.

```
WITH stats AS (
  SELECT parent_id, id, SUM(clicks) AS sum_clicks
  FROM pinot.default.events
  WHERE parent_id = 123
  GROUP BY parent_id, id
  ORDER BY sum(clicks)
)
SELECT stats.id, status, sum_clicks
FROM stats
INNER JOIN mysql.mydb.entities
ON (stats.parent_id = mysql.mydb.entities.parent_id AND stats.id = mysql.mydb.entities.id)
WHERE mysql.mydb.entities.parent_id = 123;
```

But this query fails.

```
WITH stats AS (
  SELECT parent_id, id, SUM(clicks) AS sum_clicks
  FROM pinot.default.events
  WHERE parent_id = 123
  GROUP BY parent_id, id
  ORDER BY sum(clicks)
   DESC LIMIT 10
)
SELECT stats.id, status, sum_clicks
FROM stats
INNER JOIN mysql.mydb.entities
ON (stats.id = mysql.mydb.entities.id)
WHERE mysql.mydb.entities.parent_id = 123;
```

The difference is the ON statement.
