Exception is not propagated in Function evaluation with pushdown filter enabled
For example the following query fails with exception without pushdown where as returns null with pushdown

```
CREATE TABLE lineitem_partitioned(lienumber tinyint, shipdate date, commitdate date) 
with (partitioned_by=ARRAY['commitdate']);

INSERT INTO lineitem_partitioned 
SELECT linenumber, shipdate, commitdate from lineitem;

SELECT * FROM lineitem_partitioned 
WHERE DATE_DIFF( 'day', PARSE_DATETIME( CAST("shipdate" AS VARCHAR), 'YYYY-MM-dd' ), PARSE_DATETIME( CAST("commitdate" AS VARCHAR), 'yyyy-MM-dd HH:mm:ss.SSS' ) ) = 7;
```
