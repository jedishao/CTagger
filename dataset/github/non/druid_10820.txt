UnsupportedOperationException during BUILD_SEGMENTS for arbitrary segment granularity 
### Affected Version

0.20.

### Description

Issue an index spec with the following granularity spec

```
 "granularitySpec": {
        "type": "arbitrary",
        "queryGranularity": "TEN_MINUTE",
        "rollup": true,
        "intervals": [
              "2021-01-01T00:00:00.000Z/2021-01-01T01:00:00.000Z",
              "2021-01-01T02:00:00.000Z/2021-01-01T04:00:00.000Z"
        ]
}
```
