### Minimal reproduce step

**Step-1: Apply the TLS configuration using JKS keystore but not enabled the authentication**
Proxy: 
Enable TLS using JKS keystore (But Not enable the authentication) 
Apply this config: https://pulsar.apache.org/docs/2.11.x/security-tls-transport/#configure-proxies-1

Broker: 
Enable TLS using JKS keystore 
https://pulsar.apache.org/docs/2.11.x/security-tls-transport/#configure-brokers-1

Client(Publisher or subscriber):
Enable TLS using JKS keystore 
https://pulsar.apache.org/docs/2.11.x/security-tls-transport/#configure-clients-1

Step-2: Start the Client to establish the connection   (between Client to  proxy and proxy --> Broker)
