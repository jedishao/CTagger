Introduce segmented aggregation flush threshold
#17886 introduced segmented aggregation. The current implementation needs to close the aggregation builder, destroy the hash table, then reopen the aggregation builder and recreate the hash table when flushing the finished segment(s). However, if the segments are very small, this process have to be repeated too many times, resulting in overhead costs.

Therefore, it might be helpful to introduce a flush threshold to prevent the aggregation build being rebuild too frequently.
