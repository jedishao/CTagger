Option requireTimeCondition broke function lookup() 
Set option:
druid.sql.planner.requireTimeCondition=true

When run query:
```
SELECT
  LOOKUP('key','lookupname')
```

getting error 
```
requireTimeCondition is enabled, all queries must include a filter condition on the __time column

org.apache.druid.sql.calcite.rel.CannotBuildQueryException
```
BUT  lookups didn't contain any "__time" field, looks like requireTimeCondition - must not affected on the lookups, but it do. 


### Affected Version

Druid 0.22.1+
