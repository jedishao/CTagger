Support Explain verification
Verifier need to run explain test to figure out queries with plan changes, so that they can be further tested. This allows us to address the short-coming of randomly sampled test queries, improving our confidence in release quality.

We need to:
- Support running explain verification in Verifier.
- Support multiple control and test clusters for Verifier, to speed up verification.
- Run a Presto query to fetch the list of queries to be verified, instead of using a MySQL table, since the queries to be verified could be large.
