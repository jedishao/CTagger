### Affected Version

Druid version: 0.22.1

### Description

Deployed cluster:
<img width="674" alt="Screen Shot 2022-04-18 at 2 14 32 PM" src="https://user-images.githubusercontent.com/10060411/163879166-38c9816c-dc0c-437c-bbf9-f753db5b1418.png">

Query which I am using:
```
SELECT *
      FROM (SELECT '4235' AS code, name,
                   regexp_extract(metric, '(?<=\"production\":\")(.+?)(?=\")', 0) AS production,
                   regexp_extract(metric, '(?<=\"station\":\")(.+?)(?=\")', 0) AS station,
                   regexp_extract(metric, '(?<=\"issuer\":\")(.+?)(?=\")', 0) AS issuer,
                   "value"
            FROM "FAKE_car-metrics") AS metric
               JOIN (SELECT
                         regexp_extract(metric, '(?<=\"code\":\")(.+?)(?=\")', 0) AS code,
                         regexp_extract(metric, '(?<=\"car\":\")(.+?)(?=\")', 0) AS car,
                         regexp_extract(metric, '(?<=\"sponsor\":\")(.+?)(?=\")', 0) AS sponsor,
                         regexp_extract(metric, '(?<=\"model\":\")(.+?)(?=\")', 0) AS model
                     FROM "FAKE_car-metrics"
                     WHERE source='ikig' AND name='relation'
                     LIMIT 1) AS relation ON relation.code = metric.code
```
