Add support for casting UUID to JSON and vice versa
I'm using trino 410 in docker, out of the box installation:

```
docker pull trinodb/trino
docker run -p 8080:8080 --name TRINO trinodb/trino
```

Using connector:

```sql
use memory.default;
```

This is currently not possible:

```sql
select cast(array[uuid()] as json);
```

It fails with:

> SQL Error [58]: Query failed (#20230316_085436_73501_7p99g): line 1:8: Cannot cast array(uuid) to json

A `UUID` type has to be cast to `VARCHAR` prior to casting it to `JSON`:

```sql
select cast(array[cast(uuid() as varchar)] as json);
```

To receive:

```
|_col0                                   |
|----------------------------------------|
|["ec4cb2d8-e4e1-4b3a-a056-36ef6e8a26c1"]|
```

This is a similar missing feature as https://github.com/trinodb/trino/issues/16540.
