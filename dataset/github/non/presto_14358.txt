NPE when reading structs with a newly added subfield
In case of a schema change where a new field is added to a struct there will be a missing stream when reading from older files. We need to create a MissingFieldsStreamReader to return an empty block.
This was handled for the case where the field was in the output. The same should be added when its pruned.
