Adding an iterator for Metadata entries
In some cases, it's necessary to iterate over all the entries of the metadata instance, without prior knowledge of the existing keys.
For example, when writing the headers to the log\tracing framework, writing generic interceptors etc.

The way I'm doing it now is:
1. iterate over the keys using `Metadata.keys()` - which iterates over the underlying `Object[]`
2. for each key, get its value using `Metadata.get()` - which again, iterates over the array
3. create a map from key -> value
4. return an iterator

This makes iterating over the entries more inefficient than it needs to be, IMO.

Having a new `Metadata.iterator()` method with a reasonable runtime (O(n)) will be great.

Also, if there's a more reasonable way to do it that I missed, please let me know.
Thanks
