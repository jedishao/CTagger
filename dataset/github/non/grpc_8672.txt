I make client send  3MB message per ms, something like:

```
// request chunk data info
byte[] buffer = new byte[3 * 1024 * 1024];
int length;
length = is.read(buffer);
int time = 0;
while (time < 10000) {
    requestObserver.onNext(uploadChunkRequest(buffer, length));
    time++;
    try {
        Thread.sleep(5);
    } catch (InterruptedException e) {
        e.printStackTrace();
    }
}
```

Server handle message per 5s:

```java
@Override
public void onNext(ClientSideStreamingRpcService.UploadRequest value) {
    switch (value.getDataCase()) {
        case REQUEST:
            log.info("Server handle file {}, metadata", fileName);
            break;
        case CHUNK:
            log.info("Server handle file chunk");
            try {
                Thread.sleep(5000);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            break;
        default:
            log.error("Server handle error onNext()");
            break;
    }
}
```
