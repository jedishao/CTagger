JDBC bind variables aren't supported in JSON_OBJECT and JSON_ARRAY
I'm running this on Trino 409:

```java
try (PreparedStatement s = connection.prepareStatement("select json_object(key 'a' value ?)")) {
    s.setInt(1, 1);

    try (ResultSet rs = s.executeQuery()) {
        while (rs.next())
            System.out.println(rs.getString(1));
    }
}
```

## Workarounds:

**Inline bind values:**

```java
try (PreparedStatement s = connection.prepareStatement("select json_object(key 'a' value 1)")) {
    try (ResultSet rs = s.executeQuery()) {
        while (rs.next())
            System.out.println(rs.getString(1));
    }
}
```

This produces the correct result:

```
{"a":1}
```

**Nest the expression and bind the value to a `VALUES` constructor**

```java
try (PreparedStatement s = connection.prepareStatement("select (select json_object(key 'a' value v) from (values (?)) as t (v))")) {
    s.setInt(1, 1);

    try (ResultSet rs = s.executeQuery()) {
        while (rs.next())
            System.out.println(rs.getString(1));
    }
}
```
