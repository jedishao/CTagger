Support JOIN with constant in the ON condition
### Description

Support JOIN with constant in the ON condition such as `SELECT t1.cityName from wikipedia as t1 LEFT join wikipedia as t2 on t1.cityName = 'Buenos Aires'`

### Motivation

For LEFT JOIN (like the one above), joining on constant is not the same (and cannot be move into) a regular filter (WHERE clause). (see: https://stackoverflow.com/a/354094 and https://stackoverflow.com/a/1539314).

Moreover, there are optimization where can take advantage of using `ReduceExpressionsRule.JOIN_INSTANCE` if we are able to support JOIN with constant in the ON condition. For example, SQL such as `with abc as ( SELECT cityName, "__time", sum_added from wikipedia WHERE "cityName" = 'Buenos Aires' ) SELECT t1.cityName, t1."__time" from abc as t1 LEFT join abc as t2 on t1.cityName = t2.cityName WHERE t1.cityName = 'Buenos Aires' ` can be reduced to a JOIN with constant in the condition (something like `=($0, 'Buenos Aires')`)
