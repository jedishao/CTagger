No implicit String <-> Numeric conversion during a join
It seems like an implict conversion should occur during a join (String dimension ON numerical dimension)
### Affected Version
0.22.1


### Description
I was doing some test for a query in which I do a join. I was trying to join on a String dimension and a numerical value like
`INNER JOIN someDataSource ON someDataSource."id" = 3
`Where id is a string type.
Then I receive a : 
```
Error: Unknown exception
....
org.apache.druid.java.util.common.ISE
```
However, if I do a basic query with a basic condition over the said id like that :
```
SELECT *
FROM someDataSource
WHERE id = 3
```
it works.

Here are two ingestion payload and 4 queries.
Three of them work while one doesn't but should (if I'm not wrong)
