Materialized view test should sort entries
TestHiveLogicalPlanner materialized view tests should create view tables that match the base table. To do this, they should sort the materialized view table in the same way as the base table. 

For example, TestHiveLogicalPlanner.testMaterializedViewOptimization creates a view table and base table with the same rows of orderkey, but it is sorted in a different order. Refer to the screenshot below.
