Prune empty values nodes from the plan
Currently when we do partition elimination if no partition is selected, we create a values node with no rows and that distorts plan in all sorts of ways causing occasional issues. So we should add an iterative optimizer rule to prune these. The algo is simple, when you have a values node with 0 rows

1. if it's part an inner join, replace that join node with the empty values
2. if it's the inner relation of an outer join, replace the join with the other (outer) side
3. if it's the outer relation of an outer join, replace the join with empty values node
4. if it's a part of a union or except node, just remove it from the list of relations of the union
5. if it's a part of an intersect node, replace the entire intersect with empty values
