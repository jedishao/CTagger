MariaDB connector does not support BIT datatype
Trying the MariaDB connector on a test database, it appears that fields with the datatype of BIT are not supported and skipped by Trino.

I think that the following code could be added to the MariaDbClient.toColumnMapping() method to fix this, although I did not test it.

            case Types.BIT:
                return Optional.of(booleanColumnMapping());

At least, this code works in a custom connector I wrote to address the same issue in a different database.

Does this make sense, and if it works should I create a pull request for it?
