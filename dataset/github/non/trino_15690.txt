Computation Reuse via Fusion
This is to track the implementation of the fusion rules from the [Computation reuse via fusion in Amazon Athena](https://www.amazon.science/publications/computation-reuse-via-fusion-in-amazon-athena) AWS Athena paper.

The paper describes multiple optimization rules that match specific query patterns (see details in the paper) so we can logically divide the work on the rule boundary, additionally all four rules require query fusion primitives for implementation

- [ ] Query fusion primitives
- [ ] GroupByJoinToWindow
- [ ] JoinOnKeys
- [ ] UnionAllOnJoin
- [ ] UnionAll

There are currently two PRs open for this
* Simplified implementation of `JoinOnKeys`  https://github.com/trinodb/trino/pull/14271
* Complete implementation shared by AWS team https://github.com/trinodb/trino/pull/15288

Both use a simple recursive approach that is not compatible with the planned exploratory optimizer so as a part of this we may also explore alternative approaches that are more future-proof.
