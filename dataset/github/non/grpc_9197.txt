A follow up question about how a grpc server with manual flow control behaves under load: I've created my own manual client and server, following the example available at the repository. It's slightly modified:

1 - The client sends 1 request when ready and completes (code is abridged)

```java
  public void beforeStart(ClientCallStreamObserver<Request> requestStream) {
                      this.requestStream = requestStream;
                      this.requestStream.disableAutoRequestWithInitial(1);

                      requestStream.setOnReadyHandler(
                          () -> {
                            while (requestStream.isReady()) {
                                if (!requestWasSent) {
                                  requestStream.onNext(request);
                                  requestWasSent = true;
                                  log.info("request is ready: onNext() executed [send request]");
                              } else {
                                  requestStream.onCompleted();
                                  log.info("request is ready: request.onCompleted() executed [complete request]");
                              }
                            }
                          });
                    }
                  };
```

2 - The server requests(1) when ready and sends 1 response when it gets the request from the client  (code is abridged)

```java
public StreamObserver<Request> getAd(StreamObserver<Response> responseObserver) {
        ServerCallStreamObserver<Request> scsResponseObserver =  (ServerCallStreamObserver<Response>) responseObserver;
        scsResponseObserver.disableAutoRequest();

        class OnReadyHandler implements Runnable {
            @Override
            public void run() {
                if (scsResponseObserver.isReady()) {
                    log.info("request(1)");
                    scsResponseObserver.request(1);
                }
            }
        }

        final OnReadyHandler onReadyHandler = new OnReadyHandler();
        scsResponseObserver.setOnReadyHandler(onReadyHandler);

        return new StreamObserver<>() {
            @Override
            public void onNext(Request value) {
                log.info("-> request");
                responseObserver.onNext(Response.newBuilder().build());
                log.info("<- response");
                responseObserver.onCompleted();
            }

```
It works and generates logs (at the server side) similar to the ones pasted above.
