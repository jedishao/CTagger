Presto is relatively slow compared to source DB with simple queries.
The presto cluster (0.263.1) is set up with 1 coordinator and 2 workers on machine A and the source DB (mysql) is on machine B.

The ping response from B back to A averages < 0.2ms.

When queried with simple sqls such as select * from a_2_rows_table, show tables from the database, presto takes 100 to 500 ms (sometimes even >1s if the query is not executed for a long time) wall time. And the same queries take 50 to 100 ms in navicat.

Below is the breakdown of the query time after many repetitions:
```
Elapsed Time | 136.51ms
Prerequisites Wait Time | 209.16us
Queued Time | 98.20us
Planning Time | 17.40ms
Execution Time | 118.27ms
```

I wonder what costs the extra time other than the source DB query?
