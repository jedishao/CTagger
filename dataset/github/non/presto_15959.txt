Adding the F distribution (f_cdf + inverse_f_cdf)
Adding the F distribution, which is central to many statistical procedures (https://en.wikipedia.org/wiki/F_distribution).

PR: #15958

The PR follows the diff template of: https://github.com/prestodb/presto/pull/11981/files

Both the function signature (name, input output type and meaning), and the test plan, are available in the PR.

== RELEASE NOTES ==

General Changes
* Add f_cdf() and inverse_f_cdf() functions.


(this is the same structure as was used in the beta_cdf: https://prestodb.io/docs/current/release/release-0.215.html?highlight=beta_cds)

Adding probability distribution to native Presto unblocks building statistical procedures on top of it, specifically, unblocks the ability to calculate p-values and confidence intervals of relates tests.
