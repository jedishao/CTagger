The problem was `HiveSplit.getPreferredNodes()` uses `address` field for HARD_AFFINITY, but by default Hadoop file system just return "localhost" by default and it failed to be passed to valid addresses. 

FileSystem.java:
```
public BlockLocation[] getFileBlockLocations(FileStatus file, long start, long len) throws IOException {
        if (file == null) {
            return null;
        } else if (start >= 0L && len >= 0L) {
            if (file.getLen() <= start) {
                return new BlockLocation[0];
            } else {
                String[] name = new String[]{"localhost:50010"};
                String[] host = new String[]{"localhost"};
                return new BlockLocation[]{new BlockLocation(name, host, 0L, file.getLen())};
            }
        } else {
            throw new IllegalArgumentException("Invalid start or len parameter");
        }
    }
```
