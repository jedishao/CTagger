Geospatial query behaves in a weird way
I have this query:
```sql
SELECT ST_AsText(
    simplify_geometry(
        ST_Union(
            ST_GeometryFromText('POLYGON ((-71.364345 42.636698, -71.318049 42.613751,         -71.318365 42.613912, -71.318544 42.614724,         -71.319771 42.615688, -71.319548 42.622281, -71.364345 42.636698))'), 
            ST_GeometryFromText('POLYGON ((-71.316782 42.64071,  -71.31985899999999 42.615796, -71.318544 42.614724, -71.31831699999999 42.613875, -71.297028 42.613011, -71.316782 42.64071))')
        ),
        0.001
    )
);
```

Which fails with the following error:
```
expected one element but was: <POLYGON ((-71.297028 42.613011, -71.318049 42.613751, -71.364345 42.636698, -71.319548 42.622281, -71.31973277958336 42.61681798747477, -71.316782 42.64071, -71.297028 42.613011)), POLYGON ((-71.31832088297078 42.61388952265283, -71.318544 42.614724, -71.31976980640815 42.615723288569995, -71.318544 42.614724, -71.31832088297078 42.61388952265283))>
```

It's hard to tell what exactly is happening as the error is pretty vague, but what I noticed is:

- Removing any single point from either polygon results in a successful execution of the query;
- Removing call to `simplify_geometry` function results in a successful execution as well;
- Removing `ST_AsText` also results in in a successful execution which means that this is the function that received invalid arguments: 2 geometries instead of 1. Documentation says that `simplify_geometry` returns Geometry, but clearly 2 polygons is not a valid representation of Geometry.

Here's the result for running this query without `ST_AsText`:
```
POLYGON ((-71.297028 42.613011, -71.316782 42.64071, -71.31973277958336 42.61681798747477, -71.319548 42.622281, -71.364345 42.636698, -71.318049 42.613751, -71.297028 42.613011), (-71.31832088297078 42.61388952265283, -71.318544 42.614724, -71.31976980640815 42.615723288569995, -71.318544 42.614724, -71.31832088297078 42.61388952265283))
```

Clearly there's some "miscommunication" between `simplify_geometry` and `ST_AsText`.
