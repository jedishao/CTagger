Add a HTTPClient Wrapper
Following the same logic as the VertxWrapper, it should provide a HttpClient wrapper to mitigate breaking changes when adding a method to the HTTP client interface.

As requested in #4569, it would be great to be able to pass a `Supplier` as:

```java
private final Supplier<HttpClient> supplier;
private volatile HttpClient supplied = null;

  WrappedHttpClient(Supplier<HttpClient> supplier) {
      this.supplier = supplier;
  }

  private HttpClient getDelegate() {
      if (supplied == null) {
          supplied = supplier.get();
      }
      return supplied;
  }
```
