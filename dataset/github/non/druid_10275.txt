Druid Console: Explain SQL query fails when there is a corresponding SQL line commented out.
Explain SQL query plan fails with a pop-up dialog: "Cannot read property 'replace' of undefined". This only appears to happen when I have a SQL line commented out `EXPLAIN QUERY FOR` in the query text scratch space. i.e., the Druid SQL query looks something like:
```
-- EXPLAIN PLAN FOR (
SELECT * FROM wikipedia
-- )
```

Please see screenshots below.

### Affected Version

0.18.1

### Description
I was running the SQL query plan by hand and then I realized that the console already has an option of viewing the plan from the `...` menu, so I commented out the SQL line, but I get the following error.
