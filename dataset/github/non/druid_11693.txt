Data loader generates incorrect ingestion schema when splitHintSpec is modified 
Data loader generates incorrect ingestion schema when  `maxSplitSize` or `maxNumFiles` parameter is customized in tuning section. `type` field  in splintHintSpec is missing in resulting JSON.
