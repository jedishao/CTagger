[Cassandra Connector] Reduce the number of splits when the presto cluster is small
We have a scenario where Presto cluster is only one 16Core machine, and the cassandra table contains only several records, but Presto will calculate 385 splits for this table(it calculate the splits according to the token range), so the query is very slow.

So can we provide a session property to let user reduce the split count so the performance for small presto cluster can be better?
