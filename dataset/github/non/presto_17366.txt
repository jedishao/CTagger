Presto can not work when disabled cache of hdfs or viewfs
When disabled the filesystem cache with the following conf, then the presto can not create FileSystem object, will appear the following exception:
```shell
<name>fs.viewfs.impl.disable.cache</name>
    <value>true</value>
    </property>
  <property>
    <name>fs.hdfs.impl.disable.cache</name>
    <value>true</value>
  </property>
```
