Evaluate performance gain by applying batch read to SliceDirectSelectiveStreamReader#readWithFilter for unbounded varchar
In https://github.com/prestodb/presto/pull/14544, we optimized `SliceDirectSelectiveStreamReader#readNoFilter` for unbounded varchar and got ~2x gain in JMH benchmark. We can apply similar optimizations to the `readWithFilter()` function for unbounded varchar(maxCodePoint = -1). We first read all data in one shot, then apply the filter for the valid positions, then pack the data.  We need to test if this can bring us any gains and find the best `BATCH_EXECUTION_FILTERRATE_THRESHOLD`.
