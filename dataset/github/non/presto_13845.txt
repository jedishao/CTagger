Use LazyBlock for filter function inputs
Filters like `if(f(a), f(b), f(c))` may benefit from using LazyBlocks for inputs. If `f(a)` evaluates to true most of the time, column c may not need to be read for most of the pages. When c is of complex type (array/map/struct), not reading it offers substantial CPU savings. Hence, we suggest to use LazyBlock for all filter functions with two or more inputs.

See com.facebook.presto.orc.OrcSelectiveRecordReader#OrcSelectiveRecordReader
