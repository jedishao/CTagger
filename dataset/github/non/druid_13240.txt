### Affected Version

0.22.1
query 3 on 24.0.0 also gives similar response

### Description
After upgrading from druid 0.19.0 to 0.22.1
I am seeing one query failing in our usecase

so I tried the similar type of query on wikipedia data source, seems like its an issue


- Cluster size, Configurations in use - ./bin/start-micro-quickstart with apache-druid-0.22.1

Steps to reproduce the problem

- Download and run apache-druid-0.22.1 with ./bin/start-micro-quickstart
- insert the wikipedia datasource by running this command in druid directory bin/post-index-task --file quickstart/tutorial/wikipedia-index.json --url http://localhost:8081
- run this query on wikipedia datasource.



**query 1 - If trying from druid ui remove auto limit**
SELECT DATE_TRUNC('month',t0.__time),SUM(delta) FROM "wikipedia" t0
WHERE (comment IN( 'added project') )
and (comment NOT IN ('added project' )) GROUP BY DATE_TRUNC('month',t0.__time)

**query 2- If trying from druid ui remove auto limit**
SELECT DATE_TRUNC('month',t0.__time),SUM(delta) FROM "wikipedia" t0
WHERE (comment IN( 'added project') )
and (comment NOT IN ('added project' )) GROUP BY DATE_TRUNC('month',t0.__time) LIMIT 1000

both query 1 and query 2 takes 250 to 300 secs(sometimes gives timeout after 5mins also) on wikipedia datasource. In our deployment it times out as we have 1min limit. mostly this is a case of empty result set

**query 3 -  If trying from druid ui remove auto limit**
SELECT DATE_TRUNC('month',t0.__time),SUM(delta),cityName FROM "wikipedia" t0
WHERE (comment IN( 'added project') )
and (comment NOT IN ('added project' )) GROUP BY DATE_TRUNC('month',t0.__time),cityName 
the above query times out after 5 mins

**query 4 - If trying from druid ui remove auto limit**
SELECT DATE_TRUNC('month',t0.__time),SUM(delta),cityName FROM "wikipedia" t0
WHERE (comment IN( 'added project') )
and (comment NOT IN ('added project' )) GROUP BY DATE_TRUNC('month',t0.__time),cityName LIMIT 1000
the above query returns with in seconds - only difference from query 3 is added LIMIT
