Object Array Constructor for JsonObject
#### Read me
The code like this:
~~~java
public JsonObject(Object... kvs) {
    if (kvs.length < 2 || kvs.length % 2 != 0) {
        throw new DecodeException("Invalid JSON key value length: " + kvs.length);
    }
    map = new LinkedHashMap<>();
    for (int i = 0; i < kvs.length - 1; i += 2) {
        map.put((String) kvs[i], kvs[i + 1]);
    }
}
~~~

#### Describe the feature

To build the json with key-value as fast as possible

#### Use cases

~~~java
JsonObject data = new JsonObject("name", "sam", "type", "test", "size",123);
~~~
