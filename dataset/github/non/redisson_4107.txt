TimeSeries - does not handle same values for different timestamps 
The problem as it is described in redis documents here. https://redis.com/blog/unlocking-timeseries-data-redis/

Trying to add 1000 same values to different timestamps yield a 558 items only as a result of `RANGE` command.

**Expected behavior**
all 1000 items to be returned. 

**Actual behavior**
only 558 items returned as a result of the problem 

**Steps to reproduce or test case**
```
 RTimeSeries<V> ts = redissonClient.getTimeSeries("KS400:100:my-same-value-metric");
for (int i=0;i<1000;i++){
    ts.add(System.currentTimeMillis(), "my-value",60,TimeUnit.DAYS);
}
```
