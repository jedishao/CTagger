Invalid cast to TDigest or QDigest should be caught by TRY
The [docs](https://prestodb.io/docs/current/functions/conditional.html#try) say that this should work for conversion errors, but attempting to cast an invalid VARBINARY or an invalid type like an integer to a TDigest fails even if it is wrapped in a TRY.  The same thing also happens for QDigest.

Things which currently don't work (throw an exception instead of returning null):

```
SELECT try(CAST(1 AS TDigest(DOUBLE)));
SELECT TRY_CAST(1 AS TDigest(DOUBLE));
```
