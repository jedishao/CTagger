ClassCastException when using Redisson with opentelemetry auto instrumentation
We are using opentelemetry on our service in order to trace request. On service using redisson, the implementation throw a ClassCastException when calling redisson schedule feature. 

Since I don't know who is responsible of this, I made an issue on both project (opentelemetry and redisson). Linked issue is here:
https://github.com/open-telemetry/opentelemetry-java-instrumentation/issues/6033

**Expected behavior**
No thread crash

**Actual behavior**
Thread crash due to ClassCastException
