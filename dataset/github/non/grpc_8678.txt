GRPC induces NoSuchFieldError with build() on unused message in proto file
<!-- Please answer these questions before submitting a bug report. -->

### What version of gRPC-Java are you using?
GRPC 1.37.0, Protobuf 3.18.0

### What is your environment?
Windows, Azul OpenJDK 13, 

### What did you expect to see?
no exceptions; builder returns a normal instance
OR
A custom error "this message type has been removed at runtime for the optimization CODE_SIZE; please rerun with SPEED"

### What did you see instead?
```
java.lang.NoSuchFieldError: internal_static_package_Unused_fieldAccessorTable
	at package.Unused.internalGetFieldAccessorTable(Unused.java:41)
	at com.google.protobuf.GeneratedMessageV3.getDescriptorForType(GeneratedMessageV3.java:133)
	at com.google.protobuf.GeneratedMessageV3.isInitialized(GeneratedMessageV3.java:207)
	at package.Unused$Builder.build(Unused.java:296)
```

### Steps to reproduce the bug

1. create a proto file 
   ```
   syntax = "proto3";

   option optimize_for = CODE_SIZE;

   service Thingy {
     rpc function (Input) returns (Output)
   }

   message Input {}
   message Output {}

   message Unused {}
   ```

2. write some code
   ```
   var builder = Unuused.newBuilder();
   try { builder.build() }
   catch(NoSuchFieldError e) { e.printStackTrace() }
   ```
