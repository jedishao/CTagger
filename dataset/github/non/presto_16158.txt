**Query Comments**
There are two tables:
1. Table_a = This contains all the registered players. Player Snapshot table
2. Table_b = This contains , on daily basis, all the relevant metrics for each player for that particular day. On any given day this table has 1 million rows
3.  The clan_id_array field of table_b contains all the unique clans for which a player was part of in a particular day. Each clan_id is a 36 character long string. Example,  "f4becce9-13a7-4b53-8536-8de36885bd9d". A player can be part of multiple clans  in any day.

The query above, given a current_date, scan over all the entries in table_b, and finds the most recent value of  some metrics and sum of other metrics, until the current date.
