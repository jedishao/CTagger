Zstd version is incompatible with the version of Zstd used by the Kafka Indexing service
### Affected Version

This issue affects 0.22.0 but also probably affects 0.21.x and 0.20.x.

### Description

Currently Druid relies on [version 1.3.3-1](https://github.com/apache/druid/blob/master/pom.xml#L450) of zstd. However, the Kafka client used in the Kafka Indexing Service relies on [version 1.5.0-4](https://github.com/apache/kafka/blob/493280735b418cb7d7cb68cfc2e7f84ca4a552ca/gradle/dependencies.gradle#L117).

When you attempt to ingest data from Kafka that has been compressed with zstd it yields the following exception and fails the indexing task:
