Presto UI does not work with Internet Explorer 11 and earlier
It shows that Presto UI does not work with IE.

When opening Presto UI with IE, you will notice that Presto UI does not load, and only 2 circles keep spinning as if something is loading.

There errors are found in the network requests:
```
SCRIPT5009: 'fetch' is undefined
PageTitle.jsx (60,13)


The above error occurred in one of your React components:
    in Unknown

Consider adding an error boundary to your tree to customize error handling behavior.
Visit https://fb.me/react-error-boundaries to learn more about error boundaries.

SCRIPT5009: 'fetch' is undefined
react-dom.development.js (16543,5)
```

Which mentions about the issues with React JS Applications on Internet explorer. It mentions about using ```react-app-polyfill``` to be able to use React JS with Internet Explorer which, Presto's code does not seem to be doing.
