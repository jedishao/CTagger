Recommended configuration for AWS Elasticache Global Datastore 
Hello! We are currently using Redisson with AWS Elasticache and it works well. We are currently using it in a single cluster in one region and we use the `ReplicatedConnectionManager`. 

We plan to deploy AWS Elasticache in multiple regions with their [global datastore](https://docs.aws.amazon.com/AmazonElastiCache/latest/red-ug/Redis-Global-Datastore.html) feature. With global datastore there can be two or more clusters but only one will accept writes. The other clusters will operate with a "passive" master. 

Looking at the `ReplicatedConnectionManager` [code](https://github.com/redisson/redisson/blob/608625a3bd8a5442b3c23840d2a202f7fb782bd1/redisson/src/main/java/org/redisson/connection/ReplicatedConnectionManager.java#L67-L108) I'm a bit concerned whether it will detect "passive" masters as nodes that can accept writes when those nodes cannot accept writes.

We will experiment with this soon but I figured I would document the question/experience for others.
