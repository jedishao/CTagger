java.lang.IllegalArgumentException: port out of range 


### Version

Which version(s) did you encounter this bug ?

4.3.4 and above

### Context

While upgrading from 4.3.3 to 4.3.7 I've encountered that one of my tests failed. The test initialises a verticle with faulty server configurations and in this case a port of 100.000 which should trigger the following exception: `java.lang.IllegalArgumentException: port out of range:100000`

What I've encountered is that though on the `java.base/java.net.InetSocketAddress.<init>(InetSocketAddress.java:197)` level the exception is triggered, this does not get matched by vertex core anymore. I get the following leading message: `ERROR io.vertx.core.impl.ContextBase - Unhandled exception`

This lets me think that there is an error in the handling of the code involving: `InetSocketAddress` since in `4.3.3` this resulted in a failed Future with the exception wrapped in the Throwable. Now since 4.3.4 and up the Runtime exception does not get caught.


### Do you have a reproducer?

I've written a small test in Kotlin as a reproducer:

```kotlin
@Test
    fun `reproduce server failure`(testContext: VertxTestContext) {
        val vertx = Vertx.vertx()
        vertx.createHttpServer().requestHandler(HttpServerRequest::end)
                .listen(100_000)
                .onFailure { testContext.completeNow() }
                .onSuccess { testContext.failNow("this should not be triggered") }
    }
```
