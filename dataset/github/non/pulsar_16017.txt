[Discuss][Doc]: Remove active-standby replication mode on Geo Replication doc
### What issue do you find in Pulsar docs?

I think this mode on [Geo Replication doc](https://pulsar.apache.org/zh-CN/docs/concepts-replication/#active-standby-replication) is quite easy to misunderstand for users.

Because the [replicated-subscriptions](https://pulsar.apache.org/docs/administration-geo/#replicated-subscriptions) needs two-way replication which means if users config one-way replication like the active-standby replication mode describes, their subscriptions status will not be replicated from active cluster to standby cluster.

And if the application connects to the standby cluster after the active cluster is in failure, its replication status in the active cluster will be lost.


### What is your suggestion?

Delete Active-standby replication mode on Geo Replication mode, we just recommand Active-active replication mode.
