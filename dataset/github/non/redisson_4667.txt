Regarding definition of nettyThreads
`nettyThreads` is defined as _Threads amount shared between all internal redis clients used by Redisson._

For e.g. my application connects to 3 different Redis clusters (2 sentinel based clusters, 1 multi-master cluster), all of them are initialized with different connections pool sizes and nettyThreads size. Should I keep  `nettyThreads` same across the redis clients here?
