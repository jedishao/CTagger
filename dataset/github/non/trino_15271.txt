Lateral example in SELECT documentation does not run
Looking at the [docs for 403](https://trino.io/docs/403/sql/select.html#lateral), I built a full query based on the example:
```sql
WITH
    nation AS ( SELECT * FROM (
        VALUES ('a', 'b', 'c'),
               ('1', '2', '3')
                ) AS t(name, x, y) )
SELECT *
FROM nation
         CROSS JOIN LATERAL (SELECT name || ' :-' AS x)
         CROSS JOIN LATERAL (SELECT x || ')' AS y);
```

And I get the error:

```java
[2022-12-01 15:29:51] [62] Query failed (#20221201_132950_52964_smxz7): line 9:37: Column 'x' is ambiguous
[2022-12-01 15:29:51] io.trino.spi.TrinoException: line 9:37: Column 'x' is ambiguous
```

https://github.com/trinodb/trino/blob/3737ba0a7c286732f31159f449b3020d78eef0e0/docs/src/main/sphinx/sql/select.rst#lateral

My suggestion is

1. consider including a table in the examples so they can be run and tinkered with (like a `VALUES` clause).
2. change the example to something like:

```sql
WITH
    nation AS ( SELECT * FROM (
        VALUES ('a', 'b'),
               ('1', '2')
                ) AS t(name, region) )
SELECT *
FROM nation
         CROSS JOIN LATERAL (SELECT name || ' :-' AS x)
         CROSS JOIN LATERAL (SELECT x || ')' AS y);
```

**EDIT**:  Appears that there is a schema described at the top of the docs page. So I modified the suggested changes.
