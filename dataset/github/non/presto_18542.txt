Hudi/Hive Connector Error: 'No FileSystem for scheme: s3' in diffrent versions
# Precondition
I use Presto-0.275 with Hudi/Hive Connector based on S3 protocol and everyting goes well, but the Error: `No FileSystem for scheme: s3` occured when I switched to the release-0.277.

# Exploration
I noticed the PR: #18441 has committed to fix the Hive Connector. So will this next release version fix the problem about Hudi Connector as well?

# Expectation
Querying Hudi MOR-table by Hudi/Hive Connector and both support S3 protocol.

# Error Note

- In **Presto-0.275**, Hudi Connector(_ro/_rt) ✅ , Hive Connctor(_ro/_rt) ✅
