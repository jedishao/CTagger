Support to handle type coercion for correlated subquery
When correlated symbols are in non-direct column reference type, query is failed..

presto:test> select (select count(*) from (values 1) t(a) where t.a=t2.b group by a limit 1) from (values 1.0) t2(b);

`Query 20201230_194256_00000_ydmqh failed: line 1:9: Given correlated subquery is not supported`
