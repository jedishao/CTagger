NPE on Http1xServerRequest.handleException
### Version

4.2.1

### Context
when Http1xServerRequest.reportRequestBegin() throw exception. will cause a NPE on Http1xServerRequest.handleException (line 621), 
because response not initialized.

### Steps to reproduce

1. enable vertx-micrometer-metrics .
2. config MicrometerOptions like: new MicrometerOptions().setRequestsTagsProvider(req -> {
                    List<Tag> tags = new ArrayList<>();
                    tags.add(Tag.of("uri", req.absoluteURI()));
                    return tags;
                })
3. startup http server .
3. curl -v 'http://host:port/path?a=fetch&content=<php>die(@md5(HelloThinkCMF))</php>'  (contains some illegal query-char)
