Commit hook or test to error on bad co-author tags
We have had cases where co-author tags were malformed or missing.

A commit hook that fails on a Co-author tags that don't have an email address in "<>" would be useful. It might also be helpful it if it could warn if a commit mentions backporting or cherry picking, but doesn't also include a co-author tag. Not sure if git commit hooks can emit log output.

This could also be implemented as a test in Travis so it blocks merging.
