Dynamic Filtering with Contains Clause Doesn't Work
I have an SQL statement with multiple CTEs, with a final filter in the last selection statement that looks like this
```
WITH table_a as 
(
...
),
table_b as
(
...
)
select a.*, b.*
from table_a as a
left join table_b as b
where a.id in (1, 2, 3, ...)
```
The query doesn't work with this error message:
```SQL Error [65536]: Query failed (#XXX): Right join input doesn't contain symbol for dynamic filter: external_id_233, rightVariables: [country_228], dynamicFilters.values(): [external_id_233]```

But if I change the SQL statement to filter based on multiple ORs instead of one IN clause:
```
WITH table_a as 
(
...
),
table_b as
(
...
)
select a.*, b.*
from table_a as a
left join table_b as b
where a.id = 1 or a.id = 2 or a.id = 3 or ...
```
The query works. Is this something expected? Any plan to enable IN statement in dynamic filtering?
