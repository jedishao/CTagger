Docs on how to return types from plugin-defined functions
It is difficult for a [plugin defined function](https://prestodb.io/docs/current/develop/functions.html) to figure out what types need to be supplied. There is no obvious link from the docs mentioning `StandardTypes` to `presto-common/src/main/java/com/facebook/presto/common/type/`, where the expected Java types are defined (indirectly). The Java types are not intuitive (`StandardTypes.INTEGER` maps to `long`, a 64 bit type, rather than `int`) so this is a critical reference.

I have a particular issue with this because I am having trouble figuring out how to return a `ROW(x DOUBLE, y DOUBLE)` from a function. I tried some code like the below based on [something I found in StackOverflow](https://stackoverflow.com/questions/45797583/return-row-type-in-presto-udf) but it produces a different error message about `java.lang.IllegalArgumentException: com.facebook.presto.sql.planner.PlanFragment could not be converted to JSON` ... `Caused by: java.lang.IllegalStateException: Expected AbstractSingleRowBlock` that I don't know how to resolve. The code below does work for returning `ARRAY(DOUBLE)`.

```java
      BlockBuilder blockBuilder = DOUBLE.createFixedSizeBlockBuilder(2);
      DOUBLE.writeDouble(blockBuilder, 1.0);
      DOUBLE.writeDouble(blockBuilder, 2.0);
      return blockBuilder.build();
```

Edit: Similarly I do not know how to return `ARRAY(ARRAY(DOUBLE))`
