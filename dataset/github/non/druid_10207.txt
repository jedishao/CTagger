druid-time-min-max ingestion error
Reporting bug in the druid-time-min-max extenstion. It's returning TimestampAggregatorFactory from getCombiningFactory() of both TimestampMinAggregatorFactory and TimestampMaxAggregatorFactory. That's not proper, because TimestampAggregatorFactory is not JSON-round-trippable, and in general we expect the combining factories to be JSON-round-trippable.
 
User is having trouble with druid-time-min-max extension

```         
{

            "name": "first_seen",
            "fieldName": "timestamp"
          },
          {
            "type": "timeMax",
            "name": "last_seen",
            "fieldName": "timestamp"
          }
```
