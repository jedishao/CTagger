Hi, I'm using Redisson's Reactive API and I ran into a problem with `RSetMultimapReactive`.

**Expected behavior**

Redisson retrieves the size of the set using the following minimal working example:

```java
class CacheService {
    
    private final RSetMultimapReactive<String, String> backend;

    CacheService() {
        final Config config = new Config();
        config.useSingleServer()
                .setAddress("redis://127.0.0.1:6379");
        final RedissonReactiveClient redisson = Redisson.create(config).reactive();
        this.backend = redisson.getSetMultimap("test");
    }
     
    public Mono<Integer> getSize(String key) {
        return backend.get(key).size();
    }
}
````
