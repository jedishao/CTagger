Reading Struct field fails if there is a schema mismatch with pushdown filter enabled
If there is schema evolution with struct field the scan fails with pushdown enabled as we are not populating the required field.

For example a struct schema is modified to add a new field c to be -> row ( a, b, c)
the streamreaders for this schema are only 2 for a, b but when we return the field blocks it fails as we did not create a reader for "c" field.
