One connector to read Delta Lake and Hive tables
**Problem**
I use Presto to read hive (parquet, csv etc.) and delta tables which are registered in one hive metastore instance.
I need to have both Hive and Delta Lake connectors in Presto to be able to read the data. It is required because Hive connector doesn't have support for delta tables and Delta Lake connector doesn't allow to read hive tables.


**Desired behavior**
It would be very convenient and useful to use one connector instead.


**Possible solutions**
1. Delta Lake connector should delegate work to hive connector if non-delta table is being read
2. Build in Delta Lake connector to Hive connector and use it for delta tables
3. Implement an umbrella connector which delegates the work to the appropriate Hive or Delta connector
