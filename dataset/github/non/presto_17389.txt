Presto insert to table that location is viewfilesystem exists cross namespace problem  when enable local cache
The logical of the following code is to adapt to write data to the ViewFilesystem.
 https://github.com/prestodb/presto/blob/761cd55b974a47a91a16f60be5276b646c96cc45/presto-hive/src/main/java/com/facebook/presto/hive/HiveWriteUtils.java#L421-L436

If we enable the local cache, then the HdfsEnvironment's getFilesystem is aways return a CachingFileSystem that wrapper an view filesystem. But the viewFileSystem judge logical is not adapt the CachingFileSystem, it consider the filesystem is not a viewfs, then it aways using '/tmp/presto-{user}' as the tmp location, in the final moving step, coordinator need rename the tmp location to the final location, it may lead to cross hdfs namespace move operator.
