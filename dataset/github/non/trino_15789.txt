DROP TABLE IF EXISTS fails with hive metastore on 405 if table doesn't exist
I'm guessing this might be related to: https://github.com/trinodb/trino/pull/13974

But in the most recent trino release we run queries like:
DROP TABLE IF EXISTS hive.pipeline_prod6.tablename
