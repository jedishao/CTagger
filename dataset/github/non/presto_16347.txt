Wrong parameters order in EXECUTE USING when using with clause
## env
Presto Version: 0.256
JDBC jar Version:  0.256

## If using with clause
```
PREPARE s1 FROM 
WITH t_a AS (
	SELECT
		*
	FROM table1
	WHERE name = ?
)
SELECT
	*
FROM t_a
WHERE id > ?
```

JdbcTemplate and Mybatis handle with left-to-right as they appear

```
EXECUTE s1 USING 'user',  12
```

But Presto is expecting

```
EXECUTE s1 USING 12, 'USER'

```

## If without with clause

```
PREPARE s1 FROM
SELECT
	*
FROM(
	SELECT
		*
	from table1
	where name = ?
)src
where
	id > ?
```

Presto is expecting the same order as mybatis is generated

```
EXECUTE s1 USING 'user', 12
```


Similar issue in trino has been proposed [Wrong parameters order in EXECUTE USING when using with clause](https://github.com/trinodb/trino/issues/1191)
