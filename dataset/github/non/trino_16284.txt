Trino iceberg jdbc catalog should retry connecting to database
Apparently, Iceberg jdbc catalog does not refresh its connection. We connect our Trino cluster to an aurora serverless db that scales up and down during the day, and can reach 0 instances. When this happens, all connections are lost, but Trino doesn't try to reconnect when executing another query.

## Connection properties

  trusted.properties: |-
    connector.name=iceberg
    iceberg.catalog.type=jdbc
    iceberg.file-format=PARQUET
    iceberg.jdbc-catalog.catalog-name=trusted
    iceberg.extended-statistics.enabled=true
    iceberg.jdbc-catalog.connection-url=jdbc:postgresql://my-cluster:5432/my-db
    iceberg.jdbc-catalog.connection-user={{.Values.secrets.dbUsr}}
    iceberg.jdbc-catalog.connection-password={{.Values.secrets.dbPwd}}
    iceberg.jdbc-catalog.default-warehouse-dir=s3://trusted-data
    hive.s3.endpoint=https://s3.us-east-1.amazonaws.com
    hive.s3.aws-access-key={{ .Values.secrets.trustedAwsAccessKey }}
    hive.s3.aws-secret-key={{ .Values.secrets.trustedAwsSecretKey }}


## How to reproduce it

* Start trino cluster connecting to a jdbc iceberg catalog
* Drop trino user connections from db ( something like: `select pg_terminate_backend(pid) 
from pg_stat_activity 
where state = 'idle' 
and usename = 'trino-user' ;`
* execute a select statement on a schema table
