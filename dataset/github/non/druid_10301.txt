Issues with export-metadata
Needing to do a migration from Derby to Postgres I found two issues with the export-metadata instructions

### Affected Version

latest (0.18.1)

https://druid.apache.org/docs/latest/operations/export-metadata.html

### Description

1. The export-metadata tool is broken. The exported CSV does not properly delimit backslashes. The workaround is to replace all `\` in the file with `\\` before import to Postgres can be done.

2. The import process is flawed and will break supervisors. The `druid_supervisors_id_seq` needs to be updated after the COPY commands (since COPY does not update sequences).  The one-line to accomplish this (after the COPY commands) should be:
```
SELECT setval('druid_supervisors_id_seq', (SELECT MAX(id) FROM druid_supervisors));
```
