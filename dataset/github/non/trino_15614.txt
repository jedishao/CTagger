Custom Types not supported by TrinoClient
When new custom types are defined on Trino (for example, to support integers bigger than 64 bits) and a table that uses these types is queried with the Trino client, an `unhandled type` error is thrown ([here](https://github.com/trinodb/trino/blob/master/testing/trino-testing/src/main/java/io/trino/testing/TestingTrinoClient.java#L322)).

Would it be possible to extend the definition of `TestingTrinoClient` so that it can take extra custom types without erroring?
