worsened performance for versions > 3.16.2
I'm tried running the following test using spring boot  and redisson :

@Autowired
  private RedissonReactiveClient client:

  @RepeatedTest(3)
  void redisson() {
    RAtomicLongReactive atomicLong = client.getAtomicLong("usr:2:visit");
    Mono<Void> mono = Flux.range(1, 500_000)
        .flatMap(i -> atomicLong.incrementAndGet())
        .then();
    Instant startTm=Instant.now();
    StepVerifier.create(mono).verifyComplete();
    Duration duration = Duration.between(startTm, Instant.now());
    System.out.println(duration.toMillis()+ " ms");
  }



when I use redisson version 3.16.1 or 3.16.2, my test executes in 8-9 ms.
But when I use a higher version, tried from 3.16.3 to 3.17.5, the tests executes in 22-24 ms; which is significantly slower.

**Actual behavior**
use redisson 3.16.1 or 3.16.2

**Steps to reproduce or test case**

**Redis version**
7.0.4

**Redisson version**
3.16.3 and higher
