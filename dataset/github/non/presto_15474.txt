GROUPING SETS ordinal column documentation mis-documented
I'm working with `GROUPING SETS` and was hoping to group using an ordinal column. From https://github.com/prestodb/presto/issues/9522 it appears that this isn't supported because it violates the SQL standard. However, the Presto documentation for [complex grouping operations](https://prestodb.io/docs/current/sql/select.html) implies otherwise (emphasis added):

> Presto also supports complex aggregations using the **GROUPING SETS**, CUBE and ROLLUP syntax. This syntax allows users to perform analysis that requires aggregation on multiple sets of columns in a single query. Complex grouping operations do not support grouping on expressions composed of input columns. **Only column names or ordinals are allowed.**

I just wanted to point out the potential inconsistency.
