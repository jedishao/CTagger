Redisson 3.19.1 - JCache CacheEntryListener can not deserialize Kotlin LinkedHashMap (3.18.1 success)
<!--

**Expected behavior**

deserialize is success for kotlinx.collections.Map<K, V> type

**Actual behavior**

In Redisson 3.19.1, CacheEntryListener for JCache is unable to deserialize kotlin.collections.LinkedHashMap<K, V>.
When use Java `java.util.HashMap<K, V>` is success.

I created NearCache which use Redis as back cache.
