Mismatch Domain Type Problem
In TestMaterializedViewQueryOptimizer, if we try to execute query with two different length string in the filter condition, the optimization will fail:

```
MV Definition: SELECT a, b FROM %s WHERE b <> 'apple'
Base Query: SELECT a, b FROM %s WHERE b = 'banana'

This will fail due to "Mismatch domain types: varchar(6) vs varchar(5)"
```
