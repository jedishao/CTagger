Extend ScheduledExecutorService's cron expression format with an optional "year" field
Quartz cron expressions have an optional seventh field, which signifies the year: 
http://www.quartz-scheduler.org/documentation/quartz-2.3.0/tutorials/crontrigger.html
```
1. Seconds
2. Minutes
3. Hours
4. Day-of-Month
5. Month
6. Day-of-Week
7. Year (optional field)
```
Despite claiming full compliance with the Quartz cron expression format, Redisson seems to support only 6-field cron expressions at the moment. Please extend the ScheduledExecutorService's cron expression format with an optional "year" field.
