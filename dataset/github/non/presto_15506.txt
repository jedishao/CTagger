Abandoning String Dictionary is very slow
Assume a String dictionary with X millions of keys are abandoned. String dictionary writer, converts in blocks of max 1024 rows at a time. For each of this 1024 rows, it tries to ensure that the size is less than 32 MB.

the logical size calculation, allocates a cache of X million keys, initializes them to -1, populates only 1024 entries. This slows down the abandoning process by 150 times.
