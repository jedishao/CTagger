Enable CTAS with unmanaged tables for presto-hive
As a developer
I would like doing a `CREATE TABLE AS SELECT` with an external location provided

For example : 
`
CREATE TABLE mytable
WITH (format = 'PARQUET', external_location='s3://mybucket/prefix/')
AS 
SELECT * from anothertable
`

[Currently implemented in trinodb](https://github.com/trinodb/trino/commit/66c360963e690a13b5a526060d7faac2110279ef)
