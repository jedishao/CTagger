nonProxyHost property ignored in Copy Constructor of ClientOptionsBase
### Version

Which version(s) did you encounter this bug ? 
4.3.2

### Context
nonProxyHostList value overrides to null by creating new WebClientOptions from existing WebClientOptions

```
WebClientOptions options = new WebClientOptions();
options.setNonProxyHosts(Arrays.asList("10.*","localhost"));
options.setTrustAll(true);
ProxyOptions proxyOptions = new ProxyOptions();
    proxyOptions.setHost("proxy-server");
    proxyOptions.setPort(3128);
options.setProxyOptions(proxyOptions);

//check log level and set log activity
WebClientOptions  finalOptions = new WebClientOptions(options).setLogActivity(false);
finalOptions .getNonProxyHosts() //returns null
```
