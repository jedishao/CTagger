`RScheduledFuture<?> future = RExecutor.schedule(new TestTask(), CronSchedule.of("0 */10 * * * *"));`

```
public class TestTask implements Runnable, Serializable {

    @RInject

    public TestTask() {
    }

    @SneakyThrows
    @Override

        throw new ApiFailureException("test");
    }

}
```
If the retryInterval is 1min and the retryAttempts 3, I was expecting that, after the task starts, an exception was thrown and then the task was rescheduled for a minute later (3 times).
