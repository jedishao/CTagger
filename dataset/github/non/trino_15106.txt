Improve distinct aggregation performance
At the moment, queries that use multiple distinct aggregations e.g. `select count(distinct orderkey) co, count(distinct partkey) cp from lineitem`, use multiple `MarkDistinctOperator`s and, at least in some cases, this is slower than reading the source table multiple times and using hash aggregation.
