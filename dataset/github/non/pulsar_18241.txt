[Bug] `InvalidCookieException` when restart pulsar standalone with multiple bookies
### Search before asking

- [X] I searched in the [issues](https://github.com/apache/pulsar/issues) and found nothing similar.


### Version

Master branch.

### Minimal reproduce step

After #18206, I can start pulsar standalone with multiple bookies. But if I restart the server, `InvalidCookieException` will occur.

1. `rm data` to remove the old data folder.
2. `bin/pulsar standalone --num-bookies 2` to start pulsar **with multiple bookies**, use rocksDB as the metadata store by default.
3. `Ctrl + C` stop the server.
4. `bin/pulsar standalone --num-bookies 2` to start pulsar again. Then `InvalidCookieException` occurs.

Start normally.
