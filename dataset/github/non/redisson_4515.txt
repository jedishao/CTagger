英文太难打了，大概意思就是：
当我启动单利模式的时候，如果我没有任何配置，启动直接创建50个连接，如果我配置了连接数那么启动创建的连接数是27个，为什么我是单利模式还要创建 24个slave的连接而且还没法删除，我的测试环境有40个pod,底层用的相同的配置，一启动什么也没做，redis server 直接 2000个连接打满。有谁遇到过这个问题么，我看了源代码是因为SingleEntry 是继承  MasterSlaveEntry 的，实例化SingleEntry时 实际使用的是 MasterSlaveEntry：

    public SingleEntry(ConnectionManager connectionManager, MasterSlaveServersConfig config) {
        super(connectionManager, config);
    }
而在MasterSlaveEntry 中，创建了MasterPubSubConnectionPool  ,SlaveConnectionPool ,MasterConnectionPool , 这里的SlaveConnectionPool 使用的是默认配置，无法使用到自定义配置，也就是说即便我使用了single mode， 只要启动服务就会有最低27个连接被创建。
 public MasterSlaveEntry(ConnectionManager connectionManager, MasterSlaveServersConfig config) {
        this.connectionManager = connectionManager;
        this.config = config;
        this.slaveBalancer = new LoadBalancerManager(config, connectionManager, this);
        this.writeConnectionPool = new MasterConnectionPool(config, connectionManager, this);
        this.pubSubConnectionPool = new MasterPubSubConnectionPool(config, connectionManager, this);
    }
