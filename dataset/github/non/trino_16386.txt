Off by +1 error causing HIVE connector skipping parquet files
There is an issue with the HIVE connector

If the second character of a parquet file contains an "\_" or "." then the HiveFileIterator.java will skip that file. According to documentation if the 1st character is an "\_" or "." then it should be hidden.

See
https://github.com/trinodb/trino/blob/master/plugin/trino-hive/src/main/java/io/trino/plugin/hive/fs/HiveFileIterator.java#L153

Test case:
-  2 parquet files in S3 storage.
- p_file1.parquet
- p_file2.parquet
- create a schema
- Run SQL query. You will see due to the 2nd (not the 1st) character is an _ nothing will be returned in a select *
