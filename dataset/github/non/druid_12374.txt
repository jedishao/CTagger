Turns out, java needs to be in the PATH for DRUID to be able to spun new processes. 
A workaround is adding my JAVA bin directory to my PATH fixed this problem. 
`export PATH=$PATH:/usr/local/bin/jdk1.8.0_202/bin/`

Interestingly this was not mentioned in the quick tutorial guide.  (This was not mentioned in JAVA 8 installation guide either). 

It seems this should not be necessary though, because I specified DRUID_JAVA_HOME, and for any forked processes, it should use my DRUID_JAVA_HOME/bin/java instead of calling "java" directly  (see the line started with [forking-task-runner-0])
