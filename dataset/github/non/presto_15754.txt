MAP_UNION accepts ORDER BY syntax but does not do the right thing at execution
MAP_UNION aggregation accepts the ORDER BY clause but it's not actually respecting it. So either we disallow/warn about the syntax or implement it properly (preferred).

```
presto:di> select map_union(x order by y desc) from (select 10, map(array[1], array['a']) union all select 1, map(array[1], array['b'])) T(y, x);
 _col0
-------
 {1=b}

presto:di> select map_union(x order by y asc) from (select 10, map(array[1], array['a']) union all select 1, map(array[1], array['b'])) T(y, x);
 _col0
-------
 {1=b}
 ```
