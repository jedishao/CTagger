How to work around `RPriorityBlockingQueue#contains` behaving differently from `BlockingQueue#contains`?
### Problem Statement 

I'm using Redisson's `RPriorityBlockingQueue` to replace an existing Java-standard  `BlockingQueue` (a `PriorityBlockingQueue` to be exact). I found the following difference in behaviour :  Java's  `PriorityBlockingQueue#contains` relies on the `equals` method of the queued objects, whereas `RPriorityBlockingQueue#contains` relies on the `compareTo` method of the queued objects. This is creating problems. 

* Is this behaviour by design? 
* How can I work around this to get the following effects?
    1. Queue checks if it `contains` something using `equals`
    2. Queue uses `compareTo` to sort objects when `poll`ed 

See code below for a working example of the problem. 

```java

import java.io.Serializable;
import java.util.Objects;

import org.redisson.Redisson;
import org.redisson.api.RPriorityBlockingQueue;
import org.redisson.api.RedissonClient;

public class RedissonExperiment {

    public static void main(final String[] args) {
        final RedissonClient redisson = Redisson.create();

        final RPriorityBlockingQueue<Entry> queue = redisson.getPriorityBlockingQueue("testQueue");
        queue.offer(new Entry("a", 2));
        queue.offer(new Entry("b", 1));
        queue.offer(new Entry("c", 0));

        // Must use `equals` to check `contains`
        System.out.println(queue.contains(new Entry("a", 200))); // Expected: `true`. Actual: `false`.
        System.out.println(queue.contains(new Entry("d", 0))); // Expected: `false`. Actual: `true`.

        // Must print c, b, a using `compareTo`
        while (queue.peek() != null) {
            final Entry item = queue.poll();
            System.out.println("item: " + item);
        }

        System.out.println("Done");
        redisson.shutdown();

    }

}

class Entry implements Comparable<Entry>, Serializable {

    private final String key;

    private final Integer value;

    public Entry(final String key, final Integer value) {
        this.key = key;
        this.value = value;
    }

    @Override
    public int compareTo(final Entry o) {
        return value.compareTo(o.value);
    }

    @Override
    public boolean equals(final Object o) {
        if (this == o) {return true;}
        if (o == null || getClass() != o.getClass()) {return false;}
        final Entry entry = (Entry) o;
        return key.equals(entry.key);
    }

    @Override
    public int hashCode() {
        return Objects.hash(key);
    }

    @Override
    public String toString() {
        return "Entry{" + "key='" + key + '\'' + ", value=" + value + '}';
    }
}
``` 
