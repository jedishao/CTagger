Docs – Task Affinity is not a runtime property
**With its focus on Druid configuration files, the Configuration Reference contains information about the dynamic configuration of task affinity that is set by calling an API, not held in configuration files.**

### Affects Versions

0.22

### Description

- Relates to https://druid.apache.org/docs/latest/configuration/index.html#overlord-dynamic-configuration
- Task Affinity is a hidden gem of Druid functionality, and would be better served if this information was alongside ingestion information in the docs

### Proposal

As with #11984 move this section of the docs out to a new page that allows users to see that task affinity options for ingestion tasks.
