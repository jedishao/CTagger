Implement `stream` table function that will produce unlimited sequences
`sequence` is a very useful function that can produce all values of a discrete type within a range.
However, since the function returns a single ARRAY, it cannot return large sequences. In fact, it's constrained to limit sequences of at most 10,000 elements:

```
Query 20220608_121504_61596_etnj7 failed: result of sequence function must not have more than 10000 entries
```

Implement a [**table function**](https://trino.io/docs/current/develop/table-functions.html) that will not have such limitations

```sql
SELECT element FROM TABLE(stream(1, 10000000));
```

Note: if we can guarantee that function and table function namespaces will always be separate, then we should reuse the `sequence` for the name of the table function. In either case, we should keep signatures aligned.
