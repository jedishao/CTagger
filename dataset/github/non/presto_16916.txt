[Feature request] streaming ANOVA implementation
I'm interested in implementing a new aggregation function that provides [one-way ANOVA](https://en.wikipedia.org/wiki/Analysis_of_variance) and two-sample t-test statistics.

The value of these is being able to perform additional statistical hypothesis test in presto, such as being able to assess differences in group means.

The interface would be a new aggregation function:

```
SELECT 
    ANOVA(column, grouping_column)
FROM tab
```

where `column` is numeric and `grouping_column` is a categorical column of some kind.

This would output a single F-statistic. (A two-sample t-test is equivalent to ANOVA, where t = sqrt(F).)

I have a working prototype of the algorithm in R, which simply involves updating distribution moments per-group. Presto already implements this kind of approach for AVG(), STDDEV(), etc. for a column as a whole. For ANOVA, I would need this once per "group" in the grouping_column.

I'm happy to submit a PR for this if the team is interested but I might need some pointers on how to modify the existing moment state functionality to handle multiple groups. I looked at the implementation of HISTOGRAM() as a possible source of inspiration: replacing counts with moments.
