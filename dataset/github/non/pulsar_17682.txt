### What issue do you find in Pulsar docs?

When searching "Pulsar-Admin" in Google, the first result redirects to this page in French: https://pulsar.apache.org/fr/docs/pulsar-admin/, which is not expected. And the link [Pulsar admin doc](https://pulsar.apache.org/fr/tools/pulsar-admin/) included on this page is 404 because `fr` is injected into the URL.

Another case is:
when someone searches `set up Pulsar connectors` in Google, the first result goes to [2.3.1 doc](https://pulsar.apache.org/docs/2.3.1/io-connectors) but not the latest doc version.

### What is your suggestion?

The search result should go to https://pulsar.apache.org/docs/pulsar-admin/, instead of https://pulsar.apache.org/fr/docs/pulsar-admin/.
