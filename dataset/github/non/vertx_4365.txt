Let users define a codec to use when no codec was found
- Register codecs as usual
- Provide a function to the `EventBus`; the function is invoked when no codec has been found for message body and must return a user codec name

This can solve a few use cases, for example:

- selecting a codec that does nothing for objects to deliver locally if the user knows the object is immutable
- user has many objects generated from `.proto` files and wants to defer to [Protocol Buffers](https://developers.google.com/protocol-buffers) for serialization / deserialization
- user wants to use JSON codec for any object

Sample usage:

```java
EncodeEveryThingWithJacksonCodec everyThingWithJacksonCodec = new EncodeEveryThingWithJacksonCodec();
vertx.eventBus().registerCodec(everyThingWithJacksonCodec);
vertx.eventBus().codecSelector(body -> everyThingWithJacksonCodec.name());
```
