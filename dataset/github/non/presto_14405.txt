Missing function to apply a custom number format
Hello folks, I noticed that PrestoDB doesn't have any function that accepts as input a number field and outputs a string representing that number with a specific format.

For example, in PostgreSQL we have the [TO_CHAR](https://www.postgresql.org/docs/9.6/functions-formatting.html) function which accepts multiple variable types as input:

`SELECT to_char('%,.2f', 1234567.89) -- Output = '1,234,567.89'`

If I try to run that query on PrestoDB, if raises a type error, so this method already exists (with reversed parameter order) but only works for timestamps.

`
Error running query: line 1:193: Unexpected parameters (varchar(5), decimal(9,2)) for function to_char. Expected: to_char(timestamp with time zone, varchar)
`

It would be really nice to be able to that by SQL instead of having to format the output on the consumer application. Thanks!!
