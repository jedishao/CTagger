IS DISTINCT FROM NULL gives wrong result when applied to columns with null values
Bug:
```
presto:ad_metrics> select x is distinct from null from (select cast(null as varchar))T(x);
 _col0 
-------
 true  
```

Works fine for literals though.
```
presto:ad_metrics> select null is distinct from null;
 _col0 
-------
 false 
```
