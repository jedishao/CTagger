Accelerate queries using sample tables in Presto
The basic proposal is to 

- Allow Presto to accelerate queries by replacing original table with sample tables in queries
- Acceleration enabled by setting session parameter
- The Connector Metadata can specify if a sample table exists for a parent table and the sampling percentage
- Presto then optimizes the query, replacing the TableScans for the original table by sample table scans
- Also, aggregation operations like count, sum, approx_distinct can be scaled up based on the sampling percentage of the sample table

The idea is to implement this as an optimization rule, so that the changes are contained in one places.
