Verifier: improve column mismatch error for arrays, maps and structs
It would be helpful to provide a bit more information when there a column mismatch on a complex type column (array/map/struct). 

For arrays, 
- total number of elements (`sum(cardinality(a))`) (e.g. row count check at the column level)

For maps, 
- total number of elements (e.g. row count check at the column level)
- checksum of keys 
- checksum of values

For structs,
- checksums of individual subfields
