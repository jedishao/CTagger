Production Feature performance improvements
Hi, I want to open this thread to understand how the community thinks about the performance impact (improvements/degradations) against a specific feature in the production environment. I think for the development and performance testing phase, people would like to use [Benchto](https://github.com/prestodb/benchto). But how would it work in production, there are few ways in our mind:

First, define the key metrics for the feature, which could be CPU / MEM / IO / latency, etc, then:

1. Run the same query (from production) multiple times in a completely blank cluster with session parameter override, then have a dashboard to show the key metrics difference for the different cohorts.
2. Similiar but either duplicate some % of queries with different features on production cluster or replicate complete traffic from a cluster and effect queries in some session parameter override, in order to understand the performance under load.
But 2 seemed to be a bit heavier and really need to reserve some capacity for this.

Want to hear some thoughts, suggestions, and maybe some collaborations in the community.
