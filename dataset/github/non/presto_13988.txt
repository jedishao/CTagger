Support for ordering pushdown.
I run <select * from (select * from oracle1.tdr.my_table union all select * from oracle2.tdr.my_table) order by id;> to do distribution sort. And I found out that on oracle1 instance and oracle2 instance the running SQL is: <select * from tdr.my_table>, which seems that presto fetch all my_table’s data in to presto’s memory and process sorting. According to David's explain Presto currently don't support ordering pushdown. So does community plan to support this feature in the future?
