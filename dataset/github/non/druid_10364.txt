Double Sketch Histogram: ReadOnlyException Memory is read only (when split points is >= 50)

### Affected Version

0.19.0

### Description

I attached the debugger to the broker running locally and the issue is easy to see.  If there are > 50 split points, the sketch will perform a sort as part of the process of building the histogram.  See code:

https://github.com/apache/incubator-datasketches-java/blob/bd6f03f6d0a80cfef7f93273f7f696162c7eaf67/src/main/java/org/apache/datasketches/quantiles/DoublesPmfCdfImpl.java#L65-L70

The exception happens when the sketch is backed by a read only direct byte buffer. It tries to write back to itself here:

https://github.com/apache/incubator-datasketches-java/blob/bd6f03f6d0a80cfef7f93273f7f696162c7eaf67/src/main/java/org/apache/datasketches/quantiles/DirectDoublesSketchAccessor.java#L88


I'm going to contribute a fix for this in the data sketches library, but I figured I would open a bug here since it's affecting druid.  My thinking is this bug can be closed out when the fix is in data sketches and we can rev the version in druid.

Thanks
