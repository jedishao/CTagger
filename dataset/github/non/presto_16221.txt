 Support Aggregate pushdown for JDBC data sources
Currently, Presto JDBC data sources support a rich filtering push down capability, which can dramatically affect the query performance. However, many of our businesses may have some aggregation in addition to filtering conditions, and Presto already supports a relatively complete aggregation push down capability, so it is necessary to implement an aggregation push down in the JDBC data sources.

I have seen [#4839](https://github.com/prestodb/presto/issues/4839) issue, but no progress seems to have been made so far, so I reopened a new issue to discuss it.
