Different auto-compaction configs based on the age of the data segments
### Description
It would be good  to have several auto compaction tasks for one datasource based on segment age. 

### Motivation

If for example I want to have  Hour granularity for last 30 days, Day granularity and less dimensions for 30-365 days, Year granularity and only several dimensions left for 365+ days. As usually for older data we only need to have some general overview and not detailed reports.
