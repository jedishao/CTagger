Unnest generates large DictionaryBlock when converting ColumnarArray
UnnestOperator converts the unnest column to ColumnarXXX objects. When the input of the unnest Block is a DictionaryBlock made of ArrayBlock, and each array has a lot of rows, and there are lots of repeating ids, toColumnarArray would generate large DictionaryBlock with ids array over millions of values. 
E.g. Input block is

```
DictionaryBlock of 300 rows: 
    ids: 300 rows: [0,0,2,62,62,62,...62,64,64,...64,...]
    dictionary: ArrayBlock of 1000 rows: 
        offsets: [0, 1000, 1000,1000,...1000]
        values: LongArrayBlock of 70000 integer values [....]

```
The ColmunarArray created was
```
offsets: 301 rows: [0,1000,2000,...]
elementsBlock: 
     DictionaryBlock of **300000** rows: 
        ids: [0,1,2,...999, 0,1,2,... 999, 2000,2001,...2999, ...62000,62001, ...62999, 62000, 62001, ...62999 ,...]
        dictionary:  LongArrayBlock of 70000 integer values [....]

```
The large ids array caused problem for later operators, e.g. when doing BlockFlattener.flatten(), the ids could be over 5 million values and the array is over 2GB Slice limit.
