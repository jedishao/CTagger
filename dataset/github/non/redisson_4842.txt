**Is your feature request related to a problem? Please describe.**
If I set the RMap with write-behind, then I can't evict a key manually without affecting my storage. 

**Describe the solution you'd like**).
RMap to have `evict` method that will only evict from Redis without affecting external storages when using the write-behind strategy.

**Describe alternatives you've considered**
Possibly can be solved by adding `evict(key)` and simply calling `removeOperationAsync` (that is protected encapsulation thus no simple workaround).
