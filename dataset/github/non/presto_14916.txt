Unexpected 'ARRAY comparison not supported for arrays with null elements' error when using array column in a subquery
Consider the following subquery that we have on our AWS EMR Cluster (EMR version 5.29, Presto 0.227):
```
...
inter_treatment_filtered_messages AS
(
    WITH aux_table AS
    (
        SELECT communication_type, message_parts,
            row_number() OVER(
                PARTITION BY
                    fmboa.message_contact
                ORDER BY
                    fmboa.treatment_rank, fmboa.treatment_name)
            AS rnk
        FROM filtered_messages_based_on_aggr AS fmboa
    )
    SELECT *
    FROM aux_table
    WHERE rnk = 1
)
SELECT *
FROM inter_treatment_filtered_messages
```

The column `message_parts` type is `ARRAY<STRING>` and the other columns are BIGINT or STRING. When we run the query that contains this subquery, it fails with the following stacktrace:
