I'm running in to
```
Caused by: com.google.protobuf.InvalidProtocolBufferException: Protocol message had too many levels of nesting.  May be malicious.  Use CodedInputStream.setRecursionLimit() to increase the depth limit.
	at com.google.protobuf.InvalidProtocolBufferException.recursionLimitExceeded(InvalidProtocolBufferException.java:125)
	at com.google.protobuf.CodedInputStream$ArrayDecoder.readMessage(CodedInputStream.java:885)
```
when parsing a request message that happens to have a very deep, nested structure. The marshaller `ProtoLiteUtils.java` seems to use the default of 100.

100 is of course a lot in most cases, but not when e.g. sending over serialized expressions of 30-ish deep function calls, which doesn't seem too unlikely (I ran in to it implementing the expression language [CEL](https://github.com/google/cel-spec) for example).

Is it possible to raise this limit a bit, or make it configurable?
