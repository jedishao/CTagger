Prepared statement fails when using PARTITION and DATE_TRUNC
Running the following query issues an error: `PARTITION BY expression 'DATE_TRUNC(?, orderdate)' must be an aggregate expression or appear in GROUP BY clause`:

```
PREPARE statement1 FROM
SELECT DATE_TRUNC(?, orderdate), SUM(COUNT(DISTINCT custkey)) OVER (PARTITION BY DATE_TRUNC(?, orderdate)) FROM "tpch"."sf1"."orders"
GROUP BY 1;

EXECUTE statement1 USING 'week', 'week';
```

The same query without a prepared statement works fine:

```
SELECT SUM(COUNT(DISTINCT id)) OVER (PARTITION BY DATE_TRUNC('week', "date")) FROM "sample"."demo"."missions"
GROUP BY DATE_TRUNC('week', "date");
```
