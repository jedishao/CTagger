Create JetBrains IntelliJ project & run/debug configuration templates
It would be very helpful if there was support in IntelliJ for a Vert.x [project template](https://www.jetbrains.com/help/idea/2022.1/new-project-wizard.html#framework-based-project) (e.g. `File > New > Project > Generators > Vert.x`) and [run/debug configuration template](https://www.jetbrains.com/help/idea/list-of-run-debug-configurations.html).

I started working on creating a proof-of-concept Vert.x application this morning, and I had to go hunting for answers on StackOverflow after using https://start.vertx.io to create a basic Verti.x web application using Kotlin and Gradle.  Turns out that I needed to specify `io.vertx.core.Launcher` as my Main class in the `Application > Build and run` section in IntellJ, to get things running.  

I was also getting the following warning when Vert.x started up my starter project in IntelliJ:
```
WARNING: Can not find io.netty.resolver.dns.macos.MacOSDnsServerAddressStreamProvider in the classpath, 
fallback to system defaults. This may result in incorrect DNS resolutions on MacOS.
```

I had to add the following line to my `build.gradle.kts` file to make that go away:
```
implementation("io.netty:netty-resolver-dns-native-macos:4.1.77.Final:osx-x86_64")
```

The need for these steps might be obvious to a more experienced Java developer.  But to novices like myself, it wasn't obvious at all.  Having these templates available in IntelliJ would reduce the number of manual steps needed to get an application up and running.
