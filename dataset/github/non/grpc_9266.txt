customResolver code looks as below 

```
public class CustomNameResolver extends NameResolver {

        this.activeCluster = getActiveClusterUrl();
        return this.activeClusterUrl = this.activeCluster.getActiveCluster();
}

@Override
    @GuardedBy("this")
    public void refresh() {
        if (refreshing) return;
        try {
            refreshing = true;

            this.activeCluster = getActiveClusterUrl();

             activeHost = activeCluster.getActiveCluster().get().split(":");

            ScheduledExecutorService timerService = SharedResourceHolder.get(timerServiceResource);
            timerService.schedule(() -> {
                refresh();
            }, 30, TimeUnit.SECONDS);

            update(new InetSocketAddress(activeHost[0], port)));

        } finally {
            refreshing = false;
        }
    }


  private void update(SocketAddress... addresses) {
        List<EquivalentAddressGroup> servers = Arrays.stream(addresses)
                .map(EquivalentAddressGroup::new)
                .collect(Collectors.toList());
        Attributes attr = Attributes.newBuilder().set(EquivalentAddressGroup.ATTR_AUTHORITY_OVERRIDE, this.activeCluster.getActiveCluster()).build();
        listener.onAddresses(servers, attr);

    }

}
```
