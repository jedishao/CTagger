Redisson throws RedisConnectionException: Can't add slave on Azure Redis instance unavailability and doesn't recover
Context:
Our service is using Redisson to connect to an Azure Redis cluster. Both use cases (caching & distributed locking) are applied, and usually things are working smoothly.

It is just when Microsoft has regular OS patching and 1 or 2 out of the 8 instances (and corresponding connection ports) become unavailable for ~4minutes and the service instances being connected via redisson to Azure Redis begin to throw RedisConnectionExceptions.

Before opening this issue, I checked previously resolved issues **4311** and **4245** which reported similar behaviour.
`org.redisson.client.RedisTimeoutException:* Command execution timeout for command: (AUTH), params: (password masked), Redis client: [addr=rediss://10.112.94.132:15000]*`

`CompletionException: org.redisson.client.RedisConnectionException: Unable to init enough connections amount! Only 11 of 12 were initialized. Redis server: 10.112.94.132/10.112.94.132:15001
Caused by: java.util.concurrent.CompletionException*: io.netty.channel.ConnectTimeoutException: connection timed out: 10.112.94.132/10.112.94.132:15001`

**Expected behavior**
When one of Azure Redis instance is unavailable (due to maintenance or regular OS patching), Redisson should connect to one of the other available instances.

**Actual behavior**
When one of Azure Redis instance is unavailable (due to maintenance, failovers or regular OS patching), Redisson attempts (and fails) to connect to the unavailable cluster instance.
It usually takes ~4 minutes for the Azure Redis instance to come back online.

It can be observed that the instances unavailability happens throughout the day, not all at once.

**Steps to reproduce or test case**
Multiple springboot service instances connected randomly to one of the available Redis instances (at different ports).
One of the Redis instance goes down (unavailable).
RedisConnectionExceptions are thrown by the service instance connected to unavailable Redis instance and it doesn't recover.

**Redis version**
4.0.14
Azure Redis Premium P1 (6 x 24GB)

**Redisson version**
3.17.3
