Query fails when masking function uses a column
Regression bug found on `405`

Access control file:
```
{
    "tables": [
        {
          "catalog": "tpch",
          "schema": "tiny",
          "table": "orders",
          "columns": [
            {
              "name": "comment",
              "mask": "substr(comment,1,3)"
            }
          ],
          "privileges": ["SELECT"],
          "group": ".*"
        }
    ]
}
```

```
SELECT comment FROM tpch.tiny.orders LIMIT 2
```

`405` fails
`trino.exceptions.TrinoUserError: TrinoUserError(type=USER_ERROR, name=PERMISSION_DENIED, message="Access Denied: Cannot select from table tpch.tiny.orders"`

`403`  succeed
```
+-----+
|_col0|
+-----+
|le.  |
|nst  |
+-----+
```

Query succeed on both versions when `"group"` is omitted or when masking function doesn't use a column
