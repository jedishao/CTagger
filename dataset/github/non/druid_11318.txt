ForeverDropRule doesn't drop the segments
**ForeverDropRule** doesn't drop the segments.

### Affected Version

0.21

### Description

Steps to reproduce:
1. Create a datasource.
2. Assign **loadForever** rule.
3. Wait for segments to be loaded.
4. Assign **dropForever** rule.

Expected:
Segments are dropped.

Actual result:
Segments are marked unused, but still occupy space in the historical node.
