Provide the query as an input argument to the presto-on-spark command line
As an AWS developer
I would like to provide the query as an complete input argument when calling a Presto-on-Spark processing

for example : 
`spark-submit -- \
    --class com.facebook.presto.spark.launcher.PrestoFacebookSparkLauncher \
   /presto/presto-spark-launcher/target/presto-spark-launcher-0.xxx.jar \
    --package /presto/presto-spark-package/target/presto-spark-package-0.xxx.tar.gz \
    --config /etc/config.properties \
    --catalogs /etc/catalogs \
    --query "select * from mytable"
`

This would be very usefull when submitting a new Step with presto-on-spark application to an EMR cluster for example.
