Join on multi-value column does not work as expected
### Affected Version

0.18

### Description

The following query based on the CalciteTests data does not return any rows.

```
SELECT dim3, l.v, count(*) from druid.foo f inner join lookup.lookyloo l on f.dim3 = l.k group by 1, 2
```

dim3 is a multi value column where one row has the value ['a', 'b'] and lookup has a key 'a', so this query should match one row.
