Implement range filter pushdown for subfields of array and maps
Range filters, e.g. `a = 5`, on primitive types are evaluated efficiently while reading data from an ORC stream and if columns are used only for filtering corresponding Blocks are never created. This optimization applies to subfields of structs as well, e.g. `a.b.c = 5`. Let's extend this optimization to elements of the arrays or maps, e.g. `a[1] = 5` or `c["cat"] > 10`. 

Filter pushdown on array elements has been implemented and is currently blocked by `range_filters_on_subscripts_enabled` session property. Filter pushdown for map elements needs to be added.

See com.facebook.presto.orc.reader.ListSelectiveStreamReader
