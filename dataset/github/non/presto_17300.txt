Pushown agg to join branches if the group by and join keys are the same
select arbitrary(t1.x1), arbitrary(t1.x2) ... arbitrary(t2.y1),  arbitrary(t2.y2). ...
from t1 join t2 using(k1,k2,..)
group by k1,k2, ...

In this case, it makes sense to pushdown the group by to before join especially if one side is a lot bigger. In fact, if the join keys are a superset of group by keys, then we can pushdown group by all the join keys to both sides too.
