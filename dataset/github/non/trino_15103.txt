Different results to similar datetime handling with `date_add('month', -1` vs `- interval '1' month`
Using  `date_add('month', -1` on truncated specific date with timizone info produces different result compared to  `- interval '1' month`:

```sql
SELECT date_trunc('month', dt) - INTERVAL '1' MONTH,
       date_add('month', -1, date_trunc('month', dt))
FROM (values (parse_datetime('2022-10-30 22:20:45+08:00', 'YYYY-MM-dd HH:mm:ssZ'))) as t(dt);
```
Output:

|_col0                                                            |_col1                           |
|-----------------------------------------------------------------|--------------------------------|
|2022-08-31 00:00:00.000 +08:00                                   | 2022-09-01 00:00:00.000 +08:00 |

Potentially daylight saving time handling can be involved - for the same datetime in September and August the results does not differ.
