### Steps to reproduce the bug

On a Windows 10 PC with MinGW installed via MSYS2, go into the examples directory and run

```
bazel build --compiler=mingw-gcc //...
```

Similar to https://github.com/rules-proto-grpc/rules_proto_grpc/issues/181, issue is resolved by passing `use_default_shell_env = True` to the `ctx.actions.run` that runs protoc in `java_rpc_library`, so that PATH can be inherited from the host and `libstdc++-6.dll` can be found in `C:\msys64\mingw64\bin`.
