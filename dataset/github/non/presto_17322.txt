Query details can't be render when the errorCode of the query is SYNTAX_ERROR
Query details can't be render correctly as you can see from below snapshot. Only impact those query failed due to SYNTAX_ERROR. My version is 0.269, no tested for the others.
![image](https://user-images.githubusercontent.com/3362750/154635316-0ad10b4f-1ebb-4908-b11f-ca5d9992b92b.png)


![image](https://user-images.githubusercontent.com/3362750/154635718-1f2cf6d0-a68f-483f-a48d-28e5a69f271a.png)


I think it's a bug. the reason is the query not be executed so there is no runtimeStats in queryStats. So below code will throw exception.

`if (Object.values(query.queryStats.runtimeStats).length == 0) return null;`
