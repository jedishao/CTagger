Make Serializer as Public or Module with (de)serializer
#### Describe the feature
Make serializer as public 

SerializationInclusion#Include.NON_NULL mus be set before register serializers, but with DatabindCodec, this not possible

To do that, we need to redefine serializers use on DatabindCodec because they aren't define as public  https://github.com/eclipse-vertx/vert.x/tree/master/src/main/java/io/vertx/core/json/jackson

Other better solution is to add a vertx jackson Module with serializers ?

#### Use cases
```
final ObjectMapper mapper = new ObjectMapper()
      .setSerializationInclusion(JsonInclude.Include.NON_NULL)

mapper.registerModule(vertxModule);
```
