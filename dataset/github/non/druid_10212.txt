Cannot start druid when using with gcs-connector.jar and druid-parquet-extensions
Cannot start druid when using with gcs-connector.jar and druid-parquet-extensions.

### Affected Version

v0.19.0

### Description
When using Druid in GCP, and indexing on GCP Dataproc, I am unable to start Druid historical process, when using with `druid-parquet-extensions`. If i don't load parquet extensions it works perfectly fine.

- Cluster size - Single server Small
- Configurations in use - Default with GCS storage
- Steps to reproduce the problem
Add extension 
druid.extensions.loadList=["druid-kafka-indexing-service", "druid-datasketches","druid-google-extensions", "druid-parquet-extensions"]
And make sure gcs-connector.jar (downloaded from Dataproc cluster) is in apache-druid-0.19.0/lib
