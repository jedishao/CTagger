Iceberg connector remove_orphan_files should support process specified subfolder
in our case, the iceberg table is mostly an append only table, which means we only add data, seldom delete or update.
So the only folder we want to clean up is the metadata folder, where metadata json and manifest avro  files pile up as we commit snapshot to the table.

so we'd like remove_orphan_files to accept another argument (e.g. location), and the procedure only scans this location. 
Spark has this kind of support already.
