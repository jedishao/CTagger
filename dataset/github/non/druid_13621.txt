stringFirst/stringLast aggregators returns null when used together with timeColumn
`stringFirst` / `stringLast` aggregators returns `null` when used together with `timeColumn`.

### Affected Version

0.23.0

### Description

```
{
  "queryType": "groupBy",
  "dataSource": {
    "type": "inline",
    "columnNames": ["__time", "date", "text", "number"],
    "rows": [
      [1609459200000, 1609459200000, "a", 1],
      [1609545600000, 1609545600000, "b", 2],
      [1609632000000, 1609632000000, "c", 3]
    ]
  },
  "granularity": "all",
  "intervals": ["0/3000"],
  "aggregations": [
    {
      "type": "stringFirst"
      "fieldName": "text",
      "timeColumn": "date",
      "name": "firstText",
    },
    {
      "type": "stringLast"
      "fieldName": "text",
      "timeColumn": "date",
      "name": "lastText",
    },
    {
      "type": "stringAny"
      "fieldName": "text",
      "name": "anyText",
    },
    {
      "type": "longFirst"
      "fieldName": "number",
      "timeColumn": "date",
      "name": "firstNumber",
    },
    {
      "type": "longLast"
      "fieldName": "number",
      "timeColumn": "date",
      "name": "lastNumber",
    }
  ]
}
```

output:

| firstText | lastText | anyText | firstNumber | lastNumber |
| --------- | -------- | ------- | ----------- | ---------- |
| null      | null     | a       | 1           | 3           |

expected output:

| firstText | lastText | anyText | firstNumber | lastNumber |
| --------- | -------- | ------- | ----------- | ---------- |
| a      | c     | a       | 1           | 3           |


If there is no `timeColumn` used, output is correct.
Same case when `dataSource` is regular table.
