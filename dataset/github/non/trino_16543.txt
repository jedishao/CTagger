Trino 410 + Superset  2.0.0  not displaying tables in UI 
# Steps 
- Install trino 410 connector using helm chart and configure as example  : 
''' 
connectors:
  athena.properties: |
    connector.name=hive
    hive.hdfs.impersonation.enabled=true
    hive.metastore=glue
    hive.metastore.glue.region=us-east-1
    hive.metastore.glue.aws-access-key=${ENV:SECRET_AWS_ACCESS_KEY_ID}
    hive.metastore.glue.aws-secret-key=${ENV:SECRET_AWS_SECRET_ACCESS_KEY}
    hive.s3.aws-access-key=${ENV:SECRET_AWS_ACCESS_KEY_ID}
    hive.s3.aws-secret-key=${ENV:SECRET_AWS_SECRET_ACCESS_KEY}
'''
- Install superset 2.0.0 
- Configure trino in superset SQLALCHEMY URI :  trino://admin@trino.trino.svc.cluster.local:8080/athena

# Expected 
- See all tables in a schemas using trino 410 connector
