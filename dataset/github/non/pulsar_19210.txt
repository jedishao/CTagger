[Bug] BacklogQuota not being enforced when it should be
### Search before asking

- [X] I searched in the [issues](https://github.com/apache/pulsar/issues) and found nothing similar.


### Version

**OS Version/Computer:** M1 Macbook, Monterrey 12.6.1
**Pulsar Version:** Pulsar Standalone Docker 2.10.1 and 2.11.0, run locally on Mac



### Minimal reproduce step

1. Spin up a brand new docker standalone for specific version, locally on Mac
1. Using our python code, create a topic with the following (note, python code under the hood is using the HTTP API to accomplish this)
    - 1 partition
    - persistent 
    - Retention Policy time of -1
    - Backlog Quota time of 60 seconds, with an action `producer_exception` 
    - 1 consumer group
```
  "backlog_quota_map" : {
    "message_age" : {
      "limit" : -1,
      "limitSize" : -1,
      "limitTime" : 60,
      "policy" : "producer_exception"
    },
    "destination_storage" : {
      "limit" : 2147483648,
      "limitSize" : 2147483648,
      "limitTime" : -1,
      "policy" : "producer_exception"
    }
  },
```
1. Migrate topic to Pulsar instance
1. Create a publisher and send a message (successfully) to pulsar 
1. Made sure the message just sent was not consumed   
1. Wait 5 minutes, and send another message

This was done with version 2.10.1 and 2.11.0, on my local Macbook, and a colleagues Macbook with similar specs and version.
We also did the exact same procedure, except when setting the Backlog quota, we manually set this through `pulsar-admin set-backlog-quota`
