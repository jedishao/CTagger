Expand bucket pruning to predicates with fixed number of matching values
When table is bucketed, an equality filter on bucketed-by column(s) will trigger bucket pruning and allow Presto to scan only matching files. E.g. the following query will scan only one file.

`SELECT * FROM t WHERE x = 5`

This optimization can be expanded to more sophisticated predicates, e.g. `x IN (5, 7, 10)` or `x = 5 OR x = 6 or x = 10`, e.g. any predicate for which only fixed number of values match.
