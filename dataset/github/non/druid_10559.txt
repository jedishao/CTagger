Query planner fails to plan nested query when an inner query is to topN and outer one has a filter
### Description

Below query throws a planner exception - 
```
SELECT * FROM 
(
  SELECT "channel", count(*) as c
  from wikipedia
  group by 1 
  ORDER BY 2 desc
  limit 10
) 
where "channel" = '#en.wikipedia'
```
